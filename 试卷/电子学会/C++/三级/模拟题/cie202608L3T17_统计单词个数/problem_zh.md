# 统计单词个数

输入一行英文句子（仅含小写字母和空格），单词之间由一个或多个空格分隔，句首句尾也可能有空格。请统计句子中单词的个数。

【输入格式】一行字符串，长度不超过 1000。
【输出格式】一个整数，表示单词个数。
【样例输入 1】
```
hello world
```
【样例输出 1】
```
2
```
【样例输入 2】
```
  i   love  cpp  
```
【样例输出 2】
```
3
```
【数据范围】字符串长度不超过 1000，至少含一个单词。

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1200**。
