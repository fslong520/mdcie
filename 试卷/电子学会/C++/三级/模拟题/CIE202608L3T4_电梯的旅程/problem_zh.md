# 电梯的旅程

小明去买东西，乘电梯从 1 楼出发，依次要去若干楼层。已知电梯每次只移动一层，请计算小明一共走了多少层（上升或下降一层都计 1 层，不必考虑电梯中途是否停留）。

【输入格式】第一行一个整数 n；第二行 n 个整数表示目标楼层。

【输出格式】一个整数，表示总移动层数。

【样例输入 1】
```
3
3 5 2
```
【样例输出 1】
```
7
```
【样例输入 2】
```
4
5 1 5 1
```
【样例输出 2】
```
12
```
【数据范围】1 ≤ n ≤ 10000，1 ≤ 楼层 ≤ 100。

#### 知识点与难度

本题涉及知识点：**模拟、绝对值**，难度（CF Rating）：**1500**。
