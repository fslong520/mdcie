# 元音统计

给定一个仅由大小写英文字母组成的字符串，请统计其中元音字母（a、e、i、o、u，大小写均算）的个数。

【输入格式】一行字符串，长度不超过 1000，仅含大小写英文字母。

【输出格式】一个整数，表示该字符串中元音字母的个数。

【样例输入 1】
```
AbcdeE
```
【样例输出 1】
```
3
```
【样例输入 2】
```
xyz
```
【样例输出 2】
```
0
```
【数据范围】1 ≤ 字符串长度 ≤ 1000。

#### 知识点与难度

本题涉及知识点：**字符数组、计数**，难度（CF Rating）：**1400**。
