# 密文传送

小明收到一条密文（仅包含英文字母），已知加密规则：每个字母向后移动 k 位（循环，z 后回到 a，Z 后回到 A），非字母字符不变。请编写程序加密。
【输入格式】第一行一个字符串 s；第二行一个整数 k。
【输出格式】加密后的字符串。
【样例输入 1】
```
xyz
3
```
【样例输出 1】
```
abc
```
【样例输入 2】
```
Hello, World!
5
```
【样例输出 2】
```
Mjqqt, Btwqi!
```
【数据范围】字符串长度 ≤ 1000，1 ≤ k ≤ 1000。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1500**。
