# 矩阵翻转

给定一个 n×n 的字符矩阵，请将其左右翻转后输出。
【输入格式】第一行一个整数 n；接下来 n 行每行 n 个字符。
【输出格式】n 行，每行翻转后的字符串。
【样例输入 1】
```
3
abc
def
ghi
```
【样例输出 1】
```
cba
fed
ihg
```
【数据范围】1 ≤ n ≤ 1000。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1500**。
