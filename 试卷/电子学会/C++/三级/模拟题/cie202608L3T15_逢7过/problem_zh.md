# 逢7过

报数游戏：从 1 开始依次报数，若当前数**是 7 的倍数**或**含有数字 7**，则跳过不报。求报出的第 n 个数。

例如：1、2、3、4、5、6、8、9、10、11、12、13、15、16、18……（7、14、17 被跳过）。

【输入格式】一个整数 n。
【输出格式】一个整数，表示报出的第 n 个数。
【样例输入 1】
```
7
```
【样例输出 1】
```
8
```
【样例输入 2】
```
15
```
【样例输出 2】
```
18
```
【数据范围】1 ≤ n ≤ 10000。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1400**。
