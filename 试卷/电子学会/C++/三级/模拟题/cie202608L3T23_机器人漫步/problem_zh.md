# 机器人漫步

一个机器人从点 (0, 0) 出发。给出一串长度为 n 的移动指令，每个字符表示向一个方向移动一个单位：`U` 向上（y 加 1），`D` 向下（y 减 1），`L` 向左（x 减 1），`R` 向右（x 加 1）。请统计机器人经过的不同格子的数量（起点 (0, 0) 也计为一个格子）。若多次经过同一格子，只计一次。

【输入格式】第一行一个整数 n。第二行一个长度为 n 的字符串，仅由 `U`、`D`、`L`、`R` 组成。
【输出格式】一个整数，表示经过的不同格子数。
【样例输入 1】
```
4
UUDR
```
【样例输出 1】
```
4
```
【样例说明】依次到达 (0,0)→(0,1)→(0,2)→(0,1)→(1,1)，不同格子为 (0,0)、(0,1)、(0,2)、(1,1)，共 4 个。
【样例输入 2】
```
3
LRL
```
【样例输出 2】
```
2
```
【样例说明】(0,0)→(−1,0)→(0,0)→(−1,0)，不同的格子只有 (0,0) 和 (−1,0)。
【样例输入 3】
```
5
UUULL
```
【样例输出 3】
```
6
```
【数据范围】1 ≤ n ≤ 1000，坐标绝对值不超过 n。

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1400**。
