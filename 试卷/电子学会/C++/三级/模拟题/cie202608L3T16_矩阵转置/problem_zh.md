# 矩阵转置

给定一个 n 行 m 列的整数矩阵，输出它的转置矩阵（即把第 i 行第 j 列的元素放到第 j 行第 i 列，行列互换）。

【输入格式】第一行两个整数 n 和 m。接下来 n 行，每行 m 个整数。
【输出格式】m 行，每行 n 个整数，表示转置后的矩阵，相邻元素用一个空格分隔。
【样例输入 1】
```
2 3
1 2 3
4 5 6
```
【样例输出 1】
```
1 4
2 5
3 6
```
【数据范围】1 ≤ n, m ≤ 100，矩阵元素 ≤ 10⁶。

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1400**。
