# 数对之和

给定两个正整数 n 和 k，请输出所有满足 1 ≤ a < b ≤ n 且 a + b = k 的整数对 (a, b)。每对占一行，先按 a 从小到大输出；若不存在则输出 none。

【输入格式】第一行两个整数 n、k。

【输出格式】多行，每行两个整数 a b 表示一组数对，或输出 none。

【样例输入 1】
```
5 7
```
【样例输出 1】
```
2 5
3 4
```
【样例输入 2】
```
3 10
```
【样例输出 2】
```
none
```
【数据范围】1 ≤ n ≤ 1000，1 ≤ k ≤ 2000。

#### 知识点与难度

本题涉及知识点：**枚举、数对**，难度（CF Rating）：**1600**。
