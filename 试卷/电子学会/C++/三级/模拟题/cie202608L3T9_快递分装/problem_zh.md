# 快递分装

快递站有 n 个包裹依次排列，重量分别为 w₁, w₂, …, wₙ。有一辆货车，每次最多装重量 W。按顺序装车，若当前包裹放进去后总重超过 W，则换下一辆新车，当前包裹仍装在新车上。问最少需要多少辆车。
【输入格式】第一行两个整数 n、W；第二行 n 个整数 wᵢ。
【输出格式】一个整数，表示最少车数。
【样例输入 1】
```
5 5
2 3 1 4 2
```
【样例输出 1】
```
3
```
【样例输入 2】
```
3 10
3 4 5
```
【样例输出 2】
```
1
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ wᵢ ≤ W ≤ 10⁹。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1400**。
