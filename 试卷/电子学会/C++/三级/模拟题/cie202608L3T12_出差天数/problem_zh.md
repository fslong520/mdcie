# 出差天数

输入一个日期（年-月-日）和一个正整数 d，计算 d 天后的日期。注意闰年（能被 400 整除，或能被 4 整除但不能被 100 整除）。
【输入格式】第一行三个整数 y、m、d，表示当前日期；第二行一个整数 k。
【输出格式】一行三个整数，表示 k 天后的年、月、日，用空格分隔。
【样例输入 1】
```
2026 2 27
3
```
【样例输出 1】
```
2026 3 2
```
【样例输入 2】
```
2025 12 30
5
```
【样例输出 2】
```
2026 1 4
```
【数据范围】1 ≤ y ≤ 3000，1 ≤ m ≤ 12，1 ≤ d ≤ 31，1 ≤ k ≤ 10000。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1600**。
