# 红绿灯等待

放学路上有一处红绿灯，灯按 "**绿灯 g 秒 → 红灯 r 秒**" 不断循环，且第 0 秒恰好是绿灯亮起的时刻。

小码从家出发去学校，出发时是第 0 秒，到达路口需要 pos 秒（即到达路口时是第 pos 秒）。若到达时是绿灯，他立刻通过；若是红灯，必须原地等到下一次绿灯亮起才能通过。

请你计算小码从出发到通过路口总共需要多少秒。

**输入格式**

一行三个整数 g、r、pos，用空格隔开：g 为绿灯时长，r 为红灯时长，pos 为到达路口所需秒数。

**输出格式**

一个整数，即从出发到通过路口的总秒数。

**样例输入 1**

```
5 3 4
```

**样例输出 1**

```
4
```

**样例说明 1**

一个周期为 8 秒，其中第 0~4 秒是绿灯、第 5~7 秒是红灯。到达时是第 4 秒（4 % 8 = 4 < 5），仍是绿灯，直接通过，总共 4 秒。

**样例输入 2**

```
10 3 10
```

**样例输出 2**

```
13
```

**样例说明 2**

周期为 13 秒，10 % 13 = 10，第 10 秒处于红灯（10 ≥ 10），需再等 13 − 10 = 3 秒变绿，总共 10 + 3 = 13 秒。

**样例输入 3**

```
7 3 1000000000
```

**样例输出 3**

```
1000000000
```

**样例说明 3**

周期为 10 秒（绿灯 0~6 秒、红灯 7~9 秒），1000000000 % 10 = 0，恰逢绿灯亮起，直接通过。

**数据范围**

1 ≤ g, r ≤ 10⁵；1 ≤ pos ≤ 10⁹。

**提示**

pos 很大，若逐秒模拟会超时，应利用周期的性质直接计算。
