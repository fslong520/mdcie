# 回文判断

回文是指正读和反读都相同的字符串，例如 "abcba"，"aa"，"a" 都是回文。给定一个字符串 s（仅含小写字母），判断它是否是回文，若是输出 YES，否则输出 NO。

【输入格式】一行字符串 s。
【输出格式】YES 或 NO。
【样例输入 1】
```
abcba
```
【样例输出 1】
```
YES
```
【样例输入 2】
```
hello
```
【样例输出 2】
```
NO
```
【数据范围】1 ≤ |s| ≤ 100，字符串仅含小写字母。

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1300**。
