### 第 23 题 快递分装 ★★（30 分）

**【题目描述】**

快递站有 n 个包裹依次排列，重量分别为 w₁, w₂, …, wₙ。有一辆货车，每次最多装重量 W。按顺序装车，若当前包裹放进去后总重超过 W，则换下一辆新车，当前包裹仍装在新车上。问最少需要多少辆车。
【输入格式】第一行两个整数 n、W；第二行 n 个整数 wᵢ。
【输出格式】一个整数，表示最少车数。
【样例输入 1】
```
5 5
2 3 1 4 2
```
【样例输出 1】
```
3
```
【样例输入 2】
```
3 10
3 4 5
```
【样例输出 2】
```
1
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ wᵢ ≤ W ≤ 10⁹。

**【参考程序】**

```cpp
#include <iostream>
using namespace std;

typedef long long ll;

int main()
{
    int n, ans = 1;
    ll W, cur = 0, w;
    cin >> n >> W;
    for (int i = 0; i < n; i++)
    {
        cin >> w;
        if (cur + w <= W) cur += w;
        else { ans++; cur = w; }
    }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 模拟顺序装车：当前车已经装总重 cur，若 cur+wᵢ ≤ W 则装（cur+=wᵢ），否则新车计数+1 且 cur=wᵢ。初始车数=1。

### 第 24 题 密文传送 ★★（30 分）

**【题目描述】**

小明收到一条密文（仅包含英文字母），已知加密规则：每个字母向后移动 k 位（循环，z 后回到 a，Z 后回到 A），非字母字符不变。请编写程序解密。
【输入格式】第一行一个字符串 s；第二行一个整数 k。
【输出格式】解密后的字符串。
【样例输入 1】
```
xyz
3
```
【样例输出 1】
```
abc
```
【样例输入 2】
```
Hello, World!
5
```
【样例输出 2】
```
Mjqqt, Btwqi!
```
【数据范围】字符串长度 ≤ 1000，1 ≤ k ≤ 1000。

**【参考程序】**

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string s;
    int k;
    getline(cin, s);
    cin >> k;
    for (int i = 0; i < s.size(); i++)
    {
        char c = s[i];
        if (c >= 'A' && c <= 'Z')
            c = (c - 'A' + k) % 26 + 'A';
        else if (c >= 'a' && c <= 'z')
            c = (c - 'a' + k) % 26 + 'a';
        cout << c;
    }
    cout << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 遍历字符串，对大写字母 c = (c - 'A' + k) % 26 + 'A'，小写字母同理，非字母不变。
