# 小木棍搭三角

小明在小区里收集了一堆小木棍，编号为 1、2、……、n，即长度正好为 1、2、……、n。他想从中挑三根小木棍搭成一个三角形。请统计：有多少种挑法能组成三角形（三根长度分别为 a、b、c，满足 a ≤ b ≤ c，且 a + b > c）。

【输入格式】一个整数 n。

【输出格式】一个整数，表示能组成三角形的方案数。

【样例输入 1】
```
5
```
【样例输出 1】
```
3
```
【样例输入 2】
```
10
```
【样例输出 2】
```
50
```
【数据范围】1 ≤ n ≤ 1000。

#### 知识点与难度

本题涉及知识点：**枚举、三角形**，难度（CF Rating）：**1600**。
