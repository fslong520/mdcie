# 击鼓传花

n 个小朋友围成一圈，编号 1 到 n，从 1 号开始按编号顺序报数，报到 m 的小朋友出列表演节目；他的下一位小朋友从 1 重新开始报数。依次进行，直到所有小朋友都出列。请输出出列顺序。

【输入格式】一行两个整数 n 和 m。
【输出格式】一行 n 个整数，表示出列顺序，相邻数用一个空格分隔。
【样例输入 1】
```
5 3
```
【样例输出 1】
```
3 1 5 2 4
```
【样例说明】1 报 1、2 报 2、3 报 3 出列；4 报 1、5 报 2、1 报 3 出列；依此类推。
【样例输入 2】
```
1 1
```
【样例输出 2】
```
1
```
【数据范围】1 ≤ n ≤ 1000，1 ≤ m ≤ 1000。
