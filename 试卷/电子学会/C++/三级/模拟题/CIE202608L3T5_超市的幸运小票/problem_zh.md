# 超市的幸运小票

小区新开的超市搞抽奖活动，每张小票上都印着小票号。老板说，如果这个小票号很"特别"——它自己乘自己得到的结果，末尾正好还是它自己，就能抽奖。例如 5×5=25，末尾是 5，5 是幸运号；25×25=625，末尾是 25，25 也是幸运号。请输出 1 到 n 之间所有幸运号。

【输入格式】一个整数 n。

【输出格式】每行一个幸运号，从小到大输出。

【样例输入 1】
```
100
```
【样例输出 1】
```
1
5
6
25
76
```
【样例输入 2】
```
10
```
【样例输出 2】
```
1
5
6
```
【数据范围】1 ≤ n ≤ 1000000。

#### 知识点与难度

本题涉及知识点：**枚举、自守数**，难度（CF Rating）：**1500**。
