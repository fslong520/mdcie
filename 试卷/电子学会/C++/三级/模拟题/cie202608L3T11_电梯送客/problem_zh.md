# 电梯送客

电梯从 1 楼出发，按顺序送 n 位乘客到各自的目标楼层。每次移动一层计 1 单位。求送完所有乘客后电梯总共移动了多少层。
【输入格式】第一行一个整数 n；第二行 n 个整数，表示乘客的目标楼层。
【输出格式】一个整数，表示总移动层数。
【样例输入 1】
```
3
3 5 2
```
【样例输出 1】
```
7
```
【样例输入 2】
```
5
1 1 1 1 1
```
【样例输出 2】
```
0
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ 楼层 ≤ 100000。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1400**。
