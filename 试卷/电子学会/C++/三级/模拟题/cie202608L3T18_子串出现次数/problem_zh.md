# 子串出现次数

给定文本串 s 和模式串 t，统计 t 在 s 中的出现次数。每次找到一处出现后，从该处右侧（即跳过整个 t）继续查找。可以使用 C++ 内置的 strstr 函数。

【输入格式】第一行文本串 s。第二行模式串 t。均为小写字母，s 长度不超过 1000，t 长度不超过 100。
【输出格式】一个整数，表示出现次数。
【样例输入 1】
```
ababab
aba
```
【样例输出 1】
```
1
```
【样例说明】aba 在位置 1 出现一次，跳过后剩余 bab 中不再出现。
【样例输入 2】
```
aaaa
aa
```
【样例输出 2】
```
2
```
【数据范围】s 长度 ≤ 1000，t 长度 ≤ 100。
