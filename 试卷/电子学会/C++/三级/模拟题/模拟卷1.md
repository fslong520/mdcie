### 第 1 题 元音统计 ★★（30 分）

**【题目描述】**

给定一个仅由大小写英文字母组成的字符串，请统计其中元音字母（a、e、i、o、u，大小写均算）的个数。

**【输入格式】**

一行字符串，长度不超过 1000，仅含大小写英文字母。

**【输出格式】**

一个整数，表示该字符串中元音字母的个数。

**【样例输入 1】**

```
AbcdeE
```

**【样例输出 1】**

```
3
```

**【样例输入 2】**

```
xyz
```

**【样例输出 2】**

```
0
```

**【数据范围】**

字符串长度 len 满足 1 ≤ len ≤ 1000。

---

### 第 2 题 数对之和 ★★★（30 分）

**【题目描述】**

给定两个正整数 n 和 k，请输出所有满足 1 ≤ a < b ≤ n 且 a + b = k 的整数对 (a, b)。每对占一行，先按 a 从小到大输出；若不存在满足条件的数对，则输出 none。

**【输入格式】**

一行两个正整数 n 和 k，用空格分隔。

**【输出格式】**

若干行，每行两个整数 a、b，表示满足条件的数对，按 a 从小到大输出；若无满足条件的数对，输出 none。

**【样例输入 1】**

```
6 7
```

**【样例输出 1】**

```
1 6
2 5
3 4
```

**【样例输入 2】**

```
3 10
```

**【样例输出 2】**

```
none
```

**【数据范围】**

2 ≤ n ≤ 1000，3 ≤ k ≤ 2000。
