# 首字母整理

输入一行英文，仅由小写字母和空格组成。请把每个**单词**的第一个字母改成大写字母，其余字母保持不变，然后按原样输出这一行（空格的数量和位置都必须保持不变，包括行首、行尾和连续的空格）。

一个"单词"指一段连续的非空格字符。

**输入格式**

一行字符串，仅含小写字母和空格，长度不超过 1000。

**输出格式**

一行，整理后的字符串。

**样例输入 1**

```
hello world
```

**样例输出 1**

```
Hello World
```

**样例输入 2**

```
i am  a student
```

**样例输出 2**

```
I Am  A Student
```

**样例说明 2**

"am" 和 "a" 之间有两个空格，输出时这两个空格原样保留。

**样例输入 3**

```
abc
```

**样例输出 3**

```
Abc
```

**数据范围**

1 ≤ 字符串长度 ≤ 1000。
