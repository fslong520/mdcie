# 储物柜的密码

小区楼下小超市门口有密码储物柜，顾客存包时设一个单词当密码。柜锁是老式按键锁，上面只有 2~9 八个数字键，每个键管几个字母：2 管 abc、3 管 def、4 管 ghi、5 管 jkl、6 管 mno、7 管 pqrs、8 管 tuv、9 管 wxyz。输入一个单词（仅小写字母），输出需要在键盘上按的数字序列。

【输入格式】一行字符串，仅含小写字母。

【输出格式】一行字符串，表示对应的数字按键序列。

【样例输入 1】
```
hello
```
【样例输出 1】
```
4433555
```
【样例输入 2】
```
world
```
【样例输出 2】
```
96667773
```
【数据范围】字符串长度 ≤ 1000。

#### 知识点与难度

本题涉及知识点：**模拟、字符串、按键映射**，难度（CF Rating）：**1500**。
