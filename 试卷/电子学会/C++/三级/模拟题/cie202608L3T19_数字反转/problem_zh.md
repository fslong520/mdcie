# 数字反转

给定一个整数 n，将它各位数字反转后输出。反转后产生的前导零应舍去（如 1200 反转为 0021，输出 21）；负数反转后保留负号（如 -380 反转为 -83）。

【输入格式】一行一个整数 n。
【输出格式】一行一个整数，表示反转结果。
【样例输入 1】
```
123
```
【样例输出 1】
```
321
```
【样例输入 2】
```
-380
```
【样例输出 2】
```
-83
```
【样例输入 3】
```
1200
```
【样例输出 3】
```
21
```
【数据范围】-10⁹ ≤ n ≤ 10⁹。
#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1100**。
