# 递增数统计

一个正整数被称为**递增数**，当且仅当它从高位到低位的数字**严格递增**。
例如 135、29 都是递增数（1 < 3 < 5，2 < 9）；而 133（3 和 3 相等，不严格递增）、91（9 > 1）都不是。

给定区间 [L, R]，请统计其中递增数的个数。

**输入格式**

一行两个整数 L、R，用空格隔开。

**输出格式**

一个整数，表示 [L, R] 中递增数的个数。

**样例输入 1**

```
1 20
```

**样例输出 1**

```
17
```

**样例说明 1**

1~9 共 9 个都是递增数；两位数中 12、13、14、15、16、17、18、19 共 8 个（10、11、20 都不是——11 的两个 1 相等，不严格递增）。合计 17 个。

**样例输入 2**

```
100 200
```

**样例输出 2**

```
28
```

**样例说明 2**

百位为 1 时，十位只能取 2~8，个位再取更大的数字：123~129 有 7 个、134~139 有 6 个、145~149 有 5 个、156~159 有 4 个、167~169 有 3 个、178~179 有 2 个、189 有 1 个，合计 28 个。

**样例输入 3**

```
7 7
```

**样例输出 3**

```
1
```

**数据范围**

1 ≤ L ≤ R ≤ 100000。
