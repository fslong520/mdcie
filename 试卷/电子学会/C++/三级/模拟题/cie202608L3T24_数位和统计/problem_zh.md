# 数位和统计

一个正整数各位数字之和，等于把它每一位数字相加所得的结果。例如 123 的各位数字之和是 1 + 2 + 3 = 6。
给定三个整数 L、R、k，请统计区间 [L, R] 内各位数字之和恰好等于 k 的整数个数。

【输入格式】一行三个整数 L、R、k，满足 1 ≤ L ≤ R ≤ 100000，0 ≤ k ≤ 100。
【输出格式】一个整数，表示个数。
【样例输入 1】
```
1 10 1
```
【样例输出 1】
```
2
```
【样例说明】1 的各位和为 1；10 的各位和为 1+0=1。共 2 个。
【样例输入 2】
```
20 20 2
```
【样例输出 2】
```
1
```
【样例说明】20 的各位和为 2+0=2。
【样例输入 3】
```
1 5 3
```
【样例输出 3】
```
1
```
【数据范围】1 ≤ L ≤ R ≤ 100000，0 ≤ k ≤ 100。注意 0 的各位数字之和为 0（本题 L ≥ 1，不会出现 0）。
