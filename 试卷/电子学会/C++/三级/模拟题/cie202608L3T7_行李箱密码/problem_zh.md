# 行李箱密码

行李箱密码锁是一个环形数字转盘（0-9 循环）。给定当前密码和目标密码（均为 4 位数字，每位 0-9），每次可以顺时针或逆时针转动一格，求最少转动格数。
【输入格式】两行，每行一个 4 位数字串，分别表示当前密码和目标密码。
【输出格式】一个整数，表示最少转动格数。
【样例输入 1】
```
0000
9999
```
【样例输出 1】
```
4
```
【样例输入 2】
```
1234
1244
```
【样例输出 2】
```
1
```
【数据范围】密码始终为 4 位数字。
