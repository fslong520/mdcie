# 素数统计

素数是指大于 1 且只能被 1 和自身整除的正整数。给定一个正整数 n，统计 1 到 n 之间（含 n）有多少个素数。

【输入格式】一个整数 n。
【输出格式】一个整数，表示素数的个数。
【样例输入 1】
```
10
```
【样例输出 1】
```
4
```
【样例输入 2】
```
100
```
【样例输出 2】
```
25
```
【数据范围】1 ≤ n ≤ 10000。
