# 斐波那契数列

斐波那契数列定义如下：fib(0)=0，fib(1)=1，当 n≥2 时 fib(n)=fib(n-1)+fib(n-2)。给定 n（0≤n≤30），请用递归函数计算并输出 fib(n) 的值。

【输入格式】一个整数 n。
【输出格式】一个整数，表示 fib(n) 的值。
【样例输入 1】
```
6
```
【样例输出 1】
```
8
```
【样例输入 2】
```
10
```
【样例输出 2】
```
55
```
【数据范围】0 ≤ n ≤ 30。
