# 数字摘取

输入一行仅由小写字母和数字组成的字符串（长度不超过 1000）。请把其中**所有数字字符按原顺序摘出来**，依次拼成一个大整数，然后输出这个整数 **除以 7 的余数**。

若字符串中一个数字都没有，拼出的大整数视为 0。

**输入格式**

一行字符串，仅含小写字母和数字，长度不超过 1000。

**输出格式**

一个整数，即摘出的大整数除以 7 的余数。

**样例输入 1**

```
a1b23c
```

**样例输出 1**

```
2
```

**样例说明 1**

摘出的数字依次为 1、2、3，拼成 123，123 ÷ 7 = 17 余 4。

**样例输入 2**

```
xyz
```

**样例输出 2**

```
0
```

**样例说明 2**

没有数字，结果为 0。

**样例输入 3**

```
0009
```

**样例输出 3**

```
2
```

**样例说明 3**

摘出后为 0009，即 9，9 ÷ 7 余 2。

**数据范围**

1 ≤ 字符串长度 ≤ 1000。摘出的大整数可能有几百位，**无法用 long long 直接存下**。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1000**。
