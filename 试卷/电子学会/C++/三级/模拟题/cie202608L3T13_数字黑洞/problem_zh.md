# 数字黑洞

任取一个各位数字不全相同的三位数，将其各位数字重新排列成最大数和最小数，两数相减，重复此过程，最终会得到 495（三位数的黑洞数）。输入一个三位数 n（100≤n≤999，且各位数字不全相同），输出得到 495 所需的操作次数。若 n 本身就是 495，输出 0。

【输入格式】一个整数 n。
【输出格式】一个整数，表示操作次数。
【样例输入 1】
```
123
```
【样例输出 1】
```
5
```
【样例输入 2】
```
495
```
【样例输出 2】
```
0
```
【数据范围】100 ≤ n ≤ 999，且各位数字不全相同。

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1400**。
