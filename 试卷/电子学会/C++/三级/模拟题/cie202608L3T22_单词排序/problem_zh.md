# 单词排序

输入 n 个由小写字母组成的单词，请按字典序（字母顺序）从小到大将它们排序并输出。本题鼓励使用 C 风格字符串与 `strcmp` 函数实现。

【输入格式】第一行一个整数 n。接下来 n 行，每行一个单词，仅含小写字母，长度不超过 20。
【输出格式】按字典序从小到大输出 n 行，每行一个单词。若存在相同单词，排序后它们相邻，需输出全部（含重复）。
【样例输入 1】
```
3
banana
apple
cat
```
【样例输出 1】
```
apple
banana
cat
```
【样例输入 2】
```
2
bbb
aaa
```
【样例输出 2】
```
aaa
bbb
```
【样例输入 3】
```
4
zebra
apple
mango
apple
```
【样例输出 3】
```
apple
apple
mango
zebra
```
【样例说明】若存在相同单词，排序后它们相邻输出；本题输出每个单词（含重复）。
【数据范围】1 ≤ n ≤ 50，每个单词长度 ≤ 20，仅含小写字母。
#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1300**。
