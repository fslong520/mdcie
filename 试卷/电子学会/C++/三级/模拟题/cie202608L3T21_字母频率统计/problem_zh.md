# 字母频率统计

输入一个由小写字母组成的字符串（不含空格），请统计每个小写字母出现的最多次数，找出出现次数最多的字母并输出该字母及其出现次数。若有多个字母出现次数相同且均为最多，则输出其中字母序最小的那个。

【输入格式】一行一个字符串 s，仅由小写字母组成，长度不超过 1000。
【输出格式】一行，格式为「字母:次数」，字母为出现次数最多的字母，次数为其出现次数。
【样例输入 1】
```
aabbbcc
```
【样例输出 1】
```
b:3
```
【样例说明】a 出现 2 次，b 出现 3 次，c 出现 2 次，最多为 b。
【样例输入 2】
```
abc
```
【样例输出 2】
```
a:1
```
【样例说明】a、b、c 各出现 1 次，并列最多，取字母序最小的 a。
【样例输入 3】
```
zzzyy
```
【样例输出 3】
```
z:3
```
【数据范围】1 ≤ |s| ≤ 1000，s 仅含小写字母。

本题涉及的知识点从属于 **电子学会（CIE）3级**，难度（CF Rating）：**1200**。
