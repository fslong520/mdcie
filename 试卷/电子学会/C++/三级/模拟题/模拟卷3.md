### 第 1 题（电子学会三级模拟·返回类型截断）执行以下代码，输出结果是？（ ）

```cpp
int f() {
    return 3.9;
}
int main() {
    cout << f();
    return 0;
}
```

- A. 3
- B. 4
- C. 3.9
- D. 编译错误

**答案：A**

**解析：** 函数返回类型为 int，return 3.9 是浮点数，赋给 int 时自动截断小数部分，只保留整数部分 3。

### 第 2 题（电子学会三级模拟·递归输出顺序）执行以下代码，输出结果是？（ ）

```cpp
void f(int n) {
    if (n == 0) return;
    cout << n;
    f(n - 1);
}
int main() {
    f(3);
    return 0;
}
```

- A. 321
- B. 123
- C. 无输出
- D. 编译错误

**答案：A**

**解析：** 每次调用先输出当前 n 再递归，依次输出 3、2、1，故为 321；若先递归后输出则为 123。

### 第 3 题（电子学会三级模拟·字符数组下标修改）执行以下代码，输出结果是？（ ）

```cpp
#include <iostream>
using namespace std;
int main() {
    char s[] = "abc";
    s[0] = 'x';
    cout << s;
    return 0;
}
```

- A. xbc
- B. abc
- C. 编译错误
- D. xbx

**答案：A**

**解析：** 字符数组可用下标修改单个字符，s[0] 从 'a' 改为 'x'，数组变为 "xbc"。

### 第 4 题（电子学会三级模拟·strcmp 返回值）执行 `strcmp("abc", "abd")`，返回值是？（ ）

- A. 0
- B. 负数
- C. 正数
- D. 1

**答案：B**

**解析：** strcmp 比较两个字符串，前者小于后者（'c' < 'd'）时返回负数，故 strcmp("abc","abd") 返回负数。

### 第 5 题（电子学会三级模拟·枚举·闰年）用枚举法统计 1900~2000 之间闰年的个数（闰年：能被 4 整除且不能被 100 整除，或能被 400 整除），结果是？（ ）

- A. 25
- B. 26
- C. 24
- D. 27

**答案：A**

**解析：** 能被 4 整除的年有 1900、1904……2000 共 26 个，其中 1900 能被 100 整除且不能被 400 整除，不是闰年，需排除；2000 能被 400 整除是闰年，保留。闰年共 25 个。

### 第 6 题（电子学会三级模拟·模拟·while 计数）执行以下代码，输出结果是？（ ）

```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 1, c = 0;
    while (x < 100) {
        x *= 2;
        c++;
    }
    cout << c;
    return 0;
}
```

- A. 8
- B. 7
- C. 6
- D. 9

**答案：B**

**解析：** x 依次变为 2、4、8、16、32、64、128，经过 7 次循环后 x=128≥100 停止，c=7。

### 第 7 题（电子学会三级模拟·数学库函数 floor/ceil）执行 `cout << floor(3.7) + ceil(3.2);`，输出结果是？（ ）

- A. 6
- B. 7
- C. 6.9
- D. 7.9

**答案：B**

**解析：** floor(3.7) 向下取整得 3，ceil(3.2) 向上取整得 4，3+4=7。

### 第 9 题（电子学会三级模拟·递归·汉诺塔）执行以下递归函数，f(3) 的返回值是？（ ）

```cpp
int f(int n) {
    if (n == 1) return 1;
    return 2 * f(n - 1) + 1;
}
```

- A. 6
- B. 8
- C. 7
- D. 9

**答案：C**

**解析：** f(1)=1，f(2)=2×1+1=3，f(3)=2×3+1=7，即汉诺塔移动次数递推公式。

### 第 10 题（电子学会三级模拟·枚举·回文数）用枚举法统计 100~999 之间回文数（百位与个位相同，如 121、242）的个数，结果是？（ ）

- A. 81
- B. 100
- C. 99
- D. 90

**答案：D**

### 第 1 题 超市的幸运小票 ★★（30 分）

**【题目描述】**

小区新开的超市搞抽奖活动，每张小票上都印着小票号。老板说，如果这个小票号很"特别"——它自己乘自己得到的结果，末尾正好还是它自己，就能抽奖。例如 5×5=25，结果末尾是 5；6×6=36，末尾是 6；25×25=625，末尾是 25。像这样"平方结果末尾等于本身"的数就是幸运数。

给定最大的小票号 n，请从小到大找出 1~n 内所有幸运号。

**【输入格式】**

一个正整数 n。

**【输出格式】**

若干行，每行一个整数，表示区间内的幸运号，从小到大输出；若没有，输出 none。

**【样例输入 1】**

```
100
```

**【样例输出 1】**

```
1
5
6
25
76
```

**【样例输入 2】**

```
2
```

**【样例输出 2】**

```
1
```

**【数据范围】**

1 ≤ n ≤ 10000。

> 提示：要判断 i 是不是幸运号，先看 i 有几位数（记作 k），再检查 i×i 除以 10^k 的余数是否等于 i。例如 76 有 2 位，76×76=5776，5776 除以 100 的余数是 76，所以 76 是幸运号。

### 第 2 题 小木棍搭三角 ★★★（30 分）

**【题目描述】**

小明在小区里收集了一堆小木棍，编号为 1、2、……、n，即长度正好为 1、2、……、n。他想从中挑三根小木棍搭成一个三角形。请统计：有多少种挑法能组成三角形（三根长度分别记为 a、b、c，要求 a ≤ b ≤ c 且满足 a + b > c，这样的三根才能搭成三角形）。

**【输入格式】**

一个正整数 n。

**【输出格式】**

一个整数，表示能组成三角形的方法总数。

**【样例输入 1】**

```
3
```

**【样例输出 1】**

```
7
```

**【样例输入 2】**

```
5
```

**【样例输出 2】**

```
22
```

**【数据范围】**

3 ≤ n ≤ 100。

**【提示】**
用三重循环逐一枚举 a、b、c（a 从 1 到 n，b 从 a 到 n，c 从 b 到 n），只要满足 a + b > c 就计数加一。
