### 第 1 题 超市的幸运小票 ★★（30 分）

**【题目描述】**

小区新开的超市搞抽奖活动，每张小票上都印着小票号。老板说，如果这个小票号很"特别"——它自己乘自己得到的结果，末尾正好还是它自己，就能抽奖。例如 5×5=25，结果末尾是 5；6×6=36，末尾是 6；25×25=625，末尾是 25。像这样"平方结果末尾等于本身"的数就是幸运数。

给定最大的小票号 n，请从小到大找出 1~n 内所有幸运号。

**【输入格式】**

一个正整数 n。

**【输出格式】**

若干行，每行一个整数，表示区间内的幸运号，从小到大输出；若没有，输出 none。

**【样例输入 1】**

```
100
```

**【样例输出 1】**

```
1
5
6
25
76
```

**【样例输入 2】**

```
2
```

**【样例输出 2】**

```
1
```

**【数据范围】**

1 ≤ n ≤ 10000。

> 提示：要判断 i 是不是幸运号，先看 i 有几位数（记作 k），再检查 i×i 除以 10^k 的余数是否等于 i。例如 76 有 2 位，76×76=5776，5776 除以 100 的余数是 76，所以 76 是幸运号。

### 第 2 题 小木棍搭三角 ★★★（30 分）

**【题目描述】**

小明在小区里收集了一堆小木棍，编号为 1、2、……、n，即长度正好为 1、2、……、n。他想从中挑三根小木棍搭成一个三角形。请统计：有多少种挑法能组成三角形（三根长度分别记为 a、b、c，要求 a ≤ b ≤ c 且满足 a + b > c，这样的三根才能搭成三角形）。

**【输入格式】**

一个正整数 n。

**【输出格式】**

一个整数，表示能组成三角形的方法总数。

**【样例输入 1】**

```
3
```

**【样例输出 1】**

```
7
```

**【样例输入 2】**

```
5
```

**【样例输出 2】**

```
22
```

**【数据范围】**

3 ≤ n ≤ 100。

**【提示】**
用三重循环逐一枚举 a、b、c（a 从 1 到 n，b 从 a 到 n，c 从 b 到 n），只要满足 a + b > c 就计数加一。

### 第 23 题 电梯送客 ★★（30 分）

**【题目描述】**

电梯从 1 楼出发，按顺序送 n 位乘客到各自的目标楼层。每次移动一层计 1 单位。求送完所有乘客后电梯总共移动了多少层。
【输入格式】第一行一个整数 n；第二行 n 个整数，表示乘客的目标楼层。
【输出格式】一个整数，表示总移动层数。
【样例输入 1】
```
3
3 5 2
```
【样例输出 1】
```
7
```
【样例输入 2】
```
5
1 1 1 1 1
```
【样例输出 2】
```
0
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ 楼层 ≤ 100000。

**【参考程序】**

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int main()
{
    int n, cur = 1;
    long long ans = 0;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        int f;
        cin >> f;
        ans += abs(cur - f);
        cur = f;
    }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 从 1 楼开始，对每个目标楼层，累加 |当前楼层 - 目标楼层|，然后更新当前楼层为目标楼层。

### 第 24 题 出差天数 ★★★（30 分）

**【题目描述】**

输入一个日期（年-月-日）和一个正整数 d，计算 d 天后的日期。注意闰年（能被 400 整除，或能被 4 整除但不能被 100 整除）。
【输入格式】第一行三个整数 y、m、d，表示当前日期；第二行一个整数 k。
【输出格式】一行三个整数，表示 k 天后的年、月、日，用空格分隔。
【样例输入 1】
```
2026 2 27
3
```
【样例输出 1】
```
2026 3 2
```
【样例输入 2】
```
2025 12 30
5
```
【样例输出 2】
```
2026 1 4
```
【数据范围】1 ≤ y ≤ 3000，1 ≤ m ≤ 12，1 ≤ d ≤ 31，1 ≤ k ≤ 10000。

**【参考程序】**

```cpp
#include <iostream>
using namespace std;

int days[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31};

bool isLeap(int y)
{
    return y % 400 == 0 || (y % 4 == 0 && y % 100 != 0);
}

int main()
{
    int y, m, d, k;
    cin >> y >> m >> d >> k;
    d += k;
    while (true)
    {
        int dm = days[m];
        if (m == 2 && isLeap(y)) dm = 29;
        if (d <= dm) break;
        d -= dm;
        m++;
        if (m > 12) { m = 1; y++; }
    }
    cout << y << " " << m << " " << d << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 打表每月天数（闰年 2 月 29 天），先加 k 天到当前日，然后循环减月天数进位：若当前日 > 该月天数，则日-该月天数、月+1，月>12 则年+1 月=1。
