### 第2题 vector操作front

```cpp
vector<int> a = {2, 4, 6, 8};
a.push_back(10);
cout << a.front();
```

### 第4题 栈的操作

以下代码的输出是？（ ）

```cpp
stack<int> st;
for (int i=1; i<=3; i++) st.push(i);
while (!st.empty()) {
    cout << st.top() << " ";
    st.pop();
}
```

- A. 1 2 3
- B. 3 2 1
- C. 1 1 1
- D. 无输出

**答案：B**

**解析：** for循环依次把1、2、3压入栈st，此时栈为：1 2 3， 栈底 1，栈顶 3。
栈的特点是后进先出，在while循环中，依次弹出栈顶：3 2 1，输出并删除栈顶元素。

### 第9题 枚举乘积对

以下代码的功能是？（ ）

```cpp
for (int a = 1; a <= 9; a++) {
    for (int b = 1; b <= 9; b++) {
        if (a*b == 24) {
            cout << a << " " << b << endl;
        }
    }
}
```

- A. 找出乘积为 24 的整数对
- B. 计算 24 的因数
- C. 打印乘法表
- D. A 和 B 均正确

**答案：A**

**解析：** 程序枚举 1 ~ 9 的数字，根据条件：a*b == 24，可知找出乘积为 24 的整数对。
24 的因数并不全在1到9之间，程序并不能枚举24的所有因数。

### 第10题 substr截取

s.substr(2, 3) 表示？（ ）

- A. 用索引2开始取3个字符
- B. 从索引3开始取2个字符
- C. 从索引2开始取到索引3
- D. 从第2个字符开始到第3个字符

**答案：A**

**解析：** substr(2, 3) 中：
第一个参数 2 是起始位置（索引从 0 开始）
第二个参数 3 是要提取的子串长度
所以是：从索引 2 开始，取 3 个字符。

### 第21题 排队名单（30分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L3TEST1>

**题目描述**

火车站的售票大厅中有 n 个售票窗口（窗口编号为1,...,n），春运大潮来了，今天窗口还没有开放人们就已经陆陆续续涌进来。
现在按顺序告诉你涌进来的 m 个人的目标窗口和排队编号（为 1,...,m)，请你输出售票前各窗口的排队情况。

**输入格式**

第一行两个正整数 n、m。
之后 m 个整数 ai，表示第 i 个进来的人到 ai 窗口排队。

**输出格式**

n 行，每行若干整数，分别第 i 个窗口前，从前到后排队人的编号，如果该窗口没人排，请输出 nobody。

**样例输入 1**

```
3 7
2 3 1 3 1 1 1
```

**样例输出 1**

```
3 5 6 7
1
2 4
```

**样例输入 2**

```
7 4
1 3 3 6
```

**样例输出 2**

```
1
nobody
2 3
nobody
nobody
4
nobody
```

**数据范围**

1≤n≤10^4，1≤m≤10^7，1≤ai≤n。

**参考程序**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n,m;
    cin >> n >> m;
    vector<vector<int>> a(n);
    for(int i=0; i<m; i++) {
        int k;
        cin >> k;
        a[k-1].push_back(i+1);
    }
    for(int i=0; i<n; i++) {
        if(a[i].empty())
            cout << "nobody" << endl;
        else {
            for(int j=0; j<a[i].size(); j++)
                cout << a[i][j] << " " ;
            cout << endl;
        }
    }
    return 0;
}
```

### 第22题 颁奖典礼（30分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L3TEST2>

**题目描述**

n 个学生参加颁奖典礼，学号为 1 到 n。学生根据比赛排名上台领奖。已知学号为 i 的学生是第 ai 个上去领奖的。请输出学生上台领奖的学号顺序。

**输入格式**

第一行，单个整数 n。
第二行，n 个整数a1,a2,...,an。

**输出格式**

n 个整数，表示学生上台的顺序。

**样例输入 1**

```
3
3 1 2
```

**样例输出 1**

```
2 3 1
```

**数据范围**

对于100%的数据，1≤n≤100,000，1≤ai≤n。

**参考程序**

```cpp
#include <bits/stdc++.h>
using namespace std;
bool compare(pair<int,int> a,pair<int,int> b) { //排序比较函数
    return a.second < b.second;
}
int main() {
    int n, k;
    cin >> n;
    vector<pair<int,int>> a;  //学号和领奖顺序数组
    for(int i=0; i<n; i++) {
        cin >> k;
        a.push_back({i+1, k});
    }
    sort(a.begin(), a.end(), compare); //按领奖顺序排序
    for(int i=0; i<n; i++) {
        cout << a[i].first << " ";  //输出学号
    }
    return 0;
}
```
