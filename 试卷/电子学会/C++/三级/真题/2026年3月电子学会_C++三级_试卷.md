### 第21题 知识竞赛（30分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L3A>

**题目描述**

在一场知识竞赛中，选手答对一题得 1 分，答错不得分且要倒扣 1 分，但扣分不能让分数小于 0。
给定一个由 Y 及 N 构成的字符序列，答对记为 Y，答错记为 N。选手一开始从 0 分开始，请输出选手最后的得分。

**输入格式**

单个字符序列：保证仅由字母 Y 及 N 组成。

**输出格式**

单个整数，表示最终得分。

**样例输入**

```
YNNYYY
```

**样例输出**

```
3
```

**数据范围**

设 n 表示字符序列的长度，1≤n≤100,000。

**参考程序**

```cpp
#include<iostream>
#include<string>
using namespace std;
int main() {
    string s;
    cin >> s;
    int a = 0;
    for(char c:s) {
        if(c == 'Y')
            a++;
        else if(c == 'N' && a > 0)
            a--;
    }
    cout << a << endl;
    return 0;
}
```

### 第22题 上升三元组（30分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L3B>

**题目描述**

当 0≤a≤b≤c 时，称 a、b、c 为上升三元组。
给定一个整数 n，请输出所有三数之和等于 n 的上升三元组。
若有多个三元组满足条件，则首先输出第一项较小的三元组，若第一项相等，则先输出第二项较小的三元组。

**输入格式**

单个整数表示 n。

**输出格式**

若干行，每行三个自然数，中间用一个空格分开。

**样例输入 1**

```
2
```

**样例输出 1**

```
0 0 2
0 1 1
```

**样例输入 2**

```
5
```

**样例输出 2**

```
0 0 5
0 1 4
0 2 3
1 1 3
1 2 2
```

**数据范围**

0≤n≤2000。

**参考程序**

```cpp
#include<iostream>
using namespace std;
int main() {
    int n,a,b,c;
    cin>>n;
    for(int i=0; i<=n; i++) {
        for(int j=i; j<=n; j++) {
            for(int k=j; k<=n; k++) {
                if(i+j+k == n && i<=j && j<=k) {
                    cout<<i<<" "<<j<<" "<<k<<endl;
                }
            }
        }
    }
    return 0;
}
```
