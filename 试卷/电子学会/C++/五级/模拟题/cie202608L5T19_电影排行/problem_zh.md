# 电影排行

电影节收到 n 部电影的参评信息，每部电影有名称、评分（0~100 的整数）和投票数。排行规则：

1. 评分高的排前面；
2. 评分相同的，投票数多的排前面；
3. 评分和投票数都相同的，按名称字典序升序排列。

输出排行榜前 k 部电影的名称。

【输入格式】第一行两个整数 n 和 k。接下来 n 行，每行为：电影名称（不含空格，长度不超过 20）、评分、投票数。
【输出格式】共 k 行，每行一个电影名称，按排行顺序输出。
【样例输入 1】
```
4 2
A 90 100
B 90 200
C 95 1
D 85 999
```
【样例输出 1】
```
C
B
```
【数据范围】1 ≤ k ≤ n ≤ 10⁵，0 ≤ 评分 ≤ 100，0 ≤ 投票数 ≤ 10⁹。
#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
