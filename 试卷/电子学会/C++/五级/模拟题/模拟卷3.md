### 第 1 题 配对计数 ★★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/cie202608L5T5>

**【题目描述】**

给定一个严格升序的正整数数组 a 和一个目标值 t。求满足 `a[i] + a[j] = t`（其中 i < j）的数对个数。

**【输入格式】**

第一行，两个整数 n、t。
第二行，n 个严格升序的整数，表示 a₁, a₂, …, aₙ。

**【输出格式】**

输出一个整数，表示满足条件的数对个数。

**【样例输入 1】**

```
5 10
1 2 3 7 8
```

**【样例输出 1】**

```
2
```

**【样例输入 2】**

```
4 6
1 2 4 5
```

**【样例输出 2】**

```
2
```

**【数据范围】**

1 ≤ n ≤ 10⁵，1 ≤ t ≤ 2×10⁹，1 ≤ aᵢ ≤ 10⁹，所有输入均为整数，数组严格升序。

### 第 2 题 成绩统计 ★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/cie202608L5T6>

**【题目描述】**

n 个学生参加考试，每人考语文、数学、英语三科，每科满分 100 分。现需按以下规则排名：

1. 总分高的排名靠前；
2. 总分相同，语文成绩高的靠前；
3. 语文也相同，学号小的靠前。

请按排名顺序输出每个学生的学号和总分。

**【输入格式】**

第一行，一个整数 n。
接下来 n 行，每行 4 个整数：学号、语文、数学、英语。

**【输出格式】**

按排名顺序，每行输出"学号 总分"。

**【样例输入 1】**

```
3
1 90 80 70
2 100 70 70
3 80 90 80
```

**【样例输出 1】**

```
3 250
2 240
1 240
```

**【样例输入 2】**

```
2
5 60 60 60
6 70 50 60
```

**【样例输出 2】**

```
6 180
5 180
```

**【数据范围】**

1 ≤ n ≤ 10⁵，学号互不相同且为 1 到 n 的整数，0 ≤ 各科成绩 ≤ 100。
