### 第 23 题 正方形边长 ★★★（30 分）

**【题目描述】**

给定一个面积为 n 的正方形，求其边长的整数部分（即 ⌊√n⌋）。请用二分法实现。
【输入格式】一个整数 n。
【输出格式】一个整数，表示边长的整数部分。
【样例输入 1】
```
8
```
【样例输出 1】
```
2
```
【样例输入 2】
```
16
```
【样例输出 2】
```
4
```
【数据范围】0 ≤ n ≤ 10¹⁸。

**【参考程序】**

```cpp
#include <iostream>
using namespace std;

typedef long long ll;

int main()
{
    ll n;
    cin >> n;
    ll l = 0, r = n, ans = 0;
    while (l <= r)
    {
        ll mid = l + (r - l) / 2;
        if (mid <= n / mid) { ans = mid; l = mid + 1; }
        else r = mid - 1;
    }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 二分查找 0~n 中最大的 mid 使得 mid²≤n。注意用 long long 防溢出。

### 第 24 题 投票统计 ★★★（30 分）

**【题目描述】**

班级选举投票，有 n 张选票，每张选票上写着一个候选人的名字。请统计每位候选人的得票数，按得票数从高到低输出，得票相同时按名字字典序升序输出。
【输入格式】第一行一个整数 n；接下来 n 行，每行一个字符串表示候选人名字。
【输出格式】每行"名字 票数"，按规则排序。
【样例输入 1】
```
5
Alice
Bob
Alice
Charlie
Bob
```
【样例输出 1】
```
Alice 2
Bob 2
Charlie 1
```
【数据范围】1 ≤ n ≤ 100000，名字长度 ≤ 20。

**【参考程序】**

```cpp
#include <iostream>
#include <map>
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

int main()
{
    int n;
    string s;
    map<string,int> mp;
    cin >> n;
    for (int i = 0; i < n; i++) { cin >> s; mp[s]++; }
    vector<pair<int,string>> v;
    for (auto &p : mp) v.push_back({-p.second, p.first});
    sort(v.begin(), v.end());
    for (auto &p : v) cout << p.second << " " << -p.first << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** map 统计票数，将 map 中的 pair 转入 vector，按票数降序、名字字典序升序排序后输出。
