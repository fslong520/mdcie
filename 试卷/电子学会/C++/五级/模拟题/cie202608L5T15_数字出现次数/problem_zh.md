# 数字出现次数

给定 n 个整数，统计每个数出现的次数，按数值从小到大输出"数值 次数"。

【输入格式】第一行一个整数 n。第二行 n 个整数。
【输出格式】若干行，每行两个整数，表示数值和它出现的次数，按数值升序排列。
【样例输入 1】
```
7
3 1 3 2 1 3 1
```
【样例输出 1】
```
1 3
2 1
3 3
```
【数据范围】1 ≤ n ≤ 100000，每个数 ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
