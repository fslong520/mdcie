# 正方形边长

给定一个面积为 n 的正方形，求其边长的整数部分（即 ⌊√n⌋）。请用二分法实现。
【输入格式】一个整数 n。
【输出格式】一个整数，表示边长的整数部分。
【样例输入 1】
```
8
```
【样例输出 1】
```
2
```
【样例输入 2】
```
16
```
【样例输出 2】
```
4
```
【数据范围】0 ≤ n ≤ 10¹⁸。
