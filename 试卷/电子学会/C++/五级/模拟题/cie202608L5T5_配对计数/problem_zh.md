# 配对计数

#### 题目描述

给定一个严格升序的正整数数组 a 和一个目标值 t。求满足 `a[i] + a[j] = t`（其中 i < j）的数对个数。

#### 输入格式

第一行，两个整数 n、t。
第二行，n 个严格升序的整数，表示 a₁, a₂, …, aₙ。

#### 输出格式

输出一个整数，表示满足条件的数对个数。

#### 样例输入 #1

```
5 10
1 2 3 7 8
```

#### 样例输出 #1

```
2
```

#### 样例输入 #2

```
4 6
1 2 4 5
```

#### 样例输出 #2

```
2
```

#### 数据范围

1 ≤ n ≤ 10⁵，1 ≤ t ≤ 2×10⁹，1 ≤ aᵢ ≤ 10⁹，所有输入均为整数，数组严格升序。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1500**。
