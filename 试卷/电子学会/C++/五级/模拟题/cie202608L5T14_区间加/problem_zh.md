# 区间加

有一个长度为 n 的数组，初始所有元素均为 0。进行 m 次操作，每次操作将区间 [l, r] 内的所有元素加上 x，请输出最终数组的所有元素。

【输入格式】第一行两个整数 n 和 m。接下来 m 行，每行三个整数 l, r, x。
【输出格式】一行 n 个整数，表示最终数组，相邻元素用一个空格分隔。
【样例输入 1】
```
5 2
1 3 2
4 5 1
```
【样例输出 1】
```
2 2 2 1 1
```
【样例解释】初始 [0,0,0,0,0]；操作1 [1,3]+2 → [2,2,2,0,0]；操作2 [4,5]+1 → [2,2,2,1,1]。
【数据范围】1 ≤ n, m ≤ 100000，1 ≤ x ≤ 10⁹。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
