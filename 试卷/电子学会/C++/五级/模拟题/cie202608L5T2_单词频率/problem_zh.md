# 单词频率

#### 题目描述

输入 n 个小写英文单词，统计每个单词出现的次数。按出现次数从多到少输出；出现次数相同时，按字典序从小到大输出。每行输出一个单词及其出现次数，中间用空格隔开。

#### 输入格式

第一行，一个整数 n。
第二行，n 个单词，用空格分隔。

#### 输出格式

若干行，每行"单词 出现次数"。

#### 样例输入 #1

```
6
apple banana apple cat banana apple
```

#### 样例输出 #1

```
apple 3
banana 2
cat 1
```

#### 样例输入 #2

```
4
a a b a
```

#### 样例输出 #2

```
a 3
b 1
```

#### 数据范围

1 ≤ n ≤ 10⁵，单词仅由小写英文字母组成，长度 ≤ 20。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1200**。
