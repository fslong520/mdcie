# 图书管理器

阅览室有一个空书架，管理器依次接收 n 条操作：

- `1 x`：编号为 x 的书放上架；若该书已在架上，忽略本操作。
- `2 x`：编号为 x 的书被借走下架；若架上没有该书，忽略本操作。
- `3`：查询当前书架上编号最小的书，输出其编号；若书架为空，输出 -1。

请输出所有查询操作的结果。

【输入格式】第一行一个整数 n。接下来 n 行，每行是一条操作：`1 x`、`2 x` 或 `3`。
【输出格式】若干行，按顺序输出每条 3 号操作的结果。
【样例输入】
```
6
1 5
1 3
3
2 3
1 1
3
```
【样例输出】
```
3
1
```
【样例说明】放入 5、3 后查询得最小编号 3；借走 3、放入 1 后查询得最小编号 1。
【数据范围】1 ≤ n ≤ 10⁵，1 ≤ x ≤ 10⁹。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1500**。
