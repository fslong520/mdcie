# 生产计划

工厂接到一笔 m 个零件的订单。厂里有 n 台机器，第 i 台机器每天能生产 aᵢ 个零件，且每台机器从投产起累计最多只能生产 bᵢ 个零件（达到 bᵢ 后报废停产）。所有机器从第 1 天起同时开工。问至少需要多少天，才能使累计产量不少于 m？若永远无法完成订单，输出 -1。

【输入格式】第一行两个整数 n 和 m。第二行 2n 个整数 a₁ b₁ a₂ b₂ … aₙ bₙ。
【输出格式】一行一个整数，表示最少天数；无解输出 -1。
【样例输入 1】
```
2 10
2 5 3 100
```
【样例输出 1】
```
2
```
【样例说明】第 1 天机器 1 产 2、机器 2 产 3；第 2 天机器 1 再产 2、机器 2 再产 3，累计 2×2+3×2=10，恰好在第 2 天完成。
【样例输入 2】
```
1 100
5 10
```
【样例输出 2】
```
-1
```
【数据范围】1 ≤ n ≤ 10⁵，1 ≤ m ≤ 10¹⁸，1 ≤ aᵢ, bᵢ ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1800**。
