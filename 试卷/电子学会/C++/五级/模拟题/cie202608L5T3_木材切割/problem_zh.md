# 木材切割

#### 题目描述

有 n 段木材，第 i 段长度为 aᵢ。现在要把这些木材锯成 k 段长度相等的小木段（每段长度 x），第 i 段木材可以锯出 ⌊aᵢ / x⌋ 段。长度不足 x 的余料舍弃。

求能锯出的等长小木段的最大长度 x。

#### 输入格式

第一行，两个整数 n、k。
第二行，n 个整数，表示 a₁, a₂, …, aₙ。

#### 输出格式

输出一个整数，表示最大可能的等长小木段长度 x。

#### 样例输入 #1

```
3 7
10 15 8
```

#### 样例输出 #1

```
4
```

#### 样例输入 #2

```
1 3
10
```

#### 样例输出 #2

```
3
```

#### 数据范围

1 ≤ n ≤ 10⁵，1 ≤ k ≤ 10⁹，1 ≤ aᵢ ≤ 10⁹，所有输入均为整数。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
