# 区间和查询

给定 n 个整数，进行 q 次查询，每次查询区间 [l, r] 内所有数的和（下标从 1 开始）。

【输入格式】第一行两个整数 n 和 q。第二行 n 个整数。接下来 q 行，每行两个整数 l 和 r。
【输出格式】q 行，每行一个整数表示对应区间和。
【样例输入 1】
```
5 3
1 2 3 4 5
1 5
2 4
3 3
```
【样例输出 1】
```
15
9
3
```
【数据范围】1 ≤ n, q ≤ 100000，每个整数 ≤ 10⁹。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
