# 成绩统计

#### 题目描述

n 个学生参加考试，每人考语文、数学、英语三科，每科满分 100 分。现需按以下规则排名：

1. 总分高的排名靠前；
2. 总分相同，语文成绩高的靠前；
3. 语文也相同，学号小的靠前。

请按排名顺序输出每个学生的学号和总分。

#### 输入格式

第一行，一个整数 n。
接下来 n 行，每行 4 个整数：学号、语文、数学、英语。

#### 输出格式

按排名顺序，每行输出"学号 总分"。

#### 样例输入 #1

```
3
1 90 80 70
2 100 70 70
3 80 90 80
```

#### 样例输出 #1

```
3 250
2 240
1 240
```

#### 样例输入 #2

```
2
5 60 60 60
6 70 50 60
```

#### 样例输出 #2

```
6 180
5 180
```

#### 数据范围

1 ≤ n ≤ 10⁵，学号互不相同且为 1 到 n 的整数，0 ≤ 各科成绩 ≤ 100。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1200**。
