# 最长连续段

#### 题目描述

给定长度为 n 的正整数序列 a 和整数 m。求满足"连续一段元素之和不超过 m"的最长连续段的长度。

注意：连续段可以为空，此时长度为 0。

#### 输入格式

第一行，两个整数 n、m。
第二行，n 个整数，表示 a₁, a₂, …, aₙ。

#### 输出格式

输出一个整数，表示满足条件的最长连续段的长度。

#### 样例输入 #1

```
5 10
2 3 1 5 4
```

#### 样例输出 #1

```
3
```

#### 样例输入 #2

```
4 15
3 5 7 9
```

#### 样例输出 #2

```
3
```

#### 数据范围

1 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁹，1 ≤ aᵢ ≤ 10⁹，所有输入均为整数。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
