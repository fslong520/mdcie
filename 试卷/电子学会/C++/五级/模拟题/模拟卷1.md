### 第 1 题（电子学会五级模拟·快速幂）用快速幂计算 `a^13` 时，指数 13 的二进制为 1101，最终结果可表示为？（ ）

- A. `a^8 × a^4 × a^1`
- B. `a^8 × a^4 × a^2`
- C. `a^16 × a^4 × a^1`
- D. `a^8 × a^2 × a^1`

**答案：A**

**解析：** 13 = 8 + 4 + 1，即二进制 1101。快速幂按二进制位拆分指数，对应为 1 的位做乘法，故结果为 `a^8 × a^4 × a^1 = a^13`。

### 第 2 题（电子学会五级模拟·递推）已知递推公式 `f(0)=0`，`f(n)=f(n-1)+2n-1`，则 `f(3)` 的值是？（ ）

- A. 5
- B. 7
- C. 9
- D. 11

**答案：C**

**解析：** `f(1)=0+1=1`，`f(2)=1+3=4`，`f(3)=4+5=9`。

### 第 3 题（电子学会五级模拟·贪心）贪心算法与动态规划的一个重要区别是？（ ）

- A. 贪心算法不回溯已做的选择，动态规划会保存并比较所有可能的子问题结果
- B. 贪心算法一定比动态规划更慢
- C. 动态规划只能用于解决排序问题
- D. 贪心算法和动态规划本质上完全相同

**答案：A**

**解析：** 贪心每步取局部最优且不回溯；动态规划保存子问题结果，通过状态转移比较取优。B 错（贪心通常更快），C 错（动态规划广泛用于各类最优化问题），D 错。

### 第 4 题（电子学会五级模拟·前缀和）对长度为 n 的数组预处理前缀和后，任意一次区间和查询的时间复杂度为？（ ）

- A. O(n)
- B. O(log n)
- C. O(1)
- D. O(n²)

**答案：C**

**解析：** 预处理 O(n) 后，区间 `[l, r]` 的和 = `pre[r] - pre[l-1]`，单次查询 O(1) 得出。

### 第 5 题（电子学会五级模拟·差分）已知差分数组 `d[1..5] = {3, -1, 2, 0, -4}`，其中 `d[i]=a[i]-a[i-1]`，`a[0]=0`，则 `a[3]` 的值是？（ ）

- A. 5
- B. 2
- C. 3
- D. 4

**答案：D**

**解析：** 差分数组前缀和即原数组：`a[3] = d[1]+d[2]+d[3] = 3+(-1)+2 = 4`。

### 第 6 题（电子学会五级模拟·二分）在有序数组 `{1, 3, 5, 7, 9, 11, 13}` 中用二分查找目标值 13，共需要比较几次？（ ）

- A. 4
- B. 2
- C. 1
- D. 3

**答案：D**

**解析：** 第一次比较中位 7，13>7 进入右半；第二次比较中位 11，13>11 继续右半；第三次比较 13 命中。共 3 次。

### 第 7 题（电子学会五级模拟·双指针）在有序数组中用双指针法求两数之和等于目标值，两指针的初始位置通常是？（ ）

- A. 左指针指向数组开头，右指针指向数组末尾
- B. 两个指针都指向数组开头
- C. 两个指针都指向数组中间
- D. 左指针指向数组末尾，右指针指向数组开头

**答案：A**

**解析：** 一左一右由两端向中间靠拢，和偏大则右指针左移，和偏小则左指针右移，保证 O(n) 完成。

### 第 8 题（电子学会五级模拟·STL）以下关于 `stack` 容器的说法，正确的是？（ ）

- A. `stack` 是先进先出（FIFO）结构
- B. `stack` 是后进先出（LIFO）结构
- C. `stack` 支持下标随机访问
- D. `stack` 的元素按关键字自动排序

**答案：B**

**解析：** `stack` 只在栈顶操作，后进先出；不支持下标随机访问，也不会自动排序。

### 第 9 题（电子学会五级模拟·STL）STL 中 `reverse()` 函数的作用是？（ ）

- A. 将容器中元素的顺序反转
- B. 将容器中的元素排序
- C. 在容器中查找指定元素
- D. 删除容器中的重复元素

**答案：A**

**解析：** `reverse(begin, end)` 反转迭代器区间内元素顺序；排序用 `sort`，查找用 `find`。

### 第 10 题（电子学会五级模拟·STL）以下代码的输出是？（ ）

```cpp
vector<int> v;
v.push_back(3);
v.push_back(1);
v.push_back(2);
sort(v.begin(), v.end());
cout << v[1];
```

- A. 1
- B. 2
- C. 3
- D. 编译错误

**答案：B**

**解析：** 排序后 `v = {1, 2, 3}`，`v[1]` 为 2。

### 第 11 题（电子学会五级模拟·快速幂）快速幂算法中，指数为偶数时也需要将当前底数乘入结果。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 仅当二进制位为 1（即指数为奇数）时才把当前底数乘入结果；偶数位只做底数平方。

### 第 12 题（电子学会五级模拟·递推）递推关系必须是一阶线性的，不能是二阶递推。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 递推可以是高阶的，如斐波那契 `f(n)=f(n-1)+f(n-2)` 就是典型二阶递推。

### 第 13 题（电子学会五级模拟·贪心）贪心算法每一步都选择当前局部最优，但可能得不到全局最优解。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 贪心只保证局部最优，不保证全局最优，是否最优需视问题性质而定。

### 第 14 题（电子学会五级模拟·前缀和）对原数组做一次单点修改后，之前计算好的前缀和数组仍然完全有效，无需更新。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 单点修改会影响该位置之后所有前缀和，需重新计算受影响的后缀部分。

### 第 15 题（电子学会五级模拟·差分）构建差分数组需要对数组进行多次遍历，时间复杂度为 O(n²)。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** `d[i]=a[i]-a[i-1]`，一次遍历即可完成，时间复杂度为 O(n)。

### 第 16 题（电子学会五级模拟·二分）二分答案可以用于求解具有单调性的最优化问题。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 当可行性与答案大小满足单调关系时，可用二分枚举答案并判断可行性，解决"最大值最小化""最小值最大化"等问题。

### 第 17 题（电子学会五级模拟·双指针）快慢指针可以用于检测链表中是否存在环。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 快指针每次走两步、慢指针走一步，若链表有环则两指针终会相遇。

### 第 18 题（电子学会五级模拟·STL）`vector` 使用 `push_back()` 在尾部插入元素，均摊时间复杂度为 O(1)。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 扩容虽偶尔触发 O(n) 的搬移，但整体均摊为 O(1)。

### 第 19 题（电子学会五级模拟·STL）`priority_queue` 默认是大根堆，队首元素是最大值。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `priority_queue` 默认使用 `<` 比较器，构成大根堆，`top()` 返回最大值。

### 第 20 题（电子学会五级模拟·STL）`map` 的 `lower_bound(key)` 返回第一个键不小于 key 的迭代器。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `lower_bound` 基于有序键二分，返回第一个 ≥ key 的迭代器；不存在则返回 `end()`。

### 第 1 题 最长连续段 ★★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/cie202608L5T1>

**【题目描述】**

给定长度为 n 的正整数序列 a 和整数 m。求满足"连续一段元素之和不超过 m"的最长连续段的长度。

注意：连续段可以为空，此时长度为 0。

**【输入格式】**

第一行，两个整数 n、m。
第二行，n 个整数，表示 a₁, a₂, …, aₙ。

**【输出格式】**

输出一个整数，表示满足条件的最长连续段的长度。

**【样例输入 1】**

```
5 10
2 3 1 5 4
```

**【样例输出 1】**

```
3
```

**【样例输入 2】**

```
4 15
3 5 7 9
```

**【样例输出 2】**

```
3
```

**【数据范围】**

1 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁹，1 ≤ aᵢ ≤ 10⁹，所有输入均为整数。

### 第 2 题 单词频率 ★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/cie202608L5T2>

**【题目描述】**

输入 n 个小写英文单词，统计每个单词出现的次数。按出现次数从多到少输出；出现次数相同时，按字典序从小到大输出。每行输出一个单词及其出现次数，中间用空格隔开。

**【输入格式】**

第一行，一个整数 n。
第二行，n 个单词，用空格分隔。

**【输出格式】**

若干行，每行"单词 出现次数"。

**【样例输入 1】**

```
6
apple banana apple cat banana apple
```

**【样例输出 1】**

```
apple 3
banana 2
cat 1
```

**【样例输入 2】**

```
4
a a b a
```

**【样例输出 2】**

```
a 3
b 1
```

**【数据范围】**

1 ≤ n ≤ 10⁵，单词仅由小写英文字母组成，长度 ≤ 20。
