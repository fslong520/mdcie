### 第 23 题 图书检索 ★★★（30 分）

**【题目描述】**

图书馆的书按编号从小到大排列。给定一个编号 x，请找出与 x 最接近的书的编号（若有多个，输出较小的那个）。
【输入格式】第一行两个整数 n、x；第二行 n 个升序整数。
【输出格式】一个整数，表示最接近 x 的编号。
【样例输入 1】
```
5 4
1 3 5 7 9
```
【样例输出 1】
```
3
```
【样例输入 2】
```
4 6
1 4 7 10
```
【样例输出 2】
```
7
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ 编号 ≤ 10⁹。

**【参考程序】**

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[100005];

int main()
{
    int n, x;
    cin >> n >> x;
    for (int i = 0; i < n; i++) cin >> a[i];
    int idx = lower_bound(a, a + n, x) - a;
    int ans;
    if (idx == 0) ans = a[0];
    else if (idx == n) ans = a[n - 1];
    else
    {
        int d1 = a[idx] - x, d2 = x - a[idx - 1];
        if (d2 <= d1) ans = a[idx - 1];
        else ans = a[idx];
    }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 二分查找 lower_bound 找到第一个 ≥ x 的位置 idx。比较 a[idx] 和 a[idx-1] 与 x 的距离，选更近的（距离相等选较小的）。

### 第 24 题 体力配对 ★★★（30 分）

**【题目描述】**

n 个学生的体力值按升序排列。老师想找两名同学组成一队，使两人体力值之和恰好等于目标值 x。求有多少对这样的组合。
【输入格式】第一行两个整数 n、x；第二行 n 个升序整数。
【输出格式】一个整数，表示满足条件的对数。
【样例输入 1】
```
5 7
1 2 3 4 5
```
【样例输出 1】
```
2
```
【样例输入 2】
```
4 10
1 3 5 7
```
【样例输出 2】
```
1
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ 体力值 ≤ 10⁹。

**【参考程序】**

```cpp
#include <iostream>
using namespace std;

int a[100005];

int main()
{
    int n, x, ans = 0;
    cin >> n >> x;
    for (int i = 0; i < n; i++) cin >> a[i];
    int l = 0, r = n - 1;
    while (l < r)
    {
        if (a[l] + a[r] == x) { ans++; l++; r--; }
        else if (a[l] + a[r] < x) l++;
        else r--;
    }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 双指针：l=0, r=n-1，若 a[l]+a[r]==x 则计数并 l++ r--，若和 < x 则 l++，> x 则 r--。
