# 最短积分连续段

小爱连续 n 天打卡，第 i 天获得 aᵢ 个积分（积分均为正整数）。他想知道：选出连续的若干天，使这些天的积分之和不小于 s，这样的连续段最短是多少天？若不存在这样的连续段，输出 0。

【输入格式】第一行两个整数 n 和 s。第二行 n 个正整数 a₁ … aₙ。
【输出格式】一行一个整数，表示最短连续段长度；不存在输出 0。
【样例输入 1】
```
5 10
5 1 2 3 7
```
【样例输出 1】
```
2
```
【样例说明】第 4~5 天积分 3+7=10 ≥ 10，长度 2 为最短。
【样例输入 2】
```
3 100
1 2 3
```
【样例输出 2】
```
0
```
【数据范围】1 ≤ n ≤ 10⁵，1 ≤ s ≤ 10¹⁴，1 ≤ aᵢ ≤ 10⁹。
