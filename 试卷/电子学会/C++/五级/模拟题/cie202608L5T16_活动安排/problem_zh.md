# 活动安排

一天内有 n 个活动，第 i 个活动在时间区间 [sᵢ, eᵢ] 进行。同一时间只能参加一个活动，若一个活动结束时间 ≤ 下一个活动开始时间，则可以连续参加（即前一个活动 e 时刻结束，后一个活动 e 时刻开始不算冲突，要求 e₁ ≤ s₂）。

请选择尽量多的活动参加，输出最多能参加多少个。

【输入格式】第一行一个整数 n。接下来 n 行，每行两个整数 s 和 e，表示活动的开始和结束时间。
【输出格式】一个整数，表示最多能参加的活动数量。
【样例输入 1】
```
4
1 3
2 5
3 6
5 7
```
【样例输出 1】
```
2
```
【样例说明】可参加 [1,3] 和 [3,6]（或 [1,3] 和 [5,7]），最多 2 个。
【数据范围】1 ≤ n ≤ 100000，0 ≤ sᵢ ≤ eᵢ ≤ 10⁹。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
