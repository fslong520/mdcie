# 自动找零

自动售货机需要找零。可用的纸币面额为 1 元、5 元、10 元、50 元、100 元，每种面额数量不限。对每次找零金额，用这些面额凑出该金额，求最少需要多少张纸币。

【输入格式】第一行一个整数 T，表示询问次数。接下来 T 行，每行一个正整数 m，表示需要找零的金额。
【输出格式】共 T 行，每行一个整数，表示最少纸币张数。
【样例输入 1】
```
3
67
5
999999999
```
【样例输出 1】
```
5
1
9999999
```
【样例说明】67 = 50+10+5+1+1，共 5 张；999999999 = 9999999 张 100 元再加 99 元的 10 张，共 10000009 张。
【数据范围】1 ≤ T ≤ 10⁵，1 ≤ m ≤ 10⁹。
#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1300**。
