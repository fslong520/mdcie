### 第 23 题 共同好友 ★★（30 分）

**【题目描述】**

小明和小红的好友列表（可能包含重复）分别给出，请统计两人共同的好友（去重后）有多少个。
【输入格式】第一行两个整数 n、m，表示小明和小红的好友数；第二行 n 个字符串（小明的好友）；第三行 m 个字符串（小红的好友）。
【输出格式】一个整数，表示共同好友个数。
【样例输入 1】
```
4 3
Alice Bob Cindy David
Bob Alice Eve
```
【样例输出 1】
```
2
```
【样例输入 2】
```
3 3
Tom Jerry Spike
Amy Ben Cathy
```
【样例输出 2】
```
0
```
【数据范围】1 ≤ n,m ≤ 100000，姓名长度 ≤ 20。

**【参考程序】**

```cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main()
{
    int n, m, ans = 0;
    string s;
    set<string> st;
    cin >> n >> m;
    for (int i = 0; i < n; i++) { cin >> s; st.insert(s); }
    for (int i = 0; i < m; i++) { cin >> s; if (st.count(s)) ans++; }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 用 set 存小明的好友（去重），遍历小红的好友，若在 set 中出现则计数。

### 第 24 题 糖果装盒 ★★★（30 分）

**【题目描述】**

有一些糖果，每颗糖果的重量不同。现在要用盒子装糖果，每盒最多装 2 颗，且总重量不能超过盒子限重 W。每次将最轻的糖果和最重的糖果配对，若重量和 ≤ W 则装一盒，否则最重的单独装一盒。求最少需要多少盒子。
【输入格式】第一行两个整数 n、W；第二行 n 个整数表示糖果重量。
【输出格式】一个整数，表示最少盒数。
【样例输入 1】
```
5 6
1 2 3 4 5
```
【样例输出 1】
```
3
```
【样例输入 2】
```
4 10
10 10 10 10
```
【样例输出 2】
```
4
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ wᵢ ≤ W ≤ 10⁹。

**【参考程序】**

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

typedef long long ll;
ll a[100005];

int main()
{
    int n, ans = 0;
    ll W;
    cin >> n >> W;
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a, a + n);
    int l = 0, r = n - 1;
    while (l <= r)
    {
        if (l == r) { ans++; break; }
        if (a[l] + a[r] <= W) { ans++; l++; r--; }
        else { ans++; r--; }
    }
    cout << ans << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 排序后双指针贪心：l=0, r=n-1，若 a[l]+a[r]≤W 则配对（l++ r--），否则重单独装（r--），每步盒数+1。
