# 数列分段

给定 n 个正整数，将它们按顺序分成 m 段（连续、非空），每段内所有数求和，最小化各段和的最大值。输出这个最小值。

【输入格式】第一行两个整数 n 和 m。第二行 n 个正整数。
【输出格式】一个整数，表示各段和的最大值的最小可能值。
【样例输入 1】
```
5 3
4 2 4 5 1
```
【样例输出 1】
```
6
```
【样例说明】分成 [4,2]、[4]、[5,1]，各段和为 6、4、6，最大值为 6，这是最优方案（若分成 [4,2,4]、[5]、[1] 最大和为 10）。
【样例输入 2】
```
4 4
1 2 3 4
```
【样例输出 2】
```
4
```
【数据范围】1 ≤ m ≤ n ≤ 100000，每个数 ≤ 10⁹。
