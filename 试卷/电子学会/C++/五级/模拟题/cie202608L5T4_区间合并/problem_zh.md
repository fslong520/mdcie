# 区间合并

#### 题目描述

给定 n 个闭区间 `[lᵢ, rᵢ]`。若两个区间有交集或端点相邻（如 `[1,4]` 与 `[4,5]`），则可合并为一个区间。请把所有能合并的区间合并后，输出合并后区间的个数。

#### 输入格式

第一行，一个整数 n。
接下来 n 行，每行两个整数 lᵢ、rᵢ，表示一个区间。

#### 输出格式

输出一个整数，表示合并后区间的个数。

#### 样例输入 #1

```
4
1 3
2 6
8 10
15 18
```

#### 样例输出 #1

```
3
```

#### 样例输入 #2

```
3
1 4
4 5
6 7
```

#### 样例输出 #2

```
2
```

#### 数据范围

1 ≤ n ≤ 10⁵，1 ≤ lᵢ ≤ rᵢ ≤ 10⁹，所有输入均为整数。

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1300**。
