# 体力配对

n 个学生的体力值按升序排列。老师想找两名同学组成一队，使两人体力值之和恰好等于目标值 x。求有多少对这样的组合。
【输入格式】第一行两个整数 n、x；第二行 n 个升序整数。
【输出格式】一个整数，表示满足条件的对数。
【样例输入 1】
```
5 7
1 2 3 4 5
```
【样例输出 1】
```
2
```
【样例输入 2】
```
4 10
1 3 5 7
```
【样例输出 2】
```
1
```
【数据范围】1 ≤ n ≤ 100000，1 ≤ 体力值 ≤ 10⁹。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
