### 第 1 题（2026 电子学会五级真题·快速幂）快速幂算法的核心思想？（ ）

- A. 分治法，将幂运算分解为更小的子问题
- B. 枚举法，逐一相乘
- C. 递归法，无终止条件
- D. 动态规划，存储所有中间结果

**答案：A**

**解析：** 快速幂将指数按二进制拆分或分治递归，把原本需要 O(b) 次乘法的计算降到 O(log b) 次，其核心是分治而非枚举或 DP。

### 第 2 题（2026 电子学会五级真题·递推）斐波那契数列的递推公式为 `f(n)=f(n-1)+f(n-2)`，`f(1)=1`，`f(2)=1`，则 `f(6)` 的值？（ ）

- A. 5
- B. 8
- C. 13
- D. 21

**答案：B**

**解析：** `f(3)=f(2)+f(1)=2`，`f(4)=f(3)+f(2)=3`，`f(5)=f(4)+f(3)=5`，`f(6)=f(5)+f(4)=8`。

### 第 3 题（2026 电子学会五级真题·贪心）以下哪个问题最适合用贪心算法求解？（ ）

- A. 01 背包问题
- B. 活动选择问题
- C. 最长公共子序列问题
- D. 斐波那契数列计算

**答案：B**

**解析：** 活动选择问题（最早结束优先）可用贪心得最优解；01 背包与最长公共子序列需动态规划，斐波那契用递推/递归。

### 第 4 题（2026 电子学会五级真题·前缀和）已知数组 `arr[5] = {1, 2, 3, 4, 5}`，其前缀和数组 `preSum` 中，已知 `preSum[0] = 0`，则 `preSum[3]` 的值？（ ）

- A. 3
- B. 6
- C. 10
- D. 15

**答案：B**

**解析：** 前缀和定义 `preSum[i] = preSum[i-1] + arr[i-1]`（下标从 1 计），`preSum[1]=1`，`preSum[2]=3`，`preSum[3]=6`（即 `arr[0]+arr[1]+arr[2]=1+2+3=6`）。

### 第 5 题（2026 电子学会五级真题·差分）差分算法最适合解决以下哪类问题？（ ）

- A. 多次区间修改，单次查询
- B. 多次单点修改，单次查询
- C. 多次区间查询，无修改
- D. 排序问题

**答案：A**

**解析：** 差分将区间修改转化为对差分数组的单点修改（首尾两端），最后用前缀和还原，最适合“多次区间修改、单次查询”。

### 第 6 题（2026 电子学会五级真题·双指针）在有序数组中查找两个数的和等于目标值，最优的解法是双指针法，其时间复杂度为？（ ）

- A. O(n)
- B. O(n²)
- C. O(log n)
- D. O(n log n)

**答案：A**

**解析：** 双指针一头一尾向中间靠拢，每步排除一个不可能组合，最坏遍历数组一遍，复杂度 O(n)。

### 第 7 题（2026 电子学会五级真题·二分）二分查找算法的前提条件？（ ）

- A. 数组无序
- B. 数组有序
- C. 数组元素全为正数
- D. 数组长度为偶数

**答案：B**

**解析：** 二分查找依赖每次比较后将搜索区间折半，必须建立在“数组有序”的前提上。

### 第 8 题（2026 电子学会五级真题·STL）以下哪个 STL 容器是动态数组，支持随机访问？（ ）

- A. vector
- B. list
- C. set
- D. map

**答案：A**

**解析：** `vector` 是 STL 的动态数组，底层连续存储，支持下标随机访问；`list` 为链表，`set`/`map` 为树结构，均非随机访问。

---

### 第 9 题（2026 电子学会五级真题·STL）STL 中，用于对容器元素进行排序的函数？（ ）

- A. `find()`
- B. `sort()`
- C. `max()`
- D. `swap()`

**答案：B**

**解析：** `sort()` 用于排序；`find()` 查找，`max()` 取最大值，`swap()` 交换。

### 第 10 题（2026 电子学会五级真题·STL）以下关于 `string` 类的说法，错误的？（ ）

- A. 可以用 `+` 运算符拼接两个 string 对象
- B. 可以用 `length()` 函数获取字符串长度
- C. 不支持下标访问
- D. 可以用 `substr()` 函数获取子串

**答案：C**

**解析：** `string` 重载了 `[]` 运算符，可直接用下标访问字符；A、B、D 均正确。

### 第 11 题（2026 电子学会五级真题·快速幂）快速幂算法可以将求 `a^b` 的时间复杂度从 `O(b)` 优化到 `O(log b)`。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 快速幂利用二分思想，将指数二进制拆分（如 13 = 8+4+1），把 O(b) 的乘法降到 O(log b)。

### 第 12 题（2026 电子学会五级真题·递推）递推算法是从已知的初始条件出发，逐步推导出后续结果。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 递推正是从初始条件开始，利用递推关系逐步求得后续各项，描述正确。

### 第 13 题（2026 电子学会五级真题·贪心）贪心算法的核心思想是枚举所有可能的情况。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 枚举所有可能情况是“枚举法/暴力法”的思想；贪心是每步取当前局部最优，并不枚举全部。

### 第 14 题（2026 电子学会五级真题·前缀和）前缀和数组可以快速求出数组中任意区间的元素和。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 预处理前缀和 `preSum` 后，区间 `[l, r]` 的和 = `preSum[r] - preSum[l-1]`，可在 O(1) 内求出。

### 第 15 题（2026 电子学会五级真题·差分）对差分数组求前缀和，可以得到原数组。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 差分数组 `d[i] = arr[i] - arr[i-1]`，对其求前缀和即可还原原数组 `arr[i] = d[1] + … + d[i]`。

### 第 16 题（2026 电子学会五级真题·二分）二分查找的最坏时间复杂度是 `O(n)`。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 二分每次将区间折半，最坏比较次数约 log₂n，复杂度是 O(log n) 而非 O(n)。

### 第 17 题（2026 电子学会五级真题·双指针）双指针算法只能用于处理有序数组的问题，无法在无序数组或链表中使用。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 双指针不限于有序数组，快慢指针在链表（如判环、找中点）、无序数组（如首尾指针）中都可应用。

### 第 18 题（2026 电子学会五级真题·STL）`vector` 容器的 `push_back()` 函数可以在序列头部插入元素。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** `push_back()` 在序列“尾部”追加元素；头部插入不是 `vector` 的 `push_back` 行为。

### 第 19 题（2026 电子学会五级真题·STL）`set` 容器中的元素是内部有序且不重复的。（ ）

- T. 正确

### 第 1 题 三数之和 ★★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L5A>

**【题目描述】**

现有长度为 n 的数列 a、数列 b、数列 c，再给定一个长度为 q 的查询数列 x。
对于每次查询 xᵢ，请判断能否从三个数列中各选一个元素，使得三者之和恰好等于 xᵢ。

**【输入格式】**

第一行，一个整数 n。
第二行，n 个整数，表示数列 a₁, a₂, …, aₙ。
第三行，n 个整数，表示数列 b₁, b₂, …, bₙ。
第四行，n 个整数，表示数列 c₁, c₂, …, cₙ。
第五行，一个整数 q，表示 q 次查询。
第六行，q 个整数，表示每一次查询的整数 xᵢ。

**【输出格式】**

共 q 行，第 i 行表示查询 xᵢ 的结果。

**【样例输入 1】**

```
3
1 2 3
4 5 6
7 8 9
2
12 20
```

**【样例输出 1】**

```
Yes
No
```

**【样例输入 2】**

```
4
0 100 200 300
0 50 150 250
0 80 180 280
5
0 430 580 630 750
```

**【样例输出 2】**

```
Yes
Yes
Yes
Yes
No
```

**【数据范围】**

1 ≤ n ≤ 100，0 ≤ aᵢ、bᵢ、cᵢ ≤ 10⁸，1 ≤ q ≤ 2×10⁵，0 ≤ xᵢ ≤ 3×10⁸，所有输入均为整数。

### 第 2 题 爆破 ★★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L5B>

**【题目描述】**

你遇到了 n 只怪兽，第 i 只怪兽的初始体力为 hᵢ。当怪兽的体力降至 0 级以下时，会立即消失。
你可以释放爆炸攻击怪兽，每次爆炸规则如下：选择一只存活的怪兽作为爆炸中心，中心怪兽的体力减少 a，其余所有怪兽的体力各减少 b，其中 a > b。
请计算消灭所有怪兽最少需要释放多少次爆炸。

**【输入格式】**

第一行三个整数，表示 n、a、b。
接下来 n 个整数 hᵢ，表示 n 只怪兽的体力。

**【输出格式】**

输出消灭所有怪兽所需的最小爆炸次数。

**【数据范围】**

输入中的所有数均为整数，1 ≤ n ≤ 10⁵，1 ≤ b ≤ a ≤ 10⁹，1 ≤ hᵢ ≤ 10⁹。

**【样例输入 1】**

```
4 5 3

```

**【样例输出 1】**

```
2
```

**【样例输入 2】**

```
2 10 4
```

**【样例输出 2】**

```
4
```

**【样例输入 3】**
