# 能量节点

#### 题目描述

数轴上分布着 n 个能量节点，第 i 个节点的坐标为 xᵢ。当两个节点的距离小于等于 d 时，会产生能量共鸣。

求一共有多少组节点会发生能量共鸣。

#### 输入格式

第一行，两个整数表示 n 与 d。

第二行，n 个整数，表示 x₁、x₂、……、xₙ。

#### 输出格式

单个整数：表示有多少对点可以产生能量共鸣。

#### 样例输入 #1

```
4 25
30 40 10 20
```

#### 样例输出 #1

```
5
```

#### 样例输入 #2

```
3 2
1 5 9
```

#### 样例输出 #2

```
0
```

#### 数据范围

1 ≤ n ≤ 100000，1 ≤ d、xᵢ ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）5级**，难度（CF Rating）：**1600**。
