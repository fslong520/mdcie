### 第 1 题（2026 电子学会五级真题·递推）有递推公式 `f(n) = 2*f(n-1) + 1`，`f(1)=1`，则 `f(4)` 的值是？（ ）

- A. 7
- B. 15
- C. 31
- D. 63

**答案：B**

**解析：** `f(1)=1`，`f(2)=3`，`f(3)=7`，`f(4)=15`；亦可由 `f(n)+1 = 2(f(n-1)+1)` 得 `f(n) = 2ⁿ - 1`，故 `f(4) = 15`。

### 第 2 题（2026 电子学会五级真题·贪心）以下关于贪心算法的说法，正确的是？（ ）

- A. 贪心算法总能得到全局最优解
- B. 贪心算法的核心是每一步选择当前最优的选项
- C. 01 背包问题可以用贪心算法得到最优解
- D. 贪心算法的时间复杂度一定比动态规划低

**答案：B**

**解析：** 贪心每步取局部最优，但未必得全局最优（A 错）；01 背包需动态规划（C 错）；复杂度不一定更低（D 错）。

### 第 3 题（2026 电子学会五级真题·前缀和）已知数组 `arr[6] = {2,4,6,8,10,12}`，前缀和数组 `preSum[0]=0`，`preSum[i] = arr[0]+arr[1]+…+arr[i-1]`，则区间 `[2, 4]`（下标从 0 开始）的元素和为？（ ）

- A. 18
- B. 24
- C. 30
- D. 36

**答案：B**

**解析：** 区间和 = `preSum[5] - preSum[2] = (2+4+6+8+10) - (2+4) = 30 - 6 = 24`，即 `arr[2]+arr[3]+arr[4] = 6+8+10 = 24`。

### 第 4 题（2026 电子学会五级真题·差分）对原数组的区间 `[l, r]` 全部加上 `val`，对差分数组的操作是？（ ）

- A. `diff[l] += val; diff[r] -= val;`
- B. `diff[l] += val; diff[r+1] -= val;`
- C. `diff[l] -= val; diff[r] += val;`
- D. `diff[l] -= val; diff[r+1] += val;`

**答案：B**

**解析：** 差分数组区间加的标准写法：左端点 `l` 加 `val`，右端点下一位 `r+1` 减 `val`，前缀和还原即得区间加。

### 第 5 题（2026 电子学会五级真题·二分）在长度为 n 的有序数组中，二分查找的最坏时间复杂度是？（ ）

- A. O(1)
- B. O(log n)
- C. O(n)
- D. O(n log n)

**答案：B**

**解析：** 每次将搜索区间折半，最坏比较次数约 log₂n，故 O(log n)。

### 第 6 题（2026 电子学会五级真题·双指针）以下哪个问题不适合用双指针算法求解？（ ）

- A. 有序数组两数之和
- B. 链表中环的检测
- C. 反转字符串
- D. 01 背包问题

**答案：D**

**解析：** 01 背包是动态规划问题，需考虑取舍与最优子结构，不适合双指针；其余三项均可用双指针（或快慢指针）求解。

### 第 7 题（2026 电子学会五级真题·STL）以下哪个 STL 容器是基于红黑树实现的，元素自动有序且不重复？（ ）

- A. vector
- B. set
- C. queue
- D. list

**答案：B**

**解析：** `set` 底层为红黑树，插入后自动按 key 有序排列且 key 唯一不重复。

### 第 8 题（2026 电子学会五级真题·STL）STL 中，用于在容器中查找指定元素的函数是？（ ）

- A. `sort()`
- B. `find()`
- C. `swap()`
- D. `reverse()`

**答案：B**

**解析：** `find()` 在容器中查找指定元素，返回迭代器；`sort` 排序，`swap` 交换，`reverse` 反转。

### 第 9 题（2026 电子学会五级真题·STL）以下关于 `vector` 容器的说法，【错误】的是？（ ）

- A. `vector` 是动态数组，支持动态扩容
- B. 可以用 `push_back()` 在数组尾部插入元素
- C. 可以用 `pop_front()` 删除数组头部的元素
- D. 支持下标随机访问

**答案：C**

**解析：** `vector` 没有 `pop_front()`（头部删除效率低，需用 `deque` 或 `erase`）；A、B、D 均正确。

### 第 10 题（2026 电子学会五级真题·快速幂）计算整数 `a` 的 `b` 次方，若使用快速幂算法，时间复杂度为？（ ）

- A. O(b)
- B. O(log b)
- C. O(a)
- D. O(1)

**答案：B**

**解析：** 快速幂将指数按二进制拆分，每比特做一次平方、按需乘底数，乘次数为 O(log b)。

---

### 第 11 题（2026 电子学会五级真题·快速幂）快速幂的核心是将指数分解为二进制，减少乘法运算的次数。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 快速幂将指数写成二进制，利用 `a^(2k) = (a^k)²` 与 `a^(2k+1) = (a^k)²·a`，乘法次数降至 O(log b)。

### 第 12 题（2026 电子学会五级真题·递推）递推算法分为顺推和逆推两种，斐波那契数列是顺推的典型应用。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 斐波那契从 `f(1), f(2)` 顺推至 `f(n)`，属于顺推。

### 第 1 题 能量节点 ★★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202606L5A>

**【题目描述】**

数轴上分布着 n 个能量节点，第 i 个节点的坐标为 xᵢ。当两个节点的距离小于等于 d 时，会产生能量共鸣。

求一共有多少组节点会发生能量共鸣。

**【输入格式】**

第一行，两个整数表示 n 与 d。

第二行，n 个整数，表示 x₁、x₂、……、xₙ。

**【输出格式】**

单个整数：表示有多少对点可以产生能量共鸣。

**【样例输入】**

```
4 25
30 40 10 20
```

**【样例输出】**

```
5
```

**【数据范围】**

1 ≤ n ≤ 100000，1 ≤ d、xᵢ ≤ 10⁹。

### 第 2 题 刷任务 ★★★（30 分）

**OJ 链接：** <https://fslong.iok.la/problem/CIE202606L5B>

**【题目描述】**

一共有 n 个小任务，第 i 个任务会消耗 aᵢ 点体力、bᵢ 点心神。你可以自由安排任务的完成顺序，逐个依次做完任务。当累计消耗的体力总和超过 x，或是累计消耗的心神总和超过 y 时，会立刻停下无法继续做事。

求：在运气最差、顺序最不利的情况下，你最少会完成多少个任务就被迫停止。

**【输入格式】**

第一行，三个整数表示 n, x, y；

第二行，n 个整数表示 a₁, a₂, …, aₙ；

第三行，n 个整数表示 b₁, b₂, …, bₙ。

**【输出格式】**

输出一个整数，表示最少完成的任务数量。

**【样例输入 1】**

```
4 7 18
2 3 5 1
8 8 1 4
```

**【样例输出 1】**

```
2
```

**【样例输入 2】**

```
8 30 30
1 2 3 4 5 6 7 8
8 7 6 5 4 3 2 1
```

**【样例输出 2】**

```
6
```

**【数据范围】**

1 ≤ n ≤ 2×10⁵，1 ≤ x、y ≤ 2×10¹⁴，1 ≤ aᵢ、bᵢ ≤ 10⁹。
