# 字符串的不同子串

#### 题目描述

给定一个由小写英文字母组成的字符串 s。请问 s 的不同非空子串有多少种？
子串是指字符串中连续的一段字符。例如，xxx 是 yxxxy 的子串，但不是 xxyxx 的子串。

#### 输入格式

输入一行，包含一个字符串 s。

#### 输出格式

输出一个整数，表示 s 的不同非空子串的数量。

#### 样例输入 #1

```
aababc
```

#### 样例输出 #1

```
17
```

#### 样例输入 #2

```
abracadabra
```

#### 样例输出 #2

```
54
```

#### 数据范围

s 仅由小写英文字母组成。1 ≤ |s| ≤ 100，其中 |s| 表示字符串的长度。
