# 钉子

为了获取宝藏，琼斯必须完成最后一项任务。他遇到一张桌子，桌面上沿长度方向摆放着若干木板。他注意到桌子的宽度恰好与每块木板的宽度相同。这些木板非常沉重，无法通过人力移动。其中部分木板存在重叠区域。琼斯有一把锤子，众神赐予他无限量的钉子。需要用钉子将木板固定在桌面上，确保每块木板至少被一颗钉子固定。钉子长度足够，必须垂直钉入桌面。若多块木板存在公共重叠区域，可以用一颗钉子同时固定它们。请计算固定所有木板所需的最少钉子数量。

【输入格式】第一行输入正整数 t（t ≤ 10），表示桌子的数量。随后依次给出每张桌子的描述：第 k 张桌子的首行为正整数 n（n ≤ 3000），表示该桌面上的木板数量；接下来 n 行每行两个整数 a、b（0 ≤ a ≤ b ≤ 10⁷），分别表示木板左端和右端距离桌面左边缘的距离。

【输出格式】输出包含 t 行，第 k 行对应第 k 张桌子的答案，每行一个整数表示所需钉子的最小数量。

【样例输入 1】
```
2
3
1 5
3 5
2 4
2
1 4
4 5
```
【样例输出 1】
```
1
1
```
【数据范围】t ≤ 10，1 ≤ n ≤ 3000，0 ≤ a ≤ b ≤ 10⁷。

本题涉及知识点：**贪心、区间选点**，难度（CF Rating）：**1400**。
