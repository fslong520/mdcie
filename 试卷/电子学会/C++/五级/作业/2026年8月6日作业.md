### cxy0021 驾车限速★★★（12 分）

**【题目描述】**

编号为 1 到 N 的 N 头奶牛（1 ≤ N ≤ 50,000）正各自驾驶汽车行驶在牛托邦的高速公路上。每头奶牛 i 可以选择 M 条不同的高速车道（1 ≤ M ≤ N），其最高行驶速度为 Si 公里/小时（1 ≤ Si ≤ 1,000,000）。

由于之前糟糕的驾驶经历，奶牛们非常讨厌碰撞事故，并采取了极端措施来避免。在这条高速公路上，奶牛 i 会为前方每头奶牛降低 D 公里/小时的速度（0 ≤ D ≤ 5,000），但最低不会低于 0 公里/小时。因此，如果奶牛 i 前方有 K 头奶牛，它的实际速度将是 max(Si − D×K, 0)。虽然某头奶牛的实际速度可能超过正前方的奶牛，但由于奶牛之间保持足够间距，在减速规则下不会发生碰撞。

牛托邦制定了最低限速法，要求所有在高速公路上的车辆速度不得低于 L 公里/小时（1 ≤ L ≤ 1,000,000）。根据上述规则，有时部分奶牛将无法驶入高速公路。请编写程序计算在遵守限速法的情况下，最多能有多少头奶牛同时在高速公路上行驶。

**【输入格式】**

第一行包含四个整数 N, M, D, L。接下来 N 行，第 i+1 行包含整数 Si。

**【输出格式】**

输出一个整数表示可以驶入高速公路的最大奶牛数量。

**【样例输入】**

```
3 1 1 5
5
7
5
```

**【样例输出】**

```
2
```

**【样例说明】**

可以安排速度为 5 的奶牛在前，速度为 7 的奶牛在后，这样就能让两头奶牛同时行驶。

**【数据范围】**

1 ≤ N ≤ 50,000，1 ≤ M ≤ N，0 ≤ D ≤ 5,000，1 ≤ L, Si ≤ 1,000,000。

### cxy0022 跳石过河★★★（12 分）

**【题目描述】**

河面上有一条独木桥，桥的一端是起点石（位置 0），另一端是终点石（位置 L）。河中还有 n 块石头，第 i 块的位置为 dᵢ（0 < d₁ < d₂ < … < dₙ < L）。

青蛙想踩着石头从起点跳到终点，但他觉得石头太多、跳着太累，决定移走其中 m 块石头（0 ≤ m ≤ n，只能移走河中的石头，不能移走起点和终点石）。移走后，青蛙仍从起点跳到终点，每次落脚只能在相邻两块剩余石头之间跳跃。

青蛙希望自己每一次跳跃的距离都尽量大，但他必须保证能顺利到达终点。请问：移走 m 块石头后，青蛙"最短的一次跳跃距离"最大可以是多少？

**【输入格式】**

第一行，三个整数 L、n、m。

第二行，n 个整数，表示每块石头的位置 d₁, d₂, …, dₙ（互不相同）。

**【输出格式】**

一行，一个整数，表示移走 m 块石头后，最短跳跃距离的最大值。

**【样例输入】**

```
25 5 2
2 14 11 21 17
```

**【样例输出】**

```
4
```

**【样例说明】**

原石位 2、11、14、17、21。移走 2 和 14 后剩 11、17、21，跳跃距离依次为 11、6、4，最短为 4；可证明没有更大的方案（移走 21 和 17 剩 2、11、14，最短 9 但需 3 步跨过 14→25 为 11，最短仍为 2，故 4 为最大）。

**【数据范围】**

- 50% 数据：n ≤ 1000
- 100% 数据：1 ≤ L ≤ 10⁹，1 ≤ n ≤ 10⁵，0 ≤ m ≤ n。

某同学抽屉里锁着 n 封情书，按收信日期排好，每封的重量都不同且已按从轻到重排好（可能有同样重的）。他想知道：重量不小于 x 克的情书，最靠前的一封是第几封（从 1 编号）。

重量 ≥ 5 克的最靠前情书在第 4 个位置（重 5 克）。

### cxy0024 搬家蚂蚁★★★（12 分）

**【题目描述】**

蚂蚁搬家队搞到 n 颗糖果，第 i 颗重 aᵢ 克（整数）。要按顺序依次装进恰好 k 个箱子，每箱必须装一段连续的糖果，每颗糖必须恰好进一箱，箱子实际载重就是箱内糖果总重。

蚁后怕把公路压塌，希望最重的那箱尽量轻。请你算出：最重箱子重量的最小值是多少？

**【输入格式】**

第一行，两个整数 n 和 k。

第二行，n 个整数，表示每颗糖果的重量 a₁, a₂, …, aₙ。

**【输出格式】**

一行，一个整数，表示最重箱子重量的最小值。

**【样例输入】**

```
5 3
1 2 3 4 5
```

**【样例输出】**

```
6
```

**【样例说明】**

一种装法：[1,2,3]、[4]、[5]，最重箱重 6；可以证明没有比 6 更小的方案（5 不够装，因为 5 号糖至少单独一箱，且 1+2+3 已经 6）。

**【数据范围与提示】**

- 50% 数据：n ≤ 1000
- 100% 数据：1 ≤ k ≤ n ≤ 10⁵，1 ≤ aᵢ ≤ 10⁹；提示：答案有单调性——允许的总重越大越容易装完 k 箱；试一个总重上限，从左到右贪心装箱，若能装满就缩小上限，否则放大。

### cxy0025 烤肠工坊★★★（12 分）

**【题目描述】**

烧烤摊老板有一批 n 根烤肠，第 i 根长 Lᵢ（单位：厘米）。他想把这些烤肠切成若干段长度相同的串（长度为整数厘米），一共恰好需要 k 段。每根烤肠可以切成多段，也可以留一段不切。

问：每段烤肠的最大可能长度是多少？若无论如何都切不出 k 段，则输出 0。

**【输入格式】**

第一行，两个整数 n 和 k。

第二行，n 个整数，表示每根烤肠的长度 L₁, L₂, …, Lₙ。

**【输出格式】**

一行，一个整数，表示每段烤肠的最大可能长度；切不出 k 段则输出 0。

**【样例输入】**

```
3 7
10 24 15
```

**【样例输出】**

```
6
```

**【样例说明】**

长度取 6：10 切出 1 段、24 切出 4 段、15 切出 2 段，共 1+4+2 = 7 段；若取 7，只能切出 1+3+2 = 6 段，不够 k。

**【数据范围与提示】**

- 50% 数据：n ≤ 1000，k ≤ 1000
- 100% 数据：1 ≤ n ≤ 10⁵，1 ≤ k ≤ 10⁹，1 ≤ Lᵢ ≤ 10⁹；提示：长度越大，能切出的总段数越少，单调；对每个试的长度 mid，各烤肠可出 ⌊Lᵢ/mid⌋ 段，求和与 k 比较，缩小区间。老板卖串，科学分肠。
