### cxy0053 <a href="https://fslong.iok.la/problem/cxy0053" target="_blank">打包包裹</a>★★（12 分）

**【题目描述】**

王叔叔的快递站有 n 个包裹，为了省纸箱和胶带，他要把所有包裹合并装进一个大箱：每次只能把两个箱子合并成一个（里面的东西倒在一起），合并消耗的力气等于两箱重量之和，合并后的新箱重量就是两箱之和。王叔叔每次都挑当前最轻的两个箱子先合并，最少要消耗多少力气？

**【输入格式】**

第一行，一个整数 n。

第二行，n 个整数 a₁, a₂, …, aₙ，表示每个包裹的重量。

**【输出格式】**

一个整数，表示最少消耗的力气。

**【样例输入】**

```
3
1 2 9
```

**【样例输出】**

```
15
```

**【样例说明】**

先合并 1 和 2 两个箱子：消耗力气 3，新箱重 3；再合并 3 和 9：消耗 12，总共 3+12=15。若先合并 1 和 9（消耗 10），再合并 10 和 2（消耗 12），总共 22，更费力气。

**【数据范围与提示】**

2 ≤ n ≤ 10⁵，1 ≤ aᵢ ≤ 10⁴，答案 ≤ 2×10¹⁰（请用 long long）。提示：每次合并选最轻的两箱——用小根堆 `priority_queue<int, vector<int>, greater<int>>` 取出两个最小值、合并后放回，直到只剩一个箱子。贪心依据：轻箱子参与合并的次数越多越省力（哈夫曼思想）。

### cxy0054 <a href="https://fslong.iok.la/problem/cxy0054" target="_blank">奶茶订单</a>★★★（12 分）

**【题目描述】**

冯阿姨的奶茶店一天会收到 n 个外卖订单。第 i 个订单需要 tᵢ 分钟制作，并且顾客要求在开张后 dᵢ 分钟内送到（即完成时刻 ≤ dᵢ）。店里一次只能做一杯奶茶，完成顺序可以自由安排。冯阿姨想尽可能多地完成订单，最多能完成几个？

**【输入格式】**

第一行，一个整数 n。

接下来 n 行，每行两个整数 tᵢ、dᵢ，表示第 i 个订单的制作耗时和送到时限。

**【输出格式】**

一个整数，表示最多能完成的订单数。

**【样例输入】**

```
5
2 3
1 2
4 5
1 4
3 6
```

**【样例输出】**

```
3
```

**【样例说明】**

做 (1,2)、(2,3)、(1,4) 三单：按顺序制作，完成时刻分别为 1、3、4，都不超过各自时限；任何 4 单都排不满（第 4 单加入后总耗时必然超过它的时限）。故最多 3 单。

**【数据范围与提示】**

1 ≤ n ≤ 10⁵，1 ≤ tᵢ, dᵢ ≤ 10⁹。提示：按送到时限 d 升序排序；用大根堆（`priority_queue<int>` 默认）记录已接订单的制作耗时，总耗时超过当前时限时，退掉耗时最长的订单——这就是"反悔贪心"。

### cxy0055 <a href="https://fslong.iok.la/problem/cxy0055" target="_blank">刮奖号码</a>★★★（12 分）

**【题目描述】**

超市购物抽奖：小票背面印着一串 n 位抽奖号码（不含前导 0）。中奖规则是刮掉其中恰好 k 位，剩下的号码最小者获奖（号码越小奖品越大）。刘伯伯想知道：刮掉 k 位后能得到的最小号码是多少？（结果去掉前导 0；若全为 0 则输出 0）

**【输入格式】**

第一行，一个数字字符串 s。

第二行，一个整数 k。

**【输出格式】**

一个数字字符串，表示刮掉 k 位后能得到的最小号码。

**【样例输入】**

```
1432219
3
```

**【样例输出】**

```
1219
```

**【样例说明】**

刮掉 4、3、2 三个数字后剩 1219，是刮 3 位能得到的最小结果（如刮 1、4、3 得 2219，更大）。

**【数据范围与提示】**

1 ≤ |s| ≤ 10⁵，1 ≤ k < |s|。提示：贪心——从左到右扫描，只要还能刮（已刮 < k）且"已保留的最后一位比当前数字大"，就刮掉那一位（让更小的数字顶上来）；扫描完还没刮够 k 个，就从末尾补刮。可用 `string` 模拟栈实现。

### cxy0056 <a href="https://oj.nks-oi.top/d/Team_experience/p/T1128?tid=6a4706aa8c06f9a055db7cb5" target="_blank">倍数数组</a>★★★（12 分）

**【题目描述】**

有一个包含 N 项的数列 A₁, …, A_N，以及 N 个按钮。按下第 i 个按钮（1 ≤ i ≤ N）时，数列 A 的第 1 项到第 i 项的值都会增加 1。

现在给定一个数列 B₁, …, B_N。何老板希望通过多次按按钮，使得对于所有的 i，Aᵢ 都变成 Bᵢ 的倍数。

请你求出最少需要按按钮的次数。

**【输入格式】**

第一行为整数 N。

接下来 N 行，每行 2 个整数 Aᵢ Bᵢ。

**【输出格式】**

输出一个整数，表示最少需要按按钮的次数。

**【样例输入 1】**

```
3
3 5
2 7
9 4
```

**【样例输出 1】**

```
7
```

**【样例输入 2】**

```
7
3 1
4 1
5 9
2 6
5 3
5 8
9 7
```

**【样例输出 2】**

```
22
```

**【样例说明 1】**

按第 1 个按钮 2 次、第 2 个按钮 2 次、第 3 个按钮 3 次即可。

**【数据范围与提示】**

1 ≤ N ≤ 10⁵，0 ≤ Aᵢ ≤ 10⁹，1 ≤ Bᵢ ≤ 10⁹。提示：按钮 i 影响 A[1..i]，所以 Aᵢ 只被按钮 i, i+1, …, N 影响。从右往左决定按次：设 suf 为右侧已决定的按钮总按次，则按钮 i 需要按 c = (Bᵢ − (Aᵢ + suf) % Bᵢ) % Bᵢ 次，再累加进 suf。

### cxy0057 <a href="https://vjudge.net/contest/828010#problem/H" target="_blank">小偷</a>★★★（12 分）

**【题目描述】**

国家严峻的经济形势和政府农业补贴资金的削减，迫使米尔科再次转行，这次他决定当一名盗贼。他的第一个职业目标就是抢劫一家珠宝店。

店里共有 N 件珠宝，每件珠宝都有相应的质量 Mi 和价值 Vi。米尔科准备了 K 个袋子来装赃物，每个袋子最多能承载 Ci 的质量。为了降低逃跑过程中珠宝受损的风险，他计划将所有战利品装进这些袋子，且每个袋子最多装一件珠宝。

请计算米尔科能"解放"的珠宝最大总价值。

**【输入格式】**

第一行输入包含两个数字 N 和 K（1 ≤ N, K ≤ 300 000）。

接下来的 N 行每行包含一对数字 Mi 和 Vi（1 ≤ Mi, Vi ≤ 1 000 000）。

随后的 K 行每行包含一个数字 Ci（1 ≤ Ci ≤ 100 000 000）。

**【输出格式】**

输出仅一行，包含可能获得的最大珠宝总价值。

**【样例输入 1】**

```
2 1
5 10
100 100
11
```

**【样例输出 1】**

```
10
```

**【样例输入 2】**

```
3 2
1 65
5 23
2 99
10
2
```

**【样例输出 2】**

```
164
```

**【样例说明】**

样例 1：只有 1 个袋子（容量 11），只能装下质量 5 价值 10 的珠宝，价值 10。样例 2：两个袋子容量 10 和 2：质量 2 价值 99 的珠宝装进容量 2 的袋子，质量 1 价值 65 的装进容量 10 的袋子，共 99+65=164。
