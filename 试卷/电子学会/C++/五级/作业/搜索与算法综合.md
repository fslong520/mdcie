### cxy0064 赚钱最多（12 分）

**【题目描述】**

小明开了一家奶茶店，记录了 n 天每天的营业额（可能是负数，说明亏了）。他想找出**连续的一段时间**（至少 1 天），使这段时间的营业额总和最大，好总结经营经验。

请你写程序：输入 n 天每天的营业额，输出最大连续营业额之和。

**【输入格式】**

第一行，一个整数 n。

第二行，n 个整数，表示每天营业额（可正可负）。

**【输出格式】**

一行，一个整数，表示最大连续营业额之和。

**【样例输入】**

```
6
-2 11 -4 13 -5 -2
```

**【样例输出】**

```
20
```

**【样例说明】**

最大连续段是第 2~4 天：11 + (−4) + 13 = 20。用"最大子段和"算法：累加过程中一旦总和变负就清零重新开始（因为负数只会拖累后面的段），同时不断更新最大值。

**【数据范围】**

1 ≤ n ≤ 100000，营业额绝对值 ≤ 10000。

### cxy0065 操场翻新（12 分）

**【题目描述】**

学校操场有 n 块地砖排成一排，每块地砖记录着"当天走过的学生人数"。维修队决定做 m 次加固：每次选择一段连续的地砖 [l, r]，给这段每块地砖的"踩踏数"都增加 k。

加固结束后，有 q 位老师分别想知道**某一块地砖**（比如第 p 块）最终的踩踏数是多少，好评估损耗。

请你写程序：处理完 m 次加固后，回答 q 次单点查询。

**【输入格式】**

第一行，三个整数 n、m、q。

第二行，n 个整数，表示每块地砖初始的踩踏数。

接下来 m 行，每行三个整数 l、r、k，表示给 [l, r] 的每块地砖都增加 k。

接下来 q 行，每行一个整数 p，表示一次查询的地砖编号。

**【输出格式】**

q 行，每行一个整数，表示第 p 块地砖最终踩踏数。

**【样例输入】**

```
5 2 3
1 1 1 1 1
1 3 2
2 4 3
1
3
5
```

**【样例输出】**

```
3
6
1
```

**【样例说明】**

初始全 1。第一次 [1,3] 加 2、第二次 [2,4] 加 3 后：第 1 块 = 1+2 = 3；第 3 块 = 1+2+3 = 6；第 5 块 = 1。用差分数组：每次区间加只需 diff[l]+=k、diff[r+1]−=k，全部操作完做一次前缀和还原，之后每次单点查询 O(1)。

**【数据范围】**

1 ≤ n ≤ 100000，1 ≤ m ≤ 100000，1 ≤ q ≤ 100000，踩踏数、k ≤ 1000。

### cxy0066 出迷宫（12 分）

**【题目描述】**

小智被困在一个 n 行 m 列的迷宫里（用字符矩阵表示，# 是墙，. 是路，S 是起点，E 是终点）。他每一步可以向上、下、左、右四个方向走一格，不能走出边界、不能走墙。

请你写程序：判断小智**能否**从 S 走到 E。用深度优先搜索（DFS）：从 S 出发，沿着一条路一直往前走，走不通就回头换一条路，把所有能到达的格子都走一遍，看看终点 E 在不在其中。

**【输入格式】**

第一行，两个整数 n、m。

接下来 n 行，每行 m 个字符，表示迷宫（保证 S、E 各只有一个）。

**【输出格式】**

一行，若小智能从 S 走到 E，输出 `yes`；否则输出 `no`。

**【样例输入 1】**

```
4 4
S...
..#.
..#.
...E
```

**【样例输出 1】**

```
yes
```

**【样例输入 2】**

```
3 3
S#.
###
..E
```

**【样例输出 2】**

```
no
```

**【样例说明】**

样例 1：从 S 可以沿着路一直走到 E，输出 yes。
样例 2：S 被墙围住，无法到达 E，输出 no。DFS 从 S 出发四个方向都走不通（全是墙或已访问），回溯结束，E 未被访问到。

**【数据范围】**

1 ≤ n、m ≤ 100。

### YY0010 狙击演习（12 分）

**【题目描述】**

何老板在机房外面搭建了一个 N×N 的正方形全息模拟演练基地（1 ≤ N ≤ 100）。基地里有 K 个全息训练靶标（1 ≤ K ≤ 1e5），何老板手持一把高科技全向激光枪：激活时可以同时向 8 个方向发射激光束——正东、正西、正南、正北、东北、东南、西北、西南（斜向与正方向夹角 45°），激光无限穿透。

何老板想找一个完美的狙击位置（某个格子），使在这个位置开枪能同时击中所有靶标（与靶标同格也算命中）。请计算整个基地里一共有多少个格子可以作为这样的完美狙击点。

**【输入格式】**

第一行，两个整数 N、K。

接下来 K 行，每行两个整数 R、C，表示靶标所在的行号和列号（从 1 开始）。可能有多个靶标重叠在同一格。

**【输出格式】**

一行，一个整数，表示完美狙击点的格子数量。

**【样例输入】**

```
4 3
2 1
2 3
4 1
```

**【样例输出】**

```
5
```

**【样例说明】**

完美狙击点为 (2,1)、(2,3)、(3,2)、(4,1)、(4,3) 共 5 个：每个点与三个靶标都同行、同列或同 45° 斜线。

**【数据范围】**

1 ≤ N ≤ 100，1 ≤ K ≤ 100000。

### YY0011 <a href="https://fslong.iok.la/problem/YY0011" target="_blank">排队调整</a>★★★（12 分）

**【题目描述】**

体育课按身高排队，n 个同学排成一排，每个人的身高记录在数组里。老师要求队伍按身高**从小到大**排好，但一次只能交换**相邻**两个同学的位置。

请你计算：至少需要多少次相邻交换，才能让队伍按身高从小到大排好？

（提示：相邻交换排好序所需的最少次数，等于序列中的"逆序对"数量——即有多少对 (i, j) 满足 i < j 且 a[i] > a[j]。可以用归并排序在 O(n log n) 时间内统计。）

**【输入格式】**

第一行，一个整数 n。

第二行，n 个整数，表示每个同学的身高。

**【输出格式】**

一行，一个整数，表示最少需要的相邻交换次数。

**【样例输入 1】**

```
5
3 1 2 4 5
```

**【样例输出 1】**

```
2
```

**【样例输入 2】**

```
4
4 3 2 1
```

**【样例输出 2】**

```
6
```

**【样例说明】**

样例 1：序列 3 1 2 4 5 的逆序对是 (3,1)、(3,2) 共 2 对，最少 2 次交换。
样例 2：序列 4 3 2 1 完全逆序，逆序对 = 4×3/2 = 6 对，最少 6 次交换。

**【数据范围】**

1 ≤ n ≤ 100000，身高 ≤ 10^9。
