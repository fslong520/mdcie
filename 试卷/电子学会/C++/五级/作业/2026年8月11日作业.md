### cxy0043 <a href="https://fslong.iok.la/problem/cxy0043" target="_blank">射气球</a>★★（12 分）

**【题目描述】**

游乐场的射击摊换了个新玩法：一排 n 个气球，第 i 个气球占据水平方向 [lᵢ, rᵢ] 这一段，只要箭射在这段内，气球就破。一箭射出去，所有被射中的气球（箭的落点在它们范围内）会一起破。老板想用最少的箭把所有气球都射破，请问最少需要几箭？

**【输入格式】**

第一行一个整数 t，表示测试组数。每组：第一行一个整数 n；接下来 n 行，每行两个整数 lᵢ、rᵢ，表示第 i 个气球占据的范围。

**【输出格式】**

每组一行，一个整数，表示最少的箭数。

**【样例输入】**

```
2
4
1 6
2 8
7 12
10 16
3
1 2
3 4
5 6
```

**【样例输出】**

```
2
3
```

**【样例说明】**

第 1 组：第 1 箭射在 6，射破 [1,6] 和 [2,8]；第 2 箭射在 12，射破 [7,12] 和 [10,16]，共 2 箭。第 2 组：三个气球互不重叠，只能一箭一个，共 3 箭。

**【数据范围与提示】**

1 ≤ t ≤ 10，1 ≤ n ≤ 10⁵，Σn ≤ 10⁵，1 ≤ lᵢ ≤ rᵢ ≤ 10⁹。提示：区间选点贪心——按右端点升序排序，当前箭没射到的第一个气球，就把箭射在它的右端点：右端点能带走的后续气球最多。

### cxy0045 <a href="https://fslong.iok.la/problem/cxy0045" target="_blank">视频拼接</a>★★（12 分）

**【题目描述】**

小程剪视频要凑一段完整的"日出延时"：整段目标时长 L 秒（覆盖时间 0 到 L）。他手里有 m 段素材，第 i 段覆盖时间 [aᵢ, bᵢ]（aᵢ < bᵢ，单位秒）。素材可以任意拼接——只要前一段的结束时刻 ≥ 后一段的开始时刻（正好相接也行），就能无缝接上。他想用最少的素材拼出 0 到 L 的完整片段。请问最少用几段？如果所有素材都用上也拼不满，输出 -1。

**【输入格式】**

第一行一个整数 t，表示测试组数。每组：第一行两个整数 L、m；接下来 m 行，每行两个整数 aᵢ、bᵢ，表示第 i 段素材覆盖的时间范围。

**【输出格式】**

每组一行，一个整数，表示最少需要的素材段数；拼不满则输出 -1。

**【样例输入】**

```
2
8 4
0 2
1 5
4 6
5 8
10 4
0 3
4 6
7 10
2 5
```

**【样例输出】**

```
3
-1
```

**【样例说明】**

第 1 组：L = 8。选 [0,2] 接 [1,5] 再接 [5,8]，三段拼出 [0,8]，已经最少（两段最多拼到 6）。第 2 组：L = 10，素材只能拼到 [0,6]（[0,3] → [2,5] → [4,6]），[6,10] 没有素材能接上，输出 -1。

**【数据范围与提示】**

1 ≤ t ≤ 10，1 ≤ L ≤ 10⁹，1 ≤ m ≤ 10⁵，Σm ≤ 10⁵，0 ≤ aᵢ < bᵢ ≤ 10⁹。提示：区间覆盖贪心（K 窗口）——素材按左端点升序排序；维护已拼到的最右时刻 cur，每轮在"左端 ≤ cur"的素材里挑右端最远的一段接上；若挑不出能接上的且 cur < L，就是拼不满。

### cxy0046 <a href="https://fslong.iok.la/problem/cxy0046" target="_blank">修路队</a>★★（12 分）

**【题目描述】**

市政要修一条 L 米长的公路（位置 0 到 L）。承包公司派出 n 支工程队，第 i 支队伍负责修 [aᵢ, bᵢ] 这一段，队伍之间可以重叠施工。领导想派尽量少的队伍把整条路都覆盖到（每一米至少有一支队伍修，可以重叠），请问最少派几支队伍？如果所有队伍都派上也盖不满，输出 -1。

**【输入格式】**

第一行一个整数 t，表示测试组数。每组：第一行两个整数 L、n；接下来 n 行，每行两个整数 aᵢ、bᵢ，表示第 i 支队伍负责修的范围。

**【输出格式】**

每组一行，一个整数，表示最少的队伍数；盖不满则输出 -1。

**【样例输入】**

```
2
10 5
0 3
2 8
4 5
7 9
9 10
6 3
0 2
1 4
4 6
```

**【样例输出】**

```
4
3
```

**【样例说明】**

第 1 组：L = 10。派 [0,3] → [2,8] → [7,9] → [9,10] 四支队伍，覆盖 [0,10]；三支必然不够。第 2 组：L = 6，派 [0,2] → [1,4] → [4,6] 三支覆盖 [0,6]。

**【数据范围与提示】**

1 ≤ t ≤ 10，1 ≤ L ≤ 10⁹，1 ≤ n ≤ 10⁵，Σn ≤ 10⁵，0 ≤ aᵢ < bᵢ ≤ L。提示：区间覆盖——按左端点升序排序，维护已覆盖到的最右位置 cur，每轮挑"左端 ≤ cur 且右端最远"的队伍；若出现没有队伍能接上且 cur < L，输出 -1。

### cxy0034 <a href="https://fslong.iok.la/problem/cxy0034" target="_blank">最小化</a>★★（12 分）

**【题目描述】**

有一个长度为 N 的序列 A₁, A₂, ..., A_N，最开始这个序列是 1∼N 的一个排列。在这个序列上，每次操作：选择序列中连续的 K 个元素，然后把这 K 个元素都变为这 K 个元素中的最小值。目标是把整个序列的元素都变为相等的元素，求最少需要的操作次数。

**【输入格式】**

第一行两个正整数 N、K（2 ≤ K ≤ N ≤ 10⁵）。第二行 N 个整数 A₁, A₂, ..., A_N，构成一个排列。

**【输出格式】**

输出最少需要的操作次数。

**【样例输入】**

```
4 3
2 3 1 4
```

**【样例输出】**

```
2
```

**【样例说明】**

第一次操作选择前 3 个数，变为 1,1,1,4；第二次操作选择后 3 个数，变为 1,1,1,1。

**【数据范围与提示】**

2 ≤ K ≤ N ≤ 10⁵。提示：终值必是全局最小值；从左到右遇到非最小值的元素就做一次覆盖它的操作，贪心计数。
### cxy0035 <a href="https://fslong.iok.la/problem/cxy0035" target="_blank">箱子和球</a>★★（12 分）

**【题目描述】**

有 n 个盒子，起初每个盒子里有 1 个球，1 号盒子里的球是红色的，其余都是白色的。现在给定 m 个操作，每次给出二元组 (xᵢ, yᵢ) 表示从 xᵢ 号盒子中随机拿出一个球放进 yᵢ 号盒子。求在操作结束后有多少个盒子里可能装着红色小球。

**【输入格式】**

第一行两个数 n、m（2 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁵）。接下来 m 行，每行两个数 xᵢ、yᵢ，保证 1 ≤ xᵢ, yᵢ ≤ n 且 xᵢ ≠ yᵢ，且进行第 i 次操作前盒子 xᵢ 中至少有 1 个球。

**【输出格式】**

一个数表示所求答案。

**【样例输入】**

```
3 2
1 2
2 3
```

**【样例输出】**

```
2
```

**【样例说明】**

第一次操作后盒子 1 空、盒子 2 中有红球和白球。第二次操作：若从盒子 2 选中红球，红球进盒子 3；若选中白球，红球留在盒子 2。所以可能装红球的盒子数是 2。

**【数据范围与提示】**

2 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁵。提示：维护"红球可能位置"集合 S，并记录每个盒子当前球数：若 x ∈ S 且 x 盒只剩红球一球，则 S = {y}；若 x ∈ S 且 x 盒还有白球，则 S = S ∪ {y}；若 x ∉ S，红球位置不变。
