### 第 1 题（快速幂）冯阿姨的面包店搞"集章翻倍"活动，小程写快速幂代码算第 b 天的集章数，循环体里有一句 `if (b & 1) ans = ans * a % m;`。请问当 `b & 1` 的结果为 1 时，说明？（ ）

- A. 循环立刻结束，直接输出 ans
- B. 这一轮不需要做任何乘法
- C. 底数 a 要被清零，重新开始
- D. 指数 b 的当前最低位是 1，对应的底数幂要乘进答案

**答案：D**

**解析：** `b & 1` 取出 b 的最低二进制位：为 1 说明该位对应的幂次（当前的 a）参与最终结果，乘入 ans；为 0 则跳过。它和 `a = a * a % m`（底数自乘）配合，逐个处理 b 的每一位。

### 第 2 题（递推）刘伯伯在小区健身角数台阶：上 n 级台阶，每次可以跨 1 级或 2 级，走法总数满足 f(n) = f(n−1) + f(n−2)。他先用普通递归写，发现同一个 f(k) 被反复算；后来加了张"算过就记下来"的备忘纸条。加上备忘后，每个 f(k) 真正被计算的次数至多是？（ ）

- A. 2 次
- B. n 次
- C. 1 次
- D. 每次递归都要重算

**答案：C**

**解析：** 记忆化（备忘录）：每个 f(k) 第一次算出后存入纸条，再被需要时直接取用，每个子问题最多只算 1 次——这就是"记忆化搜索"，递推思想的递归版本。

### 第 3 题（贪心·区间选点）小区晾衣绳上挂了一排刚洗好的衣服，每件衣服占绳子上一段位置（用起点、终点表示）。只要夹子夹在衣服所占的位置上，衣服就不会掉；一件衣服被一个夹子夹住就行，夹子可以同时夹住位置重叠的多件衣服。要用的夹子最少，应该怎么夹？（ ）

- A. 按起点从左到右排，夹子夹在每件衣服的起点
- B. 按衣服长度从短到长排，夹子夹在衣服中间
- C. 随便夹，夹子数量都一样
- D. 按终点从左到右排，遇到没被夹住的衣服，就夹在它的终点

**答案：D**

**解析：** 区间选点贪心：按右端点升序排序，当前夹子没夹到这件衣服时，就夹在它的右端点——右端点能覆盖尽量多的后续衣服。钉在未覆盖区间的右端点，是选点问题的标准做法。

### 第 4 题（前缀和）王叔叔的快递站记录每天收的包裹数，第 i 天的数量存在 aᵢ 里，他先算好前缀和 pre[i] = a₁ + a₂ + … + aᵢ。后来他想核对每天原始的数量。问：知道 pre 之后，怎样还原出 aᵢ？（ ）

- A. 对 pre 再求一次前缀和
- B. 对 pre 求差分：aᵢ = pre[i] − pre[i−1]
- C. 把 pre 里的数全部开平方
- D. 对 pre 从大到小排序

**答案：B**

**解析：** 前缀和是"逐项累加"，还原就是"逐项相减"：aᵢ = pre[i] − pre[i−1]，即求差分。前缀和与差分互为逆运算。

### 第 5 题（差分）深夜给便利店货架贴价签：m 次操作，每次把第 l 号到第 r 号货架的价格统一上调 k 元，最后要打印所有货架的最终价。用差分数组做，每次操作只在 diff[l] 和 diff[r+1] 两处标记，最后统一求一次前缀和。总时间复杂度是？（ ）

- A. O(m×n)
- B. O(n×m log m)
- C. O(n+m)
- D. O(m)

**答案：C**

**解析：** m 次区间加，每次 O(1) 标记，共 O(m)；最后统一求一次前缀和 O(n) 还原。总 O(n+m)，比每次现场改整段（O(nm)）快得多。

### 第 6 题（二分）刘伯伯的手机通讯录里存着一排门牌号（已升序）：1、3、3、5、7。他用 `lower_bound` 找"第一个 ≥ 4 的门牌号"，找到的位置是？（下标从 0 开始）

- A. 下标 2
- B. 下标 3
- C. 下标 4
- D. 下标 5

**答案：B**

**解析：** lower_bound 返回第一个不小于 x 的位置：数组 1(0)、3(1)、3(2)、5(3)、7(4)，第一个 ≥ 4 的是 5，下标 3。"第一个 ≥ x"正是 lower_bound 的标准语义。

### 第 7 题（双指针）妈妈在小区快递站取包裹，包裹按顺序摆了一排，她想找"总重量 ≥ X 克的一段连续包裹，最少要几件"。她左右各用一个指针框出一段，当前框内总重还不够 X 克，下一步应该？（ ）

- A. 左指针右移，让框变小
- B. 两个指针一起右移
- C. 立即停手，这段就是答案
- D. 右指针右移，把更多包裹框进来

**答案：D**

**解析：** 滑动窗口"不够就伸"：总重不足 X 时只能把右指针往右伸、纳入更多包裹；够了才记长度、缩左指针。一伸一缩滑到底，O(n) 找出最短段。

### 第 8 题（STL 堆）冯阿姨在菜市场比价，想随时拿到"当前最便宜的鸡蛋价"，需要一个小根堆（最小值优先）。正确的写法是？（ ）

- A. `priority_queue<int> pq;`
- B. `priority_queue<int, vector<int>, greater<int>> pq;`
- C. `priority_queue<int, less<int>> pq;`
- D. `queue<int> pq;`

**答案：B**

**解析：** `priority_queue` 默认是大根堆；要小根堆需指定容器和比较器：`priority_queue<int, vector<int>, greater<int>>`，堆顶 `top()` 就是最小值。

### 第 9 题（贪心·区间覆盖）公园沿着湖边修了一条 L 米长的步道，要装监控摄像头，每个摄像头能照到一段。管理员已经在步道上照到了 0 到 30 米（已覆盖到 30 米），接下来该挑哪个摄像头，才能保证最后用的摄像头总数最少？（ ）

- A. 能接上 30 米、又能照得最远的那一个
- B. 离 30 米最近的那一个
- C. 最便宜的那一个
- D. 随便挑一个能接上的

**答案：A**

**解析：** 区间覆盖贪心：每一步都选"左端 ≤ 当前已覆盖位置、右端最远"的区间，把已覆盖范围延伸得最远——局部延伸最远，全局段数最少。这就是 K 窗口贪心。

### 第 10 题（STL string）快递单号存成 `string` 后，王叔叔想判断两个单号是不是同一个，直接写 `if (s1 == s2)`。`==` 比较的是？（ ）

- A. 两个字符串的内容（逐字符）
- B. 两个 string 对象在内存中的地址
- C. 两个字符串的长度
- D. 两个字符串的首字符

**答案：A**

**解析：** `string` 重载了 `==`，比较的是内容（长度与每个字符），与地址无关。C 风格 `char*` 用 `==` 才比较地址，string 不用。

### 第 11 题（递推）只要给出了递推关系式，即使没有给出任何初始条件（初值），也能把数列的所有项都推出来。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 递推关系只说明"后项如何由前项得出"，起点（初值）不给定，链条就无从开始——初值与递推式缺一不可。

### 第 12 题（贪心·交换论证）证明区间选点贪心正确时，可以假设最优解与贪心解不同，然后通过"交换"把最优解逐步调整成贪心解、且不破坏最优性，这种证明方法叫交换论证。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 交换论证：任取一个最优解，若它与贪心解不同，通过交换元素把它"改造成"贪心解而不变差，说明贪心解也最优。决策包容性是它的变体。

### 第 13 题（贪心·区间选点）区间选点问题（最少钉子固定所有区间）中，按左端点升序排序后直接贪心，与按右端点升序排序效果完全等价，都能保证最优。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 区间选点的标准做法是按右端点升序排序，钉在未覆盖区间的右端点。按左端点排序并不能直接套用同样策略保证最优——两种排序不是等价的。

---

### 第 14 题（贪心·区间覆盖）区间覆盖问题中，每一步都选择"左端能接上当前已覆盖范围、右端延伸最远"的区间，这样选出的区间数一定是最少的。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 每一步延伸最远，给后续留下的"待覆盖尾巴"最短——用交换论证可证这是最优策略。选更近的区间只会多耗段数。

### 第 15 题（贪心 vs 动态规划）判断一个问题能不能用贪心时：若子问题相互独立、局部最优能拼出全局最优，贪心可行；若子问题相互重叠、互相影响，贪心可能失效，应考虑动态规划。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 贪心要求"决策包容性"（当前最优不堵死后面的路）；子问题重叠时，局部最优可能互相冲突（如带权区间调度），必须用 DP 记录状态。

---

### 第 16 题（贪心·区间覆盖）区间覆盖问题中，覆盖范围既然可以重叠，那么随便选一段"能接上当前已覆盖范围"的区间就行，不需要比较谁的右端更远。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 能接上只是"合格"，不代表最优。必须挑能接上且延伸最远的，否则可能多用好几段。贪心每一步都要选当前最优，而非随便合格。

---

### 第 17 题（STL string）`string` 的 `find()` 在找不到子串时会返回 `string::npos`（一个很大的值），所以判断是否找到应写 `s.find(t) != string::npos`。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `find` 返回子串起始下标；找不到返回 `npos`（通常等于 size_t 的最大值），不能当普通下标用，必须与 `npos` 比较。

---

### 第 18 题（快速幂）快速幂代码中 `while (b)` 每执行一轮，指数 b 的二进制位数就减少一位，所以总轮数约等于 b 的二进制位数（约 log₂b）。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 每轮 `b >>= 1` 把 b 右移一位，从最低位到最高位逐位处理完即停，轮数 = 二进制位数 ≈ log₂b——这正是快速幂 O(log b) 的来源。

---

### 第 19 题（双指针）滑动窗口中，只要右指针已经扫到数组末尾，就可以直接输出答案停止——左指针不用再动了。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 右指针到尾只代表"窗口右边界到头了"，左指针仍要继续右移收缩窗口，试探是否存在更短/更优的解，直到左指针也到尾才算扫完。

### 第 20 题（贪心·区间选点）区间选点问题中，钉子可以钉在区间的端点处（左右端点都算在区间内），把钉子钉在端点与钉在区间内部效果一样。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 区间是闭区间（含端点），钉在端点照样"穿"过该区间。所以贪心把钉子钉在未覆盖区间的右端点（端点位置）是合法的，还便于覆盖后续区间。

-1

### cxy0046 <a href="https://fslong.iok.la/problem/cxy0046" target="_blank">修路队</a>★★（12 分）

**【题目描述】**

市政要修一条 L 米长的公路（位置 0 到 L）。承包公司派出 n 支工程队，第 i 支队伍负责修 [aᵢ, bᵢ] 这一段，队伍之间可以重叠施工。领导想派尽量少的队伍把整条路都覆盖到（每一米至少有一支队伍修，可以重叠），请问最少派几支队伍？如果所有队伍都派上也盖不满，输出 -1。

**【输入格式】**

第一行一个整数 t，表示测试组数。每组：第一行两个整数 L、n；接下来 n 行，每行两个整数 aᵢ、bᵢ，表示第 i 支队伍负责修的范围。

**【输出格式】**

每组一行，一个整数，表示最少的队伍数；盖不满则输出 -1。

**【样例输入】**

```
2
10 5
0 3
2 8
4 5
7 9
9 10
6 3
0 2
1 4
4 6
```

**【样例输出】**

```
4
3
```

**【样例说明】**

第 1 组：L = 10。派 [0,3] → [2,8] → [7,9] → [9,10] 四支队伍，覆盖 [0,10]；三支必然不够。第 2 组：L = 6，派 [0,2] → [1,4] → [4,6] 三支覆盖 [0,6]。

**【数据范围与提示】**

1 ≤ t ≤ 10，1 ≤ L ≤ 10⁹，1 ≤ n ≤ 10⁵，Σn ≤ 10⁵，0 ≤ aᵢ < bᵢ ≤ L。提示：区间覆盖——按左端点升序排序，维护已覆盖到的最右位置 cur，每轮挑"左端 ≤ cur 且右端最远"的队伍；若出现没有队伍能接上且 cur < L，输出 -1。

### yy0006 <a href="https://fslong.iok.la/problem/YY0006" target="_blank">立方体游戏</a>★（12 分）

**【题目描述】**

桌子上竖直堆放着 N 个立方体。给定一个长度为 N 的字符串 S。从下往上数，第 i 个立方体的颜色由 S 的第 i 个字符决定：若为 0 则为红色，若为 1 则为蓝色。可以多次选择一对相邻的红色和蓝色立方体并将这两个一起移除。被移除立方体上方的立方体会直接落到下方物体上面。求最多可以移除多少个立方体。

**【输入格式】**

输入一个字符串 S。

**【输出格式】**

一行，一个整数，表示最多可以移除的立方体个数。

**【样例输入 1】**

```
0011
```

**【样例输出 1】**

```
4
```

**【样例输入 2】**

```
11011010001011
```

**【样例输出 2】**

```
12
```

**【样例输入 3】**

```
0
```

**【样例输出 3】**

```
0
```

**【样例说明】**

样例 1：0011 中 0 有 2 个、1 有 2 个，最多配 min(2, 2) = 2 对，即移除 4 个。样例 2：0 有 6 个、1 有 8 个，最多配 6 对，即 12 个。样例 3：只有一个立方体，没有相邻异色对，移除 0 个。

**【数据范围与提示】**

1 ≤ N ≤ 10⁵，|S| = N，S 的每个字符是 0 或 1。提示：每次移除一红一蓝、上方落下，剩下立方体的相对顺序始终不变——问题等价于"任意选出互不影响的异色对"。答案 = 2 × min(红色数, 蓝色数)，只需一遍计数，O(N)。

### yy0007 <a href="https://fslong.iok.la/problem/YY0007" target="_blank">一维翻转棋</a>★（12 分）

**【题目描述】**

呆呆很喜欢在电脑上玩翻转棋，但是水平很菜，经常被虐，所以他决定对翻转棋进行降维打击。降维打击后，所有的棋子只能排成一排，新的棋子可以放在这一排的任意一端。棋子有黑白两种颜色，黑色用 B 表示，白色用 W 表示。每当有新棋子落下时，新棋子和另一枚与新棋子颜色相同并且距离最近的棋子之间的所有棋子，都会变成和新棋子一样的颜色。呆呆随机摆放了一排棋子，问你在满足规则的情况下，最少新添加几枚棋子，可以让所有棋子的颜色都相同。

**【输入格式】**

第一行，一个只由 B 和 W 组成的字符串 S，1 ≤ |S| ≤ 10⁵。

**【输出格式】**

一行，一个整数，表示最少添加的棋子数量。

**【样例输入 1】**

```
WBWBWBWBWB
```

**【样例输出 1】**

```
9
```

**【样例输入 2】**

```
WWWWWW
```

**【样例输出 2】**

```
0
```

**【样例输入 3】**

```
BBBWW
```

**【样例输出 3】**

```
1
```

**【样例说明】**

样例 1：WBWBWBWBWB 中相邻颜色不同的对共有 9 对，每放一颗新棋子最多消灭一段异色边界，所以最少添加 9 颗。样例 2：整排已经是白色，不需要添加。样例 3：BBBWW 只有 B−W 一处相邻不同色，添加 1 颗即可。

**【数据范围与提示】**

1 ≤ |S| ≤ 10⁵。提示：每次放子最多让"相邻不同色对数"减少 1——放对颜色的棋子，正好可以把一段异色边界翻平；最终全同色时相邻不同色对数为 0，所以最少添加数 = 相邻不同色对数（= 连续同色段数 − 1）。一遍扫描，O(|S|)。
