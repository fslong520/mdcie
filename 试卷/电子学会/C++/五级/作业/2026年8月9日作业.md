### cxy0038 <a href="https://fslong.iok.la/problem/cxy0038" target="_blank">抢课</a>★（12 分）

**【题目描述】**

又到选课季，小明研究了一天课表：学校把一天分成很多节课，第 i 门候选课在第 aᵢ 节课开始时开课，连着上 bᵢ 节。只要后一门课的开课节数 ≥ 前一门课的结束节数，两门课就能都选上（正好衔接也行）。小明精力有限，请问他一天最多能选几门课？

**【输入格式】**

第一行一个整数 n。接下来 n 行，每行两个整数 aᵢ、bᵢ，表示第 i 门课的开始节数和持续节数。

**【输出格式】**

一个整数，表示最多能选的课数。

**【样例输入】**

```
5
1 2
2 1
3 2
0 1
4 1
```

**【样例输出】**

```
3
```

**【样例说明】**

第 1 门课占第 1~3 节，第 2 门占 2~3 节，第 3 门占 3~5 节，第 4 门占 0~1 节，第 5 门占 4~5 节。选第 4 门（0~1）、第 1 门（1~3 衔接）、第 3 门（3~5 衔接），共 3 门，别的组合最多也是 3 门。

**【数据范围与提示】**

1 ≤ n ≤ 10⁵，0 ≤ aᵢ ≤ 10⁹，1 ≤ bᵢ ≤ 10⁹。提示：每门课到底占用了哪些节？先把"占用的节数范围"想清楚，再琢磨——按什么顺序挑课，才能让后面可选的课尽量多？

### cxy0039 <a href="https://fslong.iok.la/problem/cxy0039" target="_blank">游戏任务</a>★★★（12 分）

**【题目描述】**

游戏出了限时活动"守护村庄"，活动开始后共开放很多分钟。小明接了 n 个任务，第 i 个任务做完需要 tᵢ 分钟，若在活动开始后的 dᵢ 分钟之内（完成时刻 ≤ dᵢ）完成就算成功，能拿全部奖励。角色一次只能做一个任务，但接任务时可以随时改主意——把已经排进计划的某个任务替换掉。请问他最多能成功完成几个任务？

**【输入格式】**

第一行一个整数 n。接下来 n 行，每行两个整数 tᵢ、dᵢ，表示第 i 个任务所需分钟数和完成时限。

**【输出格式】**

一个整数，表示最多能成功完成的任务数。

**【样例输入】**

```
4
2 3
1 4
3 5
2 6
```

**【样例输出】**

```
3
```

**【样例说明】**

按时限从紧到松依次考虑：任务 1（2 分钟，第 3 分钟前）做，累计 2 分钟；任务 2（1 分钟，第 4 分钟前）做，累计 3 分钟；任务 3（3 分钟，第 5 分钟前）接进来累计 6 分钟，超时了——把计划里最耗时的一个（任务 3 自己的 3 分钟）换掉，累计回到 3 分钟；任务 4（2 分钟，第 6 分钟前）接进来累计 5 分钟，不超时。最终完成任务 1、2、4 共 3 个。

**【数据范围与提示】**

1 ≤ n ≤ 10⁵，1 ≤ tᵢ, dᵢ ≤ 10⁹，答案不超过 n。提示：时限越紧的任务越该优先考虑；可当累计时间眼看要超限时，想一想：把计划里哪个任务"踢"出去，损失才最小？怎么才能随时快速找到它？

### cxy0040 <a href="https://fslong.iok.la/problem/cxy0040" target="_blank">健身器械</a>★★（12 分）

**【题目描述】**

健身房新到了一批跑步机，一天里 n 个人预约使用，第 i 个人从 aᵢ 分钟开始练，打算练 bᵢ 分钟。一台跑步机同一时间只能一个人用；前一个人练完的时刻 ≤ 后一个人的开始时刻，就可以接着用同一台。请问健身房至少需要准备几台跑步机，才能让所有人都按时练上？

**【输入格式】**

第一行一个整数 n。接下来 n 行，每行两个整数 aᵢ、bᵢ，表示第 i 个人的开始分钟数和持续分钟数。

**【输出格式】**

一个整数，表示最少需要的跑步机台数。

**【样例输入】**

```
5
60 40
90 30
120 50
100 60
170 30
```

**【样例输出】**

```
2
```

**【样例说明】**

第 1 人练 60~100 分钟，第 2 人 90~120，第 3 人 120~170，第 4 人 100~160，第 5 人 170~200。安排：1 号机：第 1 人（60~100）、第 4 人（100~160）；2 号机：第 2 人（90~120）、第 3 人（120~170）、第 5 人（170~200）。两人都守约，共 2 台；1 台必然不够（60~100 与 90~120 重叠）。

**【数据范围与提示】**

1 ≤ n ≤ 10⁵，0 ≤ aᵢ ≤ 10⁹，1 ≤ bᵢ ≤ 10⁹。提示：先把每人的"结束分钟数"算出来。机器什么时候能空出来？想清楚之后，按开始时间先后一台一台安排，随时知道"当前最早空出的跑步机是哪台、什么时刻空出"。

### cxy0041 <a href="https://fslong.iok.la/problem/cxy0041" target="_blank">寒假兼职</a>★★（12 分）

寒假有 n 天（第 1、2、…、n 天），小明想打工攒钱。他打听到 n 份兼职：第 i 份干一天就能拿 pᵢ 元，但老板要求必须在寒假第 dᵢ 天结束前干完（第 1~dᵢ 天里任选一天都行），而且小明一天只能干一份。请问他最多能赚多少钱？

**【输入格式】**

### cxy0042 <a href="https://fslong.iok.la/problem/cxy0042" target="_blank">路灯照明</a>★★（12 分）

**【题目描述】**

小区门口一条 L 米长的马路（位置 1 到 L），路边装了 m 盏路灯，第 i 盏灯在位置 xᵢ 处，照明半径 rᵢ 米，能照亮 [xᵢ − rᵢ, xᵢ + rᵢ] 这一段。为了省电，管理员想尽量少开灯，但要求整条马路都被照亮（多盏灯的照明范围可以重叠）。请问最少开几盏灯？如果全开也照亮不了整条马路，输出 -1。

**【输入格式】**

第一行两个整数 L、m。接下来 m 行，每行两个整数 xᵢ、rᵢ，表示第 i 盏灯的位置和照明半径。

**【输出格式】**

一个整数，表示最少需要打开的路灯数；无法照亮整条路则输出 -1。

**【样例输入】**

```
10 4
3 2
6 3
5 4
9 2
```

**【样例输出】**

```
2
```

**【样例说明】**

四盏灯分别照亮 [1,5]、[3,9]、[1,9]、[7,10]。开位置 5、半径 4 的那盏（照 1~9），再开位置 9、半径 2 的那盏（照 7~10），两盏就把 1~10 全照亮了。其余组合都盖不满。

**【数据范围与提示】**

1 ≤ L ≤ 10⁹，1 ≤ m ≤ 10⁵，1 ≤ xᵢ ≤ L，0 ≤ rᵢ ≤ 10⁹（照明范围可以超出马路两端）。提示：先算清每盏灯照亮的是哪一段。从马路这头开始，每次挑一盏"能接上已照亮范围、又能照得最远"的灯，直到照到另一头；中间接不上就是盖不满。
