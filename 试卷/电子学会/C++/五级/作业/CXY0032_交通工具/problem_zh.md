# 交通工具

一个国家有 6 座城市，城市之间有 5 种交通工具：火车花费 1 分钟从城市 1 到城市 2，最多载 A 人；巴士花费 1 分钟从城市 2 到城市 3，最多载 B 人；出租车花费 1 分钟从城市 3 到城市 4，最多载 C 人；飞机花费 1 分钟从城市 4 到城市 5，最多载 D 人；轮船花费 1 分钟从城市 5 到城市 6，最多载 E 人。对于每一种交通工具，同一时间只有一个在运行（但 5 种交通工具可以同时运行）。有 N 个人在城市 1，他们都想去城市 6，请求出他们最少花费多少时间能全部到达城市 6。

【输入格式】6 行，分别输入 N、A、B、C、D、E。

【输出格式】输出所有人抵达终点所需的最少时间，单位为分钟。

【样例输入 1】
```
5
3
2
4
3
5
```
【样例输出 1】
```
7
```
【样例输入 2】
```
10
5
5
5
5
5
```
【样例输出 2】
```
6
```
【数据范围】1 ≤ N, A, B, C, D, E ≤ 10¹⁵，注意使用 64 位整数。

#### 知识点与难度

本题涉及知识点：**模拟、贪心、瓶颈**，难度（CF Rating）：**1200**。
