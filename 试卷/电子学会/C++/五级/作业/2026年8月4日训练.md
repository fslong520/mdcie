### cxy0006 双人跳绳★★（12 分）

**【题目描述】**

体育节有双人跳绳项目：两个搭档的身高之和恰好等于默契值 X 时，跳得最齐。全班 n 个同学的身高记在一张名单上（顺序杂乱）。班主任想知道，有没有两个同学的身高和正好等于 X。若有，请把这两个身高找出来。

**【输入格式】**

第一行，两个整数 n 和 X。
第二行，n 个整数，表示 n 个同学的身高（顺序杂乱）。

**【输出格式】**

若存在两个身高之和等于 X，输出这两个身高（从小到大，空格隔开，任一组即可）；若不存在，输出 `No`。

**【样例输入】**

```
5 170
90 100 80 85 75
```

**【样例输出】**

```
80 90
```

### cxy0007 接车厢★★（12 分）

**【题目描述】**

两列玩具火车停在同一站台，每列车厢上的编号都已从小到大排好。小明想把两列车的车厢按编号接成一整列，仍保持从小到大。请你帮忙输出接好后的车厢编号序列。

**【输入格式】**

第一行，两个整数 n 和 m。
第二行，n 个整数，表示第一列车的车厢编号（升序）。
第三行，m 个整数，表示第二列车的车厢编号（升序）。

**【输出格式】**

一行，n+m 个整数，合并后仍按升序排列的车厢编号。

**【样例输入】**

```
3 4
2 4 7
1 3 5 6
```

**【样例输出】**

```
1 2 3 4 5 6 7
```

### cxy0009 成绩册整理★★★（12 分）

**【题目描述】**

运动会后，成绩册的学号顺序被风吹乱。体育老师想了个办法：把整份名单从中间一分为二，左半和右半各自按学号排好，再把两条有序名单合并成一条——如此反复，直到整本整理完。这就是"先拆、后排、再合"的分治整理法。

请按这个思路，把打乱的学号从小到大排好序并输出。

**【输入格式】**

第一行，一个整数 n。
第二行，n 个整数，表示打乱的学号。

**【输出格式】**

一行，n 个整数，按从小到大排序后的学号。

**【样例输入】**

```
6
5 2 4 1 3 6
```

**【样例输出】**

```
1 2 3 4 5 6
```

### cxy0010 最大逆序对和★★★（12 分）

**【题目描述】**

果老师拿到了 n 个数互不相等的数，第 i 个数为 aᵢ。如果两个位置 i、j，满足 i < j 并且 aᵢ > aⱼ，那么我们说 (aᵢ, aⱼ) 是一对逆序对。

请你找到所有逆序对中，和最大的一对，输出"和最大的逆序对"的和。题目保证至少存在一对逆序对。

**【输入格式】**

第一行，一个整数 n。
接下来一行，n 个整数，表示 a₁, a₂, …, aₙ。

**【输出格式】**

一行，一个整数，为"和最大的逆序对"的和。

**【样例输入】**

```
5
3 4 5 1 2
```

**【样例输出】**

```
7
```
