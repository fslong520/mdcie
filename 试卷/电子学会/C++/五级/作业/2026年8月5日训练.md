### 第 1 题 快速幂的核心思想：把指数 b 拆成二进制（如 13=1101₂），利用底数反复平方来跳跃式累乘。其本质是？（ ）

- A. 从底数开始逐个相乘，乘 b 次
- B. 把指数按二进制拆分，利用底数自乘来跳跃式累乘
- C. 直接用计算器
- D. 循环 b 次，每次乘 a 再取模

**答案：B**

**解析：** 快速幂把 b 的二进制位逐位扫过，遇到 1 就把当前底数乘入答案，每次底数平方，乘法次数从 O(b) 降到 O(log b)。

### 第 2 题 二分查找在数组中找目标值，循环条件应写成？（ ）

- A. l < r
- B. l > r
- C. l >= r
- D. l <= r

**答案：D**

**解析：** `while(l <= r)` 才能保证左指针超过右指针时停止；若写 `l < r` 会漏掉 l==r 时最后那个元素。

### 第 3 题 归并排序 merge 阶段，若左半 a[i] ≤ 右半 a[j]，应该？（ ）

- A. 先取右半的 a[j]
- B. 先取左半的 a[i]
- C. 两个都跳过
- D. 随便取一个

**答案：B**

**解析：** 取左半保证相等时左边先出列，维持原相对顺序，这就是归并排序稳定的实现细节。

---

### 第 4 题 已知前缀和数组 S（S[i]=a₁+a₂+...+aᵢ），区间 [l, r] 的元素和等于？（ ）

- A. S[r] − S[l−1]
- B. S[r] + S[l−1]
- C. S[r] − S[l]
- D. S[l] − S[r−1]

**答案：A**

**解析：** S[r] 包含了前 r 项，S[l−1] 包含了前 l−1 项，两者相减正好剩下 aₗ 到 aᵣ。

### 第 5 题 快速幂计算 a^b mod m 时，每步乘法后都要取模，最主要的原因是？（ ）

- A. 指数 b 会随着计算越来越大，防止指数溢出
- B. 让底数 a 变小，算起来更快
- C. 防止中间结果（如 a×a）超出数据类型范围而溢出
- D. 取模后结果一定更准确

**答案：C**

**解析：** a*a 可能超出 int/long long 范围，每步取模保持在 mod 范围内，避免中间结果溢出。

### 第 6 题 01背包问题中，贪心按价值密度排序不能保证最优，需要用什么算法？（ ）

- A. 二分查找
- B. 快速幂
- C. 动态规划
- D. 归并排序

**答案：C**

**解析：** 01背包每件物品只能选或不选，贪心无法保证全局最优，需用动态规划记录状态转移。

### 第 7 题 小刚需要存一串自动去重、并且从小到大排好序的数据。C++ 中哪个容器最合适？（ ）

- A. set
- B. vector
- C. map
- D. stack

**答案：A**

**解析：** `set` 底层红黑树，插入后自动有序且 key 不重复，正好满足"去重+排序"。

### 第 8 题 二分查找中，为避免 l+r 整数溢出，mid 的安全计算方式是？（ ）

- A. (l+r)/2
- B. (l+r)>>1
- C. l + (r-l)/2
- D. r - (r-l)/2

**答案：C**

**解析：** `l + (r-l)/2` 等价于 `(l+r)/2` 但先做减法，不会溢出；A/B 在 l、r 都很大时可能溢出 int。

### 第 9 题 快速幂递归写法中，当指数 b 为偶数时，若已算出 a^(b/2)，则 a^b =？（ ）

- A. 2 × a^(b/2)
- B. a^(b/2) × a^(b/2+1)
- C. a^(b+1) / a
- D. (a^(b/2))²

**答案：D**

**解析：** a^b = a^(2 × b/2) = (a^(b/2))²，这就是快速幂反复平方的核心公式。

---

### 第 10 题 归并排序递归拆分的终止条件是？（ ）

- A. 数组长度为 0
- B. 数组长度为 1（或 l ≥ r）
- C. 数组已有序
- D. 拆分次数达到 log₂n

**答案：B**

**解析：** 单元素天然有序，不再拆；递归到 l ≥ r 时返回。

### 第 11 题 快速幂递归写法中，当指数 b 为奇数时，a^b = a × a^(b-1)，其中 a^(b-1) 的指数是偶数。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** b 为奇数时拆出一个 a，剩余 b-1 为偶数，再用平方公式 a^(b-1) = (a^((b-1)/2))²。

---

### 第 12 题 二分查找能每次排除一半，是因为数组有序，比较后能判断目标在哪半边。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 有序是前提，比较结果直接告诉目标在左半还是右半。

### 第 13 题 归并排序 merge 时，若左半 a[i] 等于右半 a[j]，应优先取右半的 a[j]，以保证排序稳定。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 应优先取左半的 a[i]，才能让相等元素保持原相对顺序。取右半会打乱顺序，导致不稳定。

---

### 第 14 题 构造前缀和数组时，S[0] 应初始化为 a[1]，S[i] = S[i-1] + a[i]（2≤i≤n）。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** S[0] 应初始化为 0，第一项从 S[1] 开始累加。若 S[0]=a[1]，则 S[1] 会重复累加第一项。

---

### 第 15 题 贪心算法的正确性必须通过数学证明来保证。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 贪心策略必须可证明才正确。活动选择、区间覆盖等可证明；01背包等不可证明。

---

### 第 16 题 map 容器的键（key）是不允许重复的。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** map 的 key 唯一，重复插入同 key 会覆盖旧值。

### 第 17 题 `set` 容器底层是红黑树，插入一个元素的平均时间复杂度是 O(log n)。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `set` 基于平衡搜索树，每次插入沿树查找+旋转调整，代价 O(log n)。

---

### 第 18 题 `vector` 的 `pop_back()` 是 O(n) 操作。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** `pop_back()` 只需减小 size 计数，不移动元素，是 O(1)；头部 `pop_front()` 才是 O(n)。

---

### 第 19 题 快速幂递归实现中，当指数 b=1 时直接返回 base 本身。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 严格递归版本里 b=1 时走 b%2==1 分支，返回 base × pow(base, 0) = base × 1，结果正确但不是"直接返回"；若 base=0 则 pow(0,0)=1，逻辑不同。考试中此说法不严谨。

---

### 第 20 题 快速幂的时间复杂度是 O(b)。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 快速幂是 O(log b)，不是 O(b)。

### cxy0016 快速幂入门★★（12 分）

**【题目描述】**

求 a^b mod m 的值。这是快速幂的经典入门题。

**【输入格式】**

一行，三个非负整数 a、b、m（0 ≤ a, m ≤ 10⁹+7，0 ≤ b ≤ 10¹⁸）。

**【输出格式】**

一行，a^b mod m 的结果。

**【样例输入】**

```
2 10 1000
```

**【样例输出】**

```
24
```

**【数据范围】**

- 30% 数据：b ≤ 10⁶
- 100% 数据：0 ≤ b ≤ 10¹⁸，m ≤ 10⁹+7
- 提示：a^b 可能极大，不能直接算，必须用快速幂在 O(log b) 内完成；注意 m=1 时结果为 0；当 a=0 且 b=0 时，0⁰ 在数学上定义为 1（竞赛惯例）。

### cxy0019 高速公路交叉点★★★（12 分）

**【题目描述】**

J 国是狭长的岛国，东海岸有 N 座城市，西海岸有 M 座城市（均按从北到南编号 1~N、1~M）。现要建造 K 条高速公路，每条连接东海岸某城市与西海岸某城市。若两条高速的东岸编号顺序与西岸编号顺序相反，则它们会在中间交叉。求所有高速公路之间的交叉点数量。

**【输入格式】**

第一行，一个整数 T（测试用例数）。每个测试用例：
- 第一行，三个整数 N、M、K。
- 接下来 K 行，每行两个整数 eᵢ wᵢ，表示第 i 条高速连接东岸 eᵢ 和西岸 wᵢ。

**【输出格式】**

每个测试用例输出一行：`Test case X: Y`（X 为测试用例序号，Y 为交叉点数）。

**【样例输入】**

```
1
3 4 4
1 4
2 3
3 2
3 1
```

**【样例输出】**

```
Test case 1: 5
```

**【数据范围】**

- 30% 数据：K ≤ 1000
- 100% 数据：1 ≤ N, M ≤ 1000，1 ≤ K ≤ 10⁵
- 提示：按东岸编号升序排序后，西岸编号形成的序列中，逆序对即为交叉点。可用归并排序统计逆序对。
