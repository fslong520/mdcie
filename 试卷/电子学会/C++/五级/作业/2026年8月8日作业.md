### 第 1 题（快速幂）王叔叔的便利店会员卡搞"积分翻倍"活动。小程写了段快速幂代码算第 b 天的积分：`long long qpow(long long a, long long b, long long m) { long long ans = ?; while (b) { if (b & 1) ans = ans * a % m; a = a * a % m; b >>= 1; } return ans; }`，问 `ans` 的初始值应为？（ ）

- A. 1
- B. 0
- C. m
- D. -1

**答案：A**

**解析：** ans 是"乘入答案的底数幂"的累积器，初始必须为 1（乘法单位元），初始 0 会把结果全乘成 0。

### 第 2 题（递推）刘伯伯养的观赏鱼每周数量翻倍：第 10 周数了数共 512 条。按规律倒着推，第 1 周有几条？（ ）

- A. 4
- B. 2
- C. 1
- D. 16

**答案：C**

**解析：** f(n) = 2×f(n−1)，倒推 f(1) = 512 ÷ 2⁹ = 1。顺推是递推，倒着推也是递推。

### 第 3 题（贪心）小区楼下直饮水机前排着队，每个人打水时间不同。想让"所有人排队等待的总时间"最短，应该怎么排？（ ）

- A. 打水时间短的人先打
- B. 打水最久的人先打
- C. 年龄大的先打
- D. 随便排，总时间一样

**答案：A**

**解析：** 短任务优先：打得快的人先打完走人，后面的人少陪等；磨蹭的先打，全队跟着耗。

### 第 4 题（前缀和）王叔叔的菜地分了许多小格，他算好了"左上角到每个格子"的累计产量表 pre（二维前缀和）。要算 (x₁,y₁) 到 (x₂,y₂) 矩形地块的总产量，公式是？（ ）

- A. pre[x₂][y₂] − pre[x₁−1][y₁−1]
- B. pre[x₂][y₂] − pre[x₁−1][y₂] − pre[x₂][y₁−1] + pre[x₁−1][y₁−1]
- C. pre[x₂][y₂] + pre[x₁−1][y₂] − pre[x₂][y₁−1] − pre[x₁−1][y₁−1]
- D. pre[x₂][y₂] + pre[x₁−1][y₁−1] − pre[x₁−1][y₂] − pre[x₂][y₁−1]

**答案：B**

**解析：** 大矩形减左条、减上条，左上角被减了两次要加回来——容斥原理。

### 第 5 题（二分）爸爸锯木板做书架，每块木板长 Lᵢ（可带小数），要锯出 k 段等长木板（长度可为小数）。二分答案找"每段最长多少"，l、r 都是实数，循环该怎么控制？（ ）

- A. 枚举答案范围内每个整数试一遍
- B. 用 while(l < r) 且 l、r 为整数
- C. 用 while(r − l > eps) 按精度控制，如 1e−6
- D. 随便猜一个数

**答案：C**

**解析：** 实数二分没有整数下标可依，只能靠精度 eps 收窄区间；枚举整数会漏掉小数答案。

### 第 6 题（双指针）妈妈追剧，剧集按顺序排好、每集时长已知。她想找一段**连续**的剧集，总时长 ≥ X 分钟且集数越少越好：右指针伸、不够就再伸，够了就缩左指针——这属于哪种思路？（ ）

- A. 归并排序
- B. 快速幂
- C. 高精度加法
- D. 滑动窗口（双指针一伸一缩）

**答案：D**

**解析：** 右指针扩窗口、左指针缩窗口，整个窗口滑一遍 O(n) 就找到最短连续段。

### 第 7 题（STL string）闺蜜发来一串字符 `s = "hello world"`，里面藏着取件码。用 `s.substr(6, 3)` 能取出哪一段？（ ）

- A. "wor"
- B. "worl"
- C. "orld"
- D. "hello"

**答案：A**

**解析：** substr(pos, len) 从下标 pos 起取 len 个字符，下标从 0 起，s[6..8] 是 "wor"（s[5] 是空格）。

### 第 8 题（STL sort）夜市套圈奖品按价格从低到高摆了一排，老板想改成从高到低，写下 `sort(a, a + n, greater<int>())`，排出来是？（ ）

- A. 升序
- B. 不排序
- C. 随机顺序
- D. 降序

**答案：D**

**解析：** sort 默认升序，第三个参数 `greater<int>()` 把比较规则反转，变成降序。

### 第 9 题（STL map）王叔叔的便利店用 `map<string, int> mp;` 记会员积分（卡号→积分）。他执行 `mp.find("NO-8888")`，若这张卡不存在，返回的是？（ ）

- A. mp.begin()
- B. mp.end()
- C. 空字符串
- D. 一个新 map

**答案：B**

**解析：** find 找不到键时返回 end() 迭代器，用 `it != mp.end()` 判断键是否存在。

### 第 10 题（差分）小区一排 5 盏路灯，管理员用差分数组记每次调亮：diff = [2, 3, 0, −2, −3]（diff[i] 对应第 i 盏的增量差）。最后把 diff 从头累加一遍还原，第 3 盏路灯总共被调亮了多少？（ ）

- A. 2
- B. 5
- C. 0
- D. −3

**答案：B**

**解析：** 原值 = 差分前缀和：a₃ = 2 + 3 + 0 = 5。对差分数组求前缀和即还原原数组。

### 第 11 题（快速幂）快速幂算 a^b mod m 时，若 m = 1，结果恒为 0。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 任何数对 1 取模都得 0，中间结果也全模成 0，与 a、b 无关。

### 第 12 题（递推）用递归实现 f(n) = f(n−1) + f(n−2) 会重复计算大量子问题，而用递推数组从头往后算不会。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 递归每次从头分叉，同一个 f(k) 被反复算；递推数组每个只算一遍存起来。

### 第 13 题（贪心）散装零食可任意分割，按"性价比（单位重量价值）"从高到低挑，是部分背包贪心，一定能得到最优解。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 物品可分割时按性价比贪心最优；若不可分割（01 背包），贪心就不灵了。

### 第 14 题（差分）差分数组的定义是 diff[i] = a[i+1] − a[i]（i ≥ 1）。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 正确写法是 diff[i] = a[i] − a[i−1]（diff[1] = a[1]），写反了还原出来的数组就错位。

---

### 第 15 题（差分）某区间 [l, r] 的路灯同时调暗 k（减 k），应在 diff[l] −= k、diff[r+1] −= k。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 区间减 k：左端 diff[l] −= k 没错，但右端是 diff[r+1] **+=** k（差值补回来），两处都减就还原错了。

### 第 16 题（二分）lower_bound 在有序数组里找不到目标时，返回 −1。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 找不到返回的是 end() 迭代器（或 a+n 位置），不是 −1；返回 −1 是手写二分的习惯。

### 第 17 题（双指针）快慢指针可以在 O(n) 时间内判断一个链表是否存在环。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 快指针每次两步、慢指针每次一步，有环则快指针必追上慢指针，全程只走一遍。

### 第 18 题（STL vector）vector 的 push_back 在末尾追加元素的均摊时间复杂度是 O(1)。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 扩容虽偶发 O(n) 搬迁，但均摊下来每次追加 O(1)，可放心用。

### 第 19 题（STL set）set 支持用下标（如 s[0]）直接访问第 1 个元素。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** set 底层是红黑树，没有下标概念，访问元素要用迭代器遍历或 find。

### 第 20 题（STL map）用 mp[key] 访问 map 中不存在的键，会自动把该键插入 map 并赋默认值。（ ）

- T. 正确
- F. 错误

```
     /\
    /__\
```

要查看如何绘制更大的三角形，请查看示例输出。

**【输入格式】**

输入包含多个测试用例。每个测试用例由一个整数 $n$ 指定。输入以 $n = 0$ 结束。否则 $1 \le n \le 10$ 表示递归深度。

2
1

```

**【样例输出】**

      /__\    /__\

    /__\/__\

**【数据范围与提示】**

$1 \le n \le 10$，输入以 $n = 0$ 结束。提示：递归分治绘制——把 n 的三角形拆成三份（左、右、底）；用二维字符数组画布存放，行数 $2^n$、列数 $2^{n+1}$，画完后再按行输出（注意不要输出尾随空格，多组测试之间打印空行）。

### cxy0035 <a href="https://oj.nks-oi.top/d/Team_experience/p/T1133?tid=6a4706aa8c06f9a055db7cb5" target="_blank">箱子和球</a>★★（12 分）

有 n 个盒子，起初每个盒子里有 1 个球，1 号盒子里的球是红色的，其余都是白色的。现在给定 m 个操作，每次给出二元组 (xᵢ, yᵢ) 表示从 xᵢ 号盒子中随机拿出一个球放进 yᵢ 号盒子。求在操作结束后有多少个盒子里可能装着红色小球。

第一行两个数 n、m（2 ≤ n ≤ 10⁵，1 ≤ m ≤ 10⁵）。接下来 m 行，每行两个数 xᵢ、yᵢ，保证 1 ≤ xᵢ, yᵢ ≤ n 且 xᵢ ≠ yᵢ，且进行第 i 次操作前盒子 xᵢ 中至少有 1 个球。

2
```
