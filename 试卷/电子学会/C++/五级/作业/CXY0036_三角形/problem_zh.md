# 三角形

考虑一个规则的三角形区域，将其分成四个相等的三角形，且高度减半，并去掉中间的那个。对剩下的三个三角形递归地应用相同的操作。如果我们无限次重复这个过程，将得到一个面积为零的东西。以这种方式演变的分形被称为谢尔宾斯基三角形。对于这个问题，你需要用 ASCII 字符勾勒出谢尔宾斯基三角形，直到某个递归深度。绘制最小的三角形（n=1）时，使用两个斜杠、两个反斜杠和两个下划线。

【输入格式】输入包含多个测试用例。每个测试用例由一个整数 n 指定，输入以 n=0 结束，否则 1 ≤ n ≤ 10 表示递归深度。

【输出格式】对于每个测试用例，绘制一个边长总长度为 2ⁿ 字符的谢尔宾斯基三角形轮廓，将输出左对齐（最左下角的斜杠打印到第一列），不得包含尾随空格，每个测试用例后打印一个空行。

【样例输入 1】
```
3
2
1
0
```
【样例输出 1】
```
           /\
          /__\
         /\  /\
        /__\/__\
       /\      /\
      /__\    /__\
     /\  /\  /\  /\
    /__\/__\/__\/__\

       /\
      /__\
     /\  /\
    /__\/__\

     /\
    /__\
```
【数据范围】1 ≤ n ≤ 10，输入以 n=0 结束。

#### 知识点与难度

本题涉及知识点：**递归、分治、字符画**，难度（CF Rating）：**1400**。
