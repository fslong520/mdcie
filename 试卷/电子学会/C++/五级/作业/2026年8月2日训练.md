### cxy0001 凑单两件套★★（12 分）

**【题目描述】**

游乐园搞活动：商品价格从低到高摆了一排，只要买两件、且两件价格之和恰好等于优惠券上的金额 M，就能立减 20 元。小华翻遍了优惠券，想知道有没有这样两件商品。请你帮他找出来。

**【输入格式】**

第一行，两个整数 n 和 M。
第二行，n 个整数，表示价格（已经按从低到高排好）。

**【输出格式】**

若存在两件商品价格之和等于 M，输出这两个价格，中间用空格隔开（小的在前）；若有多组，输出任意一组。若不存在，输出 `No`。

**【样例输入】**

```
5 30
10 15 20 25 30
```

**【样例输出】**

```
10 20
```

**【数据范围与提示】**

- 30% 数据：n ≤ 100
- 100% 数据：2 ≤ n ≤ 10⁵，1 ≤ M ≤ 2×10⁹，价格 ≤ 10⁹；提示：价格已有序，用一个指针指最矮、一个指最高，和太大右指针左移，和太小左指针右移，各走一遍即可；两数之和可能接近 int 上限，建议用 long long

### cxy0002 两队合流★★（12 分）

**【题目描述】**

两个班的同学去春游，各自按身高从低到高排好了队。到了集合点，老师要把两队合成一队，仍然按身高从低到高站。请你帮忙输出合并后的队伍。

**【输入格式】**

第一行，两个整数 n 和 m。
第二行，n 个整数，表示第一队的身高（升序）。
第三行，m 个整数，表示第二队的身高（升序）。

**【输出格式】**

一行，n+m 个整数，合并后仍按升序排列的身高。

**【样例输入】**

```
3 3
1 3 5
2 4 6
```

**【样例输出】**

```
1 2 3 4 5 6
```

**【数据范围与提示】**

- 30% 数据：n, m ≤ 100
- 100% 数据：1 ≤ n, m ≤ 10⁵，身高 ≤ 10⁹；提示：双指针各指一队头部，取较小者放入结果，指针后移，直到某队走完，再把剩余全部接上

### cxy0003 最长连看不重样★★★（12 分）

**【题目描述】**

小宇在视频平台一口气看了很多集动画片，每集的编号都记了下来。他想找一段**连续**的观看记录，使得这段记录里没有任何两集编号相同，这样的片段越长越划算。请你帮他算算，最长能有多少集。

**【输入格式】**

第一行，一个整数 n。
第二行，n 个整数，表示每集的编号。

**【输出格式】**

```
8
1 2 3 1 2 4 5 6
```

```
6
```

**【数据范围与提示】**

- 30% 数据：n ≤ 100，编号 ≤ 100
- 100% 数据：1 ≤ n ≤ 10⁶，1 ≤ 编号 ≤ 10⁹；提示：左指针固定起点，右指针尽量往右伸，遇到重复编号就记录当前长度并收缩左指针，全程只走一遍

### cxy0005 三人拼单★★★（12 分）

**【题目描述】**

商场满减活动：任意挑三件商品，价格之和恰好等于 M 元就能减 50。货架上摆了 n 件商品，价格互不相同。小乐想看看有没有三件商品能凑出 M，请你帮他判断。

**【输入格式】**

第一行，两个整数 n 和 M。

```

```

```

```

- 30% 数据：n ≤ 50
