# 温度转换

#### 题目描述

输入一个摄氏温度值 C，将其转换为华氏温度 F 并输出，转换公式为：`F = C × 9 ÷ 5 + 32`。

#### 输入格式

一行，一个两位小数，表示摄氏温度 C。

#### 输出格式

一行，输出转换后的华氏温度，保留两位小数。

#### 样例输入 #1

```
0.00
```

#### 样例输出 #1

```
32.00
```

#### 样例输入 #2

```
37.50
```

#### 样例输出 #2

```
99.50
```

#### 样例输入 #3

```
-40.00
```

#### 样例输出 #3

```
-40.00
```

#### 数据范围

输入的摄氏温度绝对值不超过 1000。
