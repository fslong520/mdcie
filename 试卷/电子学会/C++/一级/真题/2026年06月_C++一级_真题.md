### 第21题 温度转换（20分）
**OJ 链接：** <https://fslong.iok.la/problem/CIE202606L1A>


**题目描述**

输入一个摄氏温度值 C，将其转换为华氏温度 F 并输出，转换公式为：`F = C × 9 ÷ 5 + 32`。

**输入格式**

一行，一个两位小数，表示摄氏温度 C。

**输出格式**

一行，输出转换后的华氏温度，保留两位小数。

**样例输入**

```
0.00
```

**样例输出**

```
32.00
```

**数据范围**

输入的摄氏温度绝对值不超过 1000。

**参考程序**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    double c;
    cin >> c;
    printf("%.2f", c * 9 / 5 + 32);
    return 0;
}
```

### 第22题 体温记录（20分）
**OJ 链接：** <https://fslong.iok.la/problem/CIE202606L1B>


**题目描述**

某位用户连续记录了 N 天的体温数据。体温以扩大 100 倍的整数形式表示（例如 36.50°C 表示为 3650）。

第 1 天的体温为 W，从第 2 天到第 N 天，每天记录的是相对于前一天的体温变化量为 Ai。

人体正常体温范围是 36.00℃ 至 37.00°C，对应数值即为 3600 至 3700（含边界）。

请你编写程序，计算在这 N 天的记录中，体温处于正常范围内的天数共有多少。

**输入格式**

第一行包含一个整数 N，表示记录天数；
第二行包含一个整数 W，表示第 1 天的体温；
接下来的 1 行，N - 1 个整数表示 Ai（2<i≤N），表示第 i 天的体温变化量。

**输出格式**

一个整数，表示体温处于正常范围内的天数。

**样例输入 1**

```
5
3500
50 30 20 40
```

**样例输出 1**

```
2
```

**样例输入 2**

```
5
3800
-100 -50 0 -100
```

**样例输出 2**

```
3
```

**数据范围**

2 ≤ N ≤ 1000，1 ≤ W ≤ 100000，-100000 ≤ Ai ≤ 100000。

**参考程序**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, w = 0, ans = 0;
    cin >> n;
    for(int i=0; i<n; i++) { // w 和 n-1个数据一起输入
        int a;
        cin >> a;
        w += a;   //前一天+变化量
        if(w >= 3600 && w <= 3700)
            ans++;
    }
    cout << ans;
    return 0;
}
```
