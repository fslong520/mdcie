# 夹心饼干

#### 题目描述

三个整数组成的三元组，恰好两个数相等、剩余一个数不同时，我们称其为"夹心饼干"。

给定三个整数 a、b、c，若能组成夹心饼干，输出 `Yes`，否则输出 `No`。

#### 输入格式

一行，三个整数 a、b、c。

#### 输出格式

一行，输出组成结果。

#### 样例输入 #1

```
3 3 2
```

#### 样例输出 #1

```
Yes
```

#### 样例输入 #2

```
2 2 2
```

#### 样例输出 #2

```
No
```

#### 样例输入 #3

```
1 2 3
```

#### 样例输出 #3

```
No
```

#### 数据范围

1 ≤ a、b、c ≤ 9。
