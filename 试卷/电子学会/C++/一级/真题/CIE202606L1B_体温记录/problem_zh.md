# 体温记录

#### 题目描述

某位用户连续记录了 N 天的体温数据。体温以扩大 100 倍的整数形式表示（例如 36.50°C 表示为 3650）。

第 1 天的体温为 W，从第 2 天到第 N 天，每天记录的是相对于前一天的体温变化量为 Ai。

人体正常体温范围是 36.00℃ 至 37.00°C，对应数值即为 3600 至 3700（含边界）。

请你编写程序，计算在这 N 天的记录中，体温处于正常范围内的天数共有多少。

#### 输入格式

第一行包含一个整数 N，表示记录天数；

第二行包含一个整数 W，表示第 1 天的体温；

接下来的 1 行，N - 1 个整数表示 Ai（2 ≤ i ≤ N），表示第 i 天的体温变化量。

#### 输出格式

一个整数，表示体温处于正常范围内的天数。

#### 样例输入 #1

```
5
3500
50 30 20 40
```

#### 样例输出 #1

```
2
```

#### 样例输入 #2

```
5
3800
-100 -50 0 -100
```

#### 样例输出 #2

```
3
```

#### 样例输入 #3

```
2
3600
100
```

#### 样例输出 #3

```
2
```

#### 数据范围

2 ≤ N ≤ 1000，1 ≤ W ≤ 100000，-100000 ≤ Ai ≤ 100000。
