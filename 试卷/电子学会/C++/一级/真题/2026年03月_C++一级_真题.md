### 第21题 夹心饼干（20分）
**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L1A>


**题目描述**

三个整数组成的三元组，恰好两个数相等、剩余一个数不同时，我们称其为"夹心饼干"。

给定三个整数 a、b、c，若能组成夹心饼干，输出 `Yes`，否则输出 `No`。

**输入格式**

输入三个整数 a、b、c。

**输出格式**

输出组成结果。

**样例输入 1**

```
3 3 2
```

**样例输出 1**

```
Yes
```

**样例输入 2**

```
2 2 2
```

**样例输出 2**

```
No
```

**数据范围**

1 <= a、b、c <= 9。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if(a == b && a == c) { //三个相等的情况
        cout << "No";
    } else { //三个不相等的情况中有两个相等
        if(a == b || a == c || b == c) {
            cout << "Yes";
        } else {
            cout << "No";
        }
    }
    return 0;
}
```

### 第22题 偶数求和（20分）
**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L1B>


**题目描述**

给定两个整数 a、b，计算 a 到 b 之间（包括 a、b）所有偶数的和，并输出结果。

**输入格式**

输入两个整数 a、b。

**输出格式**

输出 a 到 b 之间所有偶数的和。

**样例输入 1**

```
1 10
```

**样例输出 1**

```
30
```

**样例输入 2**

```
-10 10
```

**样例输出 2**

```
0
```

**数据范围**

-10000 <= a <= b <= 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, s = 0;
    cin >> a >> b;
    for(int i=a; i<=b; i++) {
        if(i % 2 == 0)
            s += i;
    }
    cout << s;
    return 0;
}
```
