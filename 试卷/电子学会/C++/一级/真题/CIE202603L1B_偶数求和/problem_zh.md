# 偶数求和

#### 题目描述

给定两个整数 a、b，计算 a 到 b 之间（包括 a、b）所有偶数的和，并输出结果。

#### 输入格式

一行，两个整数 a、b。

#### 输出格式

一行，输出 a 到 b 之间所有偶数的和。

#### 样例输入 #1

```
1 10
```

#### 样例输出 #1

```
30
```

#### 样例输入 #2

```
-10 10
```

#### 样例输出 #2

```
0
```

#### 样例输入 #3

```
-10 -2
```

#### 样例输出 #3

```
-30
```

#### 数据范围

-10000 ≤ a ≤ b ≤ 10000。

本题涉及的知识点从属于 **电子学会（CIE）1级**，难度（CF Rating）：**600**。
