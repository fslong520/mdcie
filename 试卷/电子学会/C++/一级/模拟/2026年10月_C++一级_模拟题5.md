## 一、单选题（10 题 × 4 分 = 40 分）

### 第 1 题（程序入口）以下关于 C++ 程序入口的说法，正确的是？（ ）

- A. 程序从第一条语句开始执行，与 main 无关
- B. 程序从 main() 函数开始执行
- C. 程序从写在最前面的函数开始执行
- D. 程序从注释之后开始执行

**答案：B**

**解析：** C++ 程序总是从 main() 函数开始执行，main() 是程序的入口，缺了它程序无法运行。

### 第 2 题（关键字）以下哪个是 C++ 的关键字，**不能**用作变量名？（ ）

- A. sum
- B. my_score
- C. double
- D. _a1

**答案：C**

**解析：** double 是表示双精度浮点类型的关键字，关键字有专门的含义，不能用作变量名；sum、my_score、_a1 都是合法的变量名。

### 第 3 题（复合赋值）执行以下代码，输出的结果是？（ ）

```cpp
int x = 7;
x %= 3;
cout << x;
```

- A. 2
- B. 1
- C. 3
- D. 2.33

**答案：B**

**解析：** x %= 3 等价于 x = x % 3，7 除以 3 的余数是 1，所以输出 1。

---

### 第 4 题（输出拼接）执行以下代码，输出的结果是？（ ）

```cpp
cout << "sum=" << 3 + 2;
```

- A. sum=3+2
- B. 3+2
- C. sum=5
- D. sum=32

**答案：C**

**解析：** cout 会先输出字符串 sum=，再计算算术表达式 3+2 得 5 并输出，所以结果是 sum=5。

### 第 5 题（数学函数）执行以下代码，输出的结果是？（ ）

```cpp
cout << pow(2, 3) + 1;
```

- A. 7
- B. 8
- C. 6
- D. 9

**答案：D**

**解析：** pow(2, 3) 计算 2 的 3 次方得 8，再加 1 得 9。pow 在 <cmath> 头文件中。

### 第 6 题（顺序执行）执行以下代码，输出的结果是？（ ）

```cpp
int a = 3;
cout << a;
a = 8;
```

- A. 8
- B. 3
- C. 38
- D. 11

**答案：B**

**解析：** 程序按书写顺序执行：先输出 a 当时的值 3，之后 a=8 只是再赋值，不会再输出。体现了顺序结构。

### 第 7 题（逻辑运算）执行以下代码，输出的结果是？（ ）

```cpp
int r = (3 > 5) || (2 < 4);
cout << r;
```

- A. 1
- B. 0
- C. true
- D. 报错

**答案：A**

**解析：** 3>5 为假，2<4 为真，逻辑或 || 只要有一个为真结果就为真，布尔值真在输出时显示为 1。

### 第 8 题（for循环）执行以下代码，输出的结果是？（ ）

```cpp
for (int i = 2; i <= 10; i += 2)
    cout << i;
```

- A. 2468
- B. 246810
- C. 13579
- D. 210

**答案：B**

**解析：** i 从 2 开始，每次加 2，依次为 2、4、6、8、10，条件 i<=10 都满足，逐个输出得 246810。

---

### 第 9 题（循环累加）执行以下代码，输出的结果是？（ ）

```cpp
int s = 0;
for (int i = 1; i <= 4; i++)
    s += i * 2;
cout << s;
```

- A. 10
- B. 16
- C. 20
- D. 24

**答案：C**

**解析：** 循环把 2、4、6、8 依次累加，2+4+6+8=20。与卷2循环累加不同：本题累加的是 i*2 而非 i。

---

### 第 10 题（循环执行次数）执行以下代码，输出的结果是？（ ）

```cpp
int x = 1;
while (x < 20)
    x *= 3;
cout << x;
```

- A. 9
- B. 20
- C. 81
- D. 27

**答案：D**

**解析：** x 依次为 1、3、9，都小于 20，再乘 3 得 27；27 不小于 20 循环结束，输出 27。注意最后输出的是跳出循环后的 x 值。

## 三、编程题（2 题 × 20 分 = 40 分）

### 第 21 题 停车收费（20 分）

**题目描述**

某停车场按小时收费：**前 2 小时**（含第 2 小时）每小时 5 元；**超过 2 小时的部分**，每小时 8 元。停车时长不足 1 小时的部分按 1 小时计算（向上取整）。

小码停车了 h 小时 m 分钟（0 ≤ m ≤ 59）。请计算他一共需要付多少元停车费。

**输入格式**

一行两个整数 h、m，用空格分隔，表示停车 h 小时 m 分钟。

**输出格式**

一个整数，表示需要支付的停车费（元）。

**样例输入 1**

```
1 30
```

**样例输出 1**

```
10
```

**样例输入 2**

```
4 20
```

**样例输出 2**

```
34
```

**样例说明**

样例 1：1 小时 30 分钟向上取整为 2 小时，未超过 2 小时，费用 2×5=10 元。
样例 2：4 小时 20 分钟向上取整为 5 小时，前 2 小时 5×2=10 元，超出 3 小时 8×3=24 元，共 34 元。

**数据范围**

0 ≤ h ≤ 24，0 ≤ m ≤ 59，且 h、m 不同时为 0。

---

**OJ 链接：** https://fslong.iok.la/problem/cie202608L1T9

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    long long h, m;
    cin >> h >> m;
    long long t = h + (m > 0 ? 1 : 0); // 不足1小时按1小时，向上取整
    long long fee;
    if (t <= 2)
        fee = t * 5; // 前2小时每小时5元
    else
        fee = 2 * 5 + (t - 2) * 8; // 超过2小时部分每小时8元
    cout << fee << endl;
    return 0;
}
```

### 第 22 题 存钱计划（20 分）

**题目描述**

小码给自己定了一个存钱计划：第 1 天存 1 元，从第 2 天起，每天存的钱是**前一天存钱的 2 倍**。也就是说：第 1 天存 1 元、第 2 天存 2 元、第 3 天存 4 元、第 4 天存 8 元……

请你算一算，按这个计划存满 n 天时，小码一共存了多少元。

**输入格式**

一行一个整数 n，表示存钱的天数。

**输出格式**

一个整数，表示 n 天一共存下的钱数（元）。

**样例输入 1**

```
3
```

**样例输出 1**

```
7
```

**样例输入 2**

```
4
```

**样例输出 2**

```
15
```

**样例说明**

样例 1：1 + 2 + 4 = 7。
样例 2：1 + 2 + 4 + 8 = 15。

**数据范围**

1 ≤ n ≤ 30。

**提示**

第 i 天存的钱是 2^(i-1) 元，n 天总数就是 1+2+4+…+2^(n-1)。

---

**OJ 链接：** https://fslong.iok.la/problem/cie202608L1T10

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    long long day = 1; // 第1天存1元
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += day; // 累加当天存的钱
        day *= 2;   // 下一天是今天的2倍
    }
    cout << sum << endl;
    return 0;
}
```
