## 三、编程题（2 题 × 20 分 = 40 分）

### 第21题 三角木架（20分）

**题目描述**

张叔叔是木匠，他想用三根木条做一个三角形展示架。做之前要判断：这三根木条的长度能不能组成一个三角形。

规则：任意两根木条的长度之和大于第三根木条，才能组成三角形。

请你写程序：输入三根木条的长度，判断能否组成三角形，能则输出 YES，不能则输出 NO。

**输入格式**

一行，三个整数 a、b、c，分别表示三根木条的长度（1 ≤ a、b、c ≤ 10000）。

**输出格式**

一行，若能组成三角形输出 YES，否则输出 NO。

**样例输入 1**

```
3 4 5
```

**样例输出 1**

```
YES
```

**样例输入 2**

```
1 2 3
```

**样例输出 2**

```
NO
```

**样例输入 3**

```
5 5 9
```

**样例输出 3**

```
YES
```

**样例说明**

样例 2：1+2=3，不大于 3，不能组成三角形。样例 3：5+5=10>9，能组成三角形。

**数据范围**

1 ≤ a、b、c ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a + b > c && a + c > b && b + c > a)
        cout << "YES";
    else
        cout << "NO";
    return 0;
}
```

### 第22题 跳绳记录（20分）

**题目描述**

刘伯伯坚持晨练跳绳，他把 n 天里每天跳绳的个数都记在本子上。他想知道这些天里，最多的一天跳了多少个。

请你写程序：输入 n 和 n 天的跳绳个数，输出其中的最大值。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000）。

第二行，n 个整数，表示每天跳绳的个数（1 ≤ 个数 ≤ 10000），用空格分隔。

**输出格式**

一行，一个整数，表示 n 天中跳绳个数的最大值。

**样例输入 1**

```
5
100 200 150 300 250
```

**样例输出 1**

```
300
```

**样例输入 2**

```
3
50 50 50
```

**样例输出 2**

```
50
```

**样例说明**

样例 1：5 个数中最大的是 300。样例 2：三天都是 50，最大值是 50。

**数据范围**

1 ≤ n ≤ 1000，1 ≤ 个数 ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x, maxn = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x;
        if (x > maxn)
            maxn = x;
    }
    cout << maxn;
    return 0;
}
```
