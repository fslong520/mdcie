## 一、单选题（10 题 × 4 分 = 40 分）

### 第1题 数据类型

存储小数（如 3.14）时，应该使用哪种数据类型？（ ）

- A. int
- B. double
- C. char
- D. bool

**答案：B**

**解析：** double 是双精度浮点类型，可以存储小数。int 只能存整数，char 存字符，bool 存真假。

---

### 第2题 bool类型

执行以下代码，输出的结果是？（ ）

```cpp
bool b = true;
cout << b;
```

- A. 1
- B. true
- C. 0
- D. 报错

**答案：A**

**解析：** bool 类型输出时，真（true）显示为 1，假（false）显示为 0。

---

### 第3题 逻辑非等价

条件 `!(x < 10)` 与以下哪个条件等价？（ ）

- A. `x < 10`
- B. `x > 10`
- C. `x >= 10`
- D. `x <= 10`

**答案：C**

**解析：** ! 取反：x 不小于 10，即 x 大于或等于 10，所以等价于 `x >= 10`。

---

### 第4题 自增表达式

执行以下代码，输出的结果是？（ ）

```cpp
int x = 5;
cout << x++;
```

- A. 6
- B. 4
- C. 5
- D. 报错

**答案：C**

**解析：** x++ 是后置自增：先使用 x 的当前值 5 输出，再让 x 变成 6。所以输出 5。

---

### 第5题 换行输出

执行以下代码，输出结果是？（ ）

```cpp
cout << 1 << endl << 2;
```

- A. 1 2（同一行，中间空格）
- B. 报错
- C. 12（同一行）
- D. 1 和 2 分两行输出

**答案：D**

**解析：** endl 输出换行。先输出 1 并换行，再输出 2，所以 1 和 2 各占一行。

### 第6题 数学函数

以下C++代码执行后，输出的结果是？（ ）

```cpp
cout << min(5, 9);
```

- A. 5
- B. 9
- C. 14
- D. 45

**答案：A**

**解析：** min(a, b) 返回两个数中较小的一个，min(5, 9) 返回 5。

### 第7题 多分支判断

小红考了 85 分，成绩规则：90 分及以上"优秀"，80~89 分"良好"，60~79 分"及格"，60 分以下"不及格"。执行以下代码，输出结果是？（ ）

```cpp
int score = 85;
if (score >= 90)
    cout << "优秀";
else if (score >= 80)
    cout << "良好";
else if (score >= 60)
    cout << "及格";
else
    cout << "不及格";
```

- A. 优秀
- B. 良好
- C. 及格
- D. 不及格

**答案：B**

**解析：** 85 分不满足 >=90，但满足 >=80，所以进入第二个分支，输出"良好"。

### 第8题 break语句

在循环中执行 `break;` 语句，会？（ ）

- A. 跳过本次循环剩余部分，进入下一次循环
- B. 循环次数减一
- C. 停止程序
- D. 立即结束整个循环

**答案：D**

**解析：** break 的作用是立即跳出（结束）当前整个循环，继续执行循环后面的代码。

---

### 第9题 continue语句

在循环中执行 `continue;` 语句，会？（ ）

- A. 立即结束整个循环
- B. 跳过本次循环剩余部分，进入下一次循环
- C. 停止程序
- D. 报错

**答案：B**

**解析：** continue 跳过本次循环中 continue 后面的语句，直接进入下一次循环。与 break（结束整个循环）不同。

---

### 第10题 循环计算输出

执行以下代码，输出的结果是？（ ）

```cpp
for (int i = 1; i <= 3; i++)
    cout << i * i << " ";
```

- A. 1 2 3
- B. 1 8 27
- C. 1 4 9
- D. 2 4 6

**答案：C**

**解析：** i 取 1、2、3，输出 i×i：1×1=1，2×2=4，3×3=9。

### 第18题

while 循环先判断条件再执行循环体，do-while 循环先执行循环体再判断条件。（ ）

## 三、编程题（2 题 × 20 分 = 40 分）

### 第21题 三角木架（20分）

**题目描述**

张叔叔是木匠，他想用三根木条做一个三角形展示架。做之前要判断：这三根木条的长度能不能组成一个三角形。

规则：任意两根木条的长度之和大于第三根木条，才能组成三角形。

请你写程序：输入三根木条的长度，判断能否组成三角形，能则输出 YES，不能则输出 NO。

**输入格式**

一行，三个整数 a、b、c，分别表示三根木条的长度（1 ≤ a、b、c ≤ 10000）。

**输出格式**

一行，若能组成三角形输出 YES，否则输出 NO。

**样例输入 1**

```
3 4 5
```

**样例输出 1**

```
YES
```

**样例输入 2**

```
1 2 3
```

**样例输出 2**

```
NO
```

**样例输入 3**

```
5 5 9
```

**样例输出 3**

```
YES
```

**样例说明**

样例 2：1+2=3，不大于 3，不能组成三角形。样例 3：5+5=10>9，能组成三角形。

**数据范围**

1 ≤ a、b、c ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a + b > c && a + c > b && b + c > a)
        cout << "YES";
    else
        cout << "NO";
    return 0;
}
```

### 第22题 跳绳记录（20分）

**题目描述**

刘伯伯坚持晨练跳绳，他把 n 天里每天跳绳的个数都记在本子上。他想知道这些天里，最多的一天跳了多少个。

请你写程序：输入 n 和 n 天的跳绳个数，输出其中的最大值。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000）。

第二行，n 个整数，表示每天跳绳的个数（1 ≤ 个数 ≤ 10000），用空格分隔。

**输出格式**

一行，一个整数，表示 n 天中跳绳个数的最大值。

**样例输入 1**

```
5
100 200 150 300 250
```

**样例输出 1**

```
300
```

**样例输入 2**

```
3
50 50 50
```

**样例输出 2**

```
50
```

**样例说明**

样例 1：5 个数中最大的是 300。样例 2：三天都是 50，最大值是 50。

**数据范围**

1 ≤ n ≤ 1000，1 ≤ 个数 ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x, maxn = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x;
        if (x > maxn)
            maxn = x;
    }
    cout << maxn;
    return 0;
}
```
