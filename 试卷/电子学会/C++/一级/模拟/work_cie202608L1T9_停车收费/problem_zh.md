# 停车收费

#### 题目描述

某停车场按小时收费：**前 2 小时**（含第 2 小时）每小时 5 元；**超过 2 小时的部分**，每小时 8 元。停车时长不足 1 小时的部分按 1 小时计算（向上取整）。

小码停车了 h 小时 m 分钟（0 ≤ m ≤ 59）。请计算他一共需要付多少元停车费。

#### 输入格式

一行两个整数 h、m，用空格分隔，表示停车 h 小时 m 分钟。

#### 输出格式

一个整数，表示需要支付的停车费（元）。

#### 样例输入 #1

```
1 30
```

#### 样例输出 #1

```
10
```

#### 样例输入 #2

```
4 20
```

#### 样例输出 #2

```
34
```

#### 样例说明

样例 1：1 小时 30 分钟向上取整为 2 小时，未超过 2 小时，费用 2×5=10 元。
样例 2：4 小时 20 分钟向上取整为 5 小时，前 2 小时 5×2=10 元，超出 3 小时 8×3=24 元，共 34 元。

#### 数据范围

0 ≤ h ≤ 24，0 ≤ m ≤ 59，且 h、m 不同时为 0。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会 1级**（分支结构、向上取整、分段计费），难度（CF Rating）：**800**。
