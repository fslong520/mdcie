## 一、单选题（10 题 × 4 分 = 40 分）

### 第1题 数学函数头文件

要使用平方根函数 `sqrt()`，程序开头应该包含哪个头文件？（ ）

- A. `<iostream>`
- B. `<string>`
- C. `<fstream>`
- D. `<cmath>`

**答案：D**

**解析：** sqrt 等数学函数定义在 <cmath> 头文件中，包含它才能使用。iostream 用于输入输出。

### 第2题 前置自增

执行以下代码，输出的结果是？（ ）

```cpp
int x = 5;
cout << ++x;
```

- A. 4
- B. 5
- C. 6
- D. 报错

**答案：C**

**解析：** ++x 是前置自增：先把 x 加 1 变成 6，再输出 6。与后置的 x++（先输出后加）不同。

### 第3题 break应用

执行以下代码，输出的结果是？（ ）

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3)
        break;
    cout << i;
}
```

- A. 12
- B. 123
- C. 1245
- D. 12345

**答案：A**

**解析：** 当 i=3 时执行 break，立即结束整个循环。i 依次为 1、2 时输出 1、2，到 3 就跳出，所以输出 12。

---

### 第4题 continue应用

执行以下代码，输出的结果是？（ ）

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3)
        continue;
    cout << i;
}
```

- A. 12
- B. 1245
- C. 12345
- D. 135

**答案：B**

**解析：** 当 i=3 时执行 continue，跳过本次循环（不输出 3），继续下一次。所以输出 1、2、4、5，即 1245。

### 第5题 return语句

在 `main()` 函数末尾写 `return 0;`，表示？（ ）

- A. 输出数字 0
- B. 让程序死循环
- C. 暂停程序
- D. 程序正常结束

**答案：D**

**解析：** return 0 表示程序运行成功、正常结束，并把 0 作为返回值返回给操作系统。它不是输出语句。

### 第6题 字符运算

执行以下代码，输出的结果是？（ ）

```cpp
cout << (char)('A' + 1);
```

- A. A
- B. B
- C. 65
- D. 报错

**答案：B**

**解析：** 字符 'A' 的 ASCII 码是 65，65+1=66，正是字符 'B' 的 ASCII 码。(char) 把它转回字符，输出 B。

### 第7题 浮点输出格式

执行以下代码，输出的结果是？（ ）

```cpp
#include <iomanip>
cout << fixed << setprecision(2) << 3.14159;
```

- A. 3.14
- B. 3.1
- C. 3.14159
- D. 3.142

**答案：A**

**解析：** fixed 固定小数格式，setprecision(2) 保留 2 位小数，3.14159 四舍五入为 3.14。setprecision 在 <iomanip> 头文件中。

### 第8题 do-while应用

执行以下代码，输出的结果是？（ ）

```cpp
int i = 5;
do {
    cout << i;
    i++;
} while (i < 3);
```

- A. 6
- B. 什么都不输出
- C. 报错
- D. 5

**答案：D**

**解析：** do-while 先执行一次循环体再判断条件。条件 i<3（5<3）为假，但第一次已经执行，输出 5。

---

### 第9题 赋值链

执行以下代码，输出的结果是？（ ）

```cpp
int a, b, c;
a = b = c = 5;
cout << a + b + c;
```

- A. 15
- B. 5
- C. 0
- D. 20

**答案：A**

**解析：** 赋值从右往左：先 c=5，再 b=5，再 a=5，三个变量都是 5，和为 15。

---

### 第10题 函数嵌套

执行以下代码，输出的结果是？（ ）

```cpp
cout << max(min(3, 8), 5);
```

- A. 3
- B. 8
- C. 5
- D. 15

**答案：C**

**解析：** 先算内层 min(3, 8)=3，再算外层 max(3, 5)=5。嵌套函数从里往外计算。

**答案：错误**

### 第13题

在 switch 语句中，执行完一个 case 分支后会直接跳出，不需要加 break。（ ）

**答案：错误**

**解析：** switch 匹配一个 case 后，会继续向下执行后面的 case（称为"穿透"），要跳出必须写 break。

## 三、编程题（2 题 × 20 分 = 40 分）

### 第21题 平均成绩（20分）

**题目描述**

刘老师统计了 n 名同学期末考试的数学成绩，他想算算全班的平均成绩是多少。请你写程序帮助刘老师计算平均成绩，并保留两位小数输出。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000），表示学生人数。

第二行，n 个整数，表示每名同学的成绩（0 ≤ 成绩 ≤ 100），用空格分隔。

**输出格式**

一行，一个浮点数，表示平均成绩，保留两位小数。

**样例输入 1**

```
4
85 90 78 92
```

**样例输出 1**

```
86.25
```

**样例输入 2**

```
3
60 60 60
```

**样例输出 2**

```
60.00
```

**样例说明**

样例 1：(85+90+78+92)÷4=86.25。样例 2：60×3÷3=60.00。

**数据范围**

1 ≤ n ≤ 1000，0 ≤ 成绩 ≤ 100。

**参考程序**

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    int n, x, sum = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x;
        sum += x;
    }
    cout << fixed << setprecision(2) << (double)sum / n;
    return 0;
}
```

### 第22题 不及格人数（20分）

**题目描述**

刘老师批改完试卷，想统计班里有几个同学不及格（成绩小于 60 分）。班里有 n 名同学。

请你写程序：输入 n 和 n 名同学的成绩，输出不及格的人数。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000）。

第二行，n 个整数，表示每名同学的成绩（0 ≤ 成绩 ≤ 100），用空格分隔。

**输出格式**

一行，一个整数，表示成绩小于 60 分的人数。

**样例输入 1**

```
5
85 42 90 58 100
```

**样例输出 1**

```
2
```

**样例输入 2**

```
3
60 70 80
```

**样例输出 2**

```
0
```

**样例说明**

样例 1：42 和 58 小于 60，共 2 人。样例 2：60、70、80 都不小于 60，0 人。

**数据范围**

1 ≤ n ≤ 1000，0 ≤ 成绩 ≤ 100。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x, cnt = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x;
        if (x < 60)
            cnt++;
    }
    cout << cnt;
    return 0;
}
```
