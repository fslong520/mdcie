### 第21题 哪箱最重（20分）

**题目描述**

王叔叔的便利店新进了三箱饮料，分别是果汁、牛奶和汽水。他想知道这三箱里哪一箱最重，好把最重的摆在货架底层。

请你写程序：输入三箱饮料的重量，输出最重的那一箱的重量。

**输入格式**

一行，三个整数 a、b、c，分别表示三箱饮料的重量（单位：千克）。

**输出格式**

一行，一个整数，表示三箱中最大的重量。

**样例输入 1**

```
3 9 5
```

**样例输出 1**

```
9
```

**样例输入 2**

```
7 7 2
```

**样例输出 2**

```
7
```

**样例说明**

样例 2：牛奶和汽水都是 7 千克，果汁 2 千克，最重的是 7 千克。

**数据范围**

1 ≤ a、b、c ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b, c, max;
    cin >> a >> b >> c;
    max = a;
    if (b > max) max = b;
    if (c > max) max = c;
    cout << max;
    return 0;
}
```

### 第22题 幸运兑换（20分）

**题目描述**

美食街新开的甜品店搞活动：每张购物小票上有一个编号，编号能被 3 整除的小票可以到柜台免费兑换一杯柠檬水。

冯阿姨帮邻居们收了一叠小票，想数一数有几张能兑换柠檬水。

请你写程序：输入 n 张小票的编号，输出其中能兑换的张小票数（能被 3 整除的个数）。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000）。

第二行，n 个整数，表示每张小票的编号（绝对值不超过 10000）。

**输出格式**

一行，一个整数，表示能被 3 整除的小票数。

**样例输入 1**

```
5
3 6 7 9 10
```

**样例输出 1**

```
3
```

**样例输入 2**

```
4
1 2 4 5
```

**样例输出 2**

```
0
```

**样例说明**

样例 1：编号 3、6、9 能被 3 整除，共 3 张。样例 2：4 张都不能被 3 整除，共 0 张。

**数据范围**

1 ≤ n ≤ 1000，整数绝对值 ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, count = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x % 3 == 0)
            count++;
    }
    cout << count;
    return 0;
}
```
