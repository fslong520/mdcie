## 一、单选题（10 题 × 4 分 = 40 分）

### 第1题 头文件作用

程序开头写 `#include <iostream>`，它的作用是？（ ）

- A. 定义一个变量
- B. 引入标准输入输出流库，让 cin、cout 可用
- C. 结束程序
- D. 声明一个函数

**答案：B**

**解析：** iostream 是标准输入输出流头文件，包含它之后才能使用 cin 输入、cout 输出。

---

### 第2题 注释

在C++中，`//` 后面的内容是什么？（ ）

- A. 注释，不会被计算机执行
- B. 输出语句
- C. 变量定义
- D. 输入语句

**答案：A**

**解析：** `//` 是单行注释符，后面的内容仅供人阅读，编译时被忽略，不会执行。

### 第3题 const常量

执行以下代码，会发生什么？（ ）

```cpp
const int a = 10;
a = 20;
```

- A. a 变成 20
- B. 正常运行，a 还是 10
- C. 输出 20
- D. 编译报错

**答案：D**

**解析：** const 定义的是常量，值不可修改。对常量赋值 a = 20 会导致编译报错。

### 第4题 奇偶判断

要判断整数 x 是偶数，以下哪个条件正确？（ ）

- A. `x % 2 == 1`
- B. `x % 2 == 0`
- C. `x / 2 == 0`
- D. `x * 2 == 0`

**答案：B**

**解析：** 偶数能被 2 整除，余数为 0，所以用 `x % 2 == 0` 判断。`x % 2 == 1` 是判断奇数。

### 第5题 连续输入

执行以下代码，输入 `3 5` 并回车，a 和 b 的值分别是？（ ）

```cpp
int a, b;
cin >> a >> b;
```

- A. a=3, b=5
- B. a=5, b=3
- C. a=3, b=3
- D. 报错

**答案：A**

**解析：** cin 可以连续读入多个变量，按顺序赋值：第一个数给 a，第二个数给 b。

### 第6题 数学函数

以下C++代码执行后，输出的结果是？（ ）

```cpp
cout << max(5, 9);
```

- A. 5
- B. 14
- C. 9
- D. 45

**答案：C**

**解析：** max(a, b) 返回两个数中较大的一个，max(5, 9) 返回 9。

### 第7题 程序结构

以下哪个**不是**C++程序的三种基本结构之一？（ ）

- A. 顺序结构
- B. 递归结构
- C. 选择结构
- D. 循环结构

**答案：B**

**解析：** 程序的三种基本结构是顺序、选择（分支）、循环。递归不是基本结构，它是函数自己调用自己的一种方式。

### 第8题 逻辑与应用

夏天开空调，气温在 20℃ 到 30℃ 之间（含两端）最舒适。执行以下代码，输出结果是？（ ）

```cpp
int temp = 25;
if (temp >= 20 && temp <= 30)
    cout << "OK";
else
    cout << "NO";
```

- A. NO
- B. 1
- C. 0
- D. OK

**答案：D**

**解析：** `temp >= 20 && temp <= 30` 用逻辑与 && 判断 25 是否在 [20, 30] 区间内。25 满足条件，输出 OK。

### 第9题 循环累加

执行以下代码，输出的结果是？（ ）

```cpp
int s = 0;
for (int i = 1; i <= 5; i += 2)
    s += i;
cout << s;
```

- A. 9
- B. 15
- C. 6
- D. 25

**答案：A**

**解析：** i 依次取 1、3、5（步长为 2），s = 1 + 3 + 5 = 9。

---

### 第10题 for循环倒序

执行以下代码，输出的结果是？（ ）

```cpp
for (int i = 5; i >= 1; i--)
    cout << i << " ";
```

- A. 5 5 5 5 5
- B. 4 3 2 1 0
- C. 5 4 3 2 1
- D. 1 2 3 4 5

**答案：C**

**解析：** i 从 5 开始，每次减 1，直到 i>=1 不成立，依次输出 5 4 3 2 1。i-- 是每次减 1。

## 三、编程题（2 题 × 20 分 = 40 分）

### 第21题 蛋糕计时（20分）

**题目描述**

冯阿姨在家烤蛋糕，烤箱的定时器只能按分钟设定。她想把总时间换算成"几小时几分钟"显示在厨房的小黑板上。

请你写程序：输入总分钟数 m，输出它等于几小时几分钟。

**输入格式**

一行，一个整数 m（1 ≤ m ≤ 10000），表示总分钟数。

**输出格式**

一行，两个整数，分别表示小时数和分钟数，用空格分隔。

**样例输入 1**

```
125
```

**样例输出 1**

```
2 5
```

**样例输入 2**

```
90
```

**样例输出 2**

```
1 30
```

**样例输入 3**

```
45
```

**样例输出 3**

```
0 45
```

**样例说明**

样例 1：125 分钟 = 2 小时 5 分钟。样例 3：不足 1 小时时，小时数为 0。

**数据范围**

1 ≤ m ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int m, hour, minute;
    cin >> m;
    hour = m / 60;
    minute = m % 60;
    cout << hour << " " << minute;
    return 0;
}
```

### 第22题 买菜算账（20分）

**题目描述**

刘伯伯去菜市场买菜，一共买了 n 样东西，每样的价格都记在纸上。他想算一算今天一共花了多少钱。

请你写程序：输入 n 和 n 个价格，输出它们的总和。

**输入格式**

第一行，一个整数 n（1 ≤ n ≤ 1000）。

第二行，n 个整数，表示每样东西的价格（1 ≤ 价格 ≤ 10000），用空格分隔。

**输出格式**

一行，一个整数，表示 n 个价格的总和。

**样例输入 1**

```
3
3 5 2
```

**样例输出 1**

```
10
```

**样例输入 2**

```
5
10 20 30 40 50
```

**样例输出 2**

```
150
```

**样例说明**

样例 1：3+5+2 = 10 元。样例 2：10+20+30+40+50 = 150 元。

**数据范围**

1 ≤ n ≤ 1000，1 ≤ 价格 ≤ 10000。

**参考程序**

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x, sum = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> x;
        sum += x;
    }
    cout << sum;
    return 0;
}
```
