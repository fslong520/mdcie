### zkh56 幸运数字（12 分）

**【题目描述】**

小区抽奖活动：号码**个位是 7**，或者**能被 7 整除**，就是"幸运数字"。请你判断一个号码是不是幸运数字。

**【输入格式】**

一行，一个整数 n，表示抽奖号码。

**【输出格式】**

一行，若 n 是幸运数字，输出 `lucky`；否则输出 `unlucky`。

**【样例输入 1】**

```
17
```

**【样例输出 1】**

```
lucky
```

**【样例输入 2】**

```
21
```

**【样例输出 2】**

```
lucky
```

**【样例输入 3】**

```
5
```

**【样例输出 3】**

```
unlucky
```

**【样例说明】**

样例 1：17 的个位是 7，是幸运数字。
样例 2：21 的个位不是 7，但 21 能被 7 整除，也是幸运数字。
样例 3：5 的个位不是 7，5 也不能被 7 整除，不是幸运数字。

**【数据范围】**

1 ≤ n ≤ 10000。

### zkh57 倒序报数（12 分）

**【题目描述】**

体育课列队报数：从第 n 个同学开始，每隔一个同学报一次数（也就是从大到小、每次跳过 1 个），报到最大的正数为止。

例如 n = 7 时，报数的同学编号是：7、5、3、1。

请你写程序：输入 n，输出报数的序列。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，n 从大到小、每隔一个输出一个数，数之间用空格隔开（最后一个数后面没有空格）。

**【样例输入 1】**

```
7
```

**【样例输出 1】**

```
7 5 3 1
```

**【样例输入 2】**

```
6
```

**【样例输出 2】**

```
6 4 2
```

**【样例说明】**

样例 1：从 7 开始，每次减 2：7、5、3、1，减到 1 后再减 2 就是 -1（不是正数），停止。
样例 2：6、4、2，再减 2 是 0，停止。

**【数据范围】**

1 ≤ n ≤ 100。

### zkh58 首尾配对（12 分）

**【题目描述】**

体育课分组做游戏：n 个同学按身高排成一排，第 1 个同学和倒数第 1 个同学配对、第 2 个和倒数第 2 个配对……每对同学的"默契分"等于两人身高之和。

请你写程序：输入 n 个同学的身高，按配对的顺序输出每对的默契分（身高之和）；n 为奇数时，正中间那个同学没有搭档，直接输出他自己的身高。

**【输入格式】**

第一行，一个整数 n。

第二行，n 个整数，表示按顺序排列的同学身高。

**【输出格式】**

一行，按配对的顺序输出：第 1 个与最后 1 个之和、第 2 个与倒数第 2 个之和……（n 为奇数时中间那个数直接输出），数字之间用空格隔开。

**【样例输入】**

```
5
1 2 3 4 5
```

**【样例输出】**

```
6 6 3
```

**【样例说明】**

配对顺序：1 和 5 配对得 6，2 和 4 配对得 6，中间的 3 没有搭档，直接输出 3。所以输出 6 6 3。

**【数据范围】**

1 ≤ n ≤ 1000，1 ≤ 身高 ≤ 10000。

### zkh59 花坛外圈（12 分）

**【题目描述】**

小区花坛是 n 行 m 列的方格，每个格子里写着一种花的数量。物业想把**最外圈**的花数一数（第一行、最后一行、第一列、最后一列，四个角只算一次），好统计围墙外的展示效果。

请你写程序：输入一个 n×m 的矩阵，输出最外圈所有数的和。

**【输入格式】**

第一行，两个整数 n、m。

接下来 n 行，每行 m 个整数，表示花坛每个格子里的数。

**【输出格式】**

一行，一个整数，表示最外圈所有数的和。

**【样例输入】**

```
3 3
1 2 3
4 5 6
7 8 9
```

**【样例输出】**

```
40
```

**【样例说明】**

最外圈是第一行 1、2、3，最后一行 7、8、9，加上第一列的 4 和最后一列的 6（四个角的数已经算过，不再重复）。1+2+3+4+6+7+8+9 = 40。

**【数据范围】**

1 ≤ n、m ≤ 30，格子里的数 ≤ 10000。

### zkh60 找不同（12 分）

**【题目描述】**

小区门口有两块一模一样的拼图板（都是 n 行 m 列的方格），每格印着一个数字。管理员怀疑两块板有格子被换了，想检查两幅图**有几个位置的数字不一样**。

请你写程序：输入两块 n×m 的数字板，输出对应位置数字不同的格子个数。

**【输入格式】**

第一行，两个整数 n、m。

接下来 n 行，每行 m 个整数，表示第一块板。

接下来 n 行，每行 m 个整数，表示第二块板。

**【输出格式】**

一行，一个整数，表示两块板对应位置数字不同的个数。

**【样例输入】**

```
2 2
1 2
3 4
1 9
3 4
```

**【样例输出】**

```
1
```

**【样例说明】**

两块板逐格比较：位置 (1,1) 都是 1、位置 (2,1) 都是 3、位置 (2,2) 都是 4，只有位置 (1,2) 是 2 对 9 不同，共 1 处不同。

**【数据范围】**

1 ≤ n、m ≤ 30，格子里的数 ≤ 10000。
