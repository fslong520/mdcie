### zkh51 快递计费（12 分）

**【题目描述】**

小区快递驿站的收费规则：包裹重量**不超过 2 千克**，收 **5 元**；**超过 2 千克**的部分，每多 1 千克加收 **2 元**（重量按整数千克计）。

请你写程序：输入包裹重量 w，输出快递费。

**【输入格式】**

一行，一个整数 w，表示包裹重量（单位：千克）。

**【输出格式】**

一行，一个整数，表示快递费（单位：元）。

**【样例输入 1】**

```
2
```

**【样例输出 1】**

```
5
```

**【样例输入 2】**

```
3
```

**【样例输出 2】**

```
7
```

**【样例输入 3】**

```
6
```

**【样例输出 3】**

```
13
```

**【样例说明】**

样例 1：2 千克没有超过首重，只收 5 元。
样例 2：3 千克超过首重 1 千克，5 + 1×2 = 7 元。
样例 3：6 千克超过首重 4 千克，5 + 4×2 = 13 元。

**【数据范围】**

1 ≤ w ≤ 1000。

### zkh52 幸运抽奖（12 分）

**【题目描述】**

游乐园搞抽奖活动，柜台上的号码从 a 到 b（含两端）都能抽。规则很简单：凡是号码是 7 的倍数，就中奖 1 元。

请你帮老板算一算：a 到 b 之间所有 7 的倍数加起来，一共要准备多少元奖金？

**【输入格式】**

一行，两个整数 a、b。

**【输出格式】**

一行，一个整数，表示 a 到 b 之间所有 7 的倍数的和。

**【样例输入 1】**

```
1 14
```

**【样例输出 1】**

```
21
```

**【样例输入 2】**

```
10 20
```

**【样例输出 2】**

```
14
```

**【样例说明】**

样例 1：1 到 14 之间 7 的倍数有 7 和 14，和是 21。
样例 2：10 到 20 之间只有 14 是 7 的倍数，和是 14。

**【数据范围】**

1 ≤ a ≤ b ≤ 10000。

### zkh53 元音密信（12 分）

**【题目描述】**

特工收到一封密信，内容是一行由小写字母组成的字符串（没有空格）。情报局的规则是：数一数这封信里有几个**元音字母**（a、e、i、o、u），答案就是解密的线索。

请你写程序：输入一行小写字母组成的字符串，输出其中元音字母的个数。

**【输入格式】**

一行，由小写字母组成的字符串（无空格）。

**【输出格式】**

一行，一个整数，表示元音字母的个数。

**【样例输入】**

```
helloworld
```

**【样例输出】**

```
3
```

**【样例说明】**

`helloworld` 里的元音字母是 e、o、o，共 3 个（字母 o 出现两次要算两次）。

**【数据范围】**

字符串长度 ≤ 1000。

### zkh54 座位点名（12 分）

**【题目描述】**

电影院里有一块 n 行 m 列的座位区，管理员按**列**点名：从第 1 列开始，每列从上往下依次点名，点完一整列，再点下一列。第一个被点到的座位号是 k。

请你写程序：输入 n、m、k，输出整个座位区的编号矩阵（第 1 列从上往下是 k、k+1、k+2、……，第 2 列接着往下排）。

**【输入格式】**

一行，三个整数 n、m、k。

**【输出格式】**

n 行，每行 m 个整数，同一行的数字之间用空格分隔。

**【样例输入】**

```
3 3 10
```

**【样例输出】**

```
10 13 16
11 14 17
12 15 18
```

**【样例说明】**

先填第 1 列：从上往下 10、11、12；再填第 2 列：13、14、15；最后填第 3 列：16、17、18。

**【数据范围】**

1 ≤ n、m ≤ 30，1 ≤ k ≤ 1000。

### zkh55 阶梯方阵（12 分）

**【题目描述】**

小区广场要铺一块 n 行 n 列的地砖，只铺**左下角阶梯状**的部分（主对角线以及它的下方），其他格子留作花坛，输出 0。

请你写程序：输入 n，从 1 开始，从上到下、从左到右给阶梯部分编号，输出整个方阵。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

n 行，每行 n 个整数，同一行的数字之间用空格分隔。

**【样例输入 1】**

```
3
```

**【样例输出 1】**

```
1 0 0
2 3 0
4 5 6
```

**【样例输入 2】**

```
4
```

**【样例输出 2】**

```
1 0 0 0
2 3 0 0
4 5 6 0
7 8 9 10
```

**【样例说明】**

第 1 行只填第 1 个格子，得 1；第 2 行填前两个格子，得 2、3；第 3 行填前三个格子，得 4、5、6。主对角线及下方的格子都填数，右上角的格子全部输出 0。

**【数据范围】**

1 ≤ n ≤ 20。
