### zkh61 数字反转（12 分）

**【题目描述】**

深夜，天文台收到一串来自宇宙的神秘信号：一组数字。科学家小赵把信号放大投影到屏幕上，突然发现——信号要**倒过来**读才有意义！

比如信号 123 倒过来是 321，信号 2040 倒过来是 402（开头的 0 不读）。

请你写程序：输入信号数字 n，输出倒过来解读的结果。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，一个整数，表示 n 倒过来后的数。

**【样例输入 1】**

```
123
```

**【样例输出 1】**

```
321
```

**【样例输入 2】**

```
2040
```

**【样例输出 2】**

```
402
```

**【样例说明】**

样例 1：123 的个位是 3、十位是 2、百位是 1，倒过来是 321。
样例 2：2040 倒过来是 0402，开头的 0 不输出，所以是 402。

**【数据范围】**

1 ≤ n ≤ 1000000。

### zkh62 月份天数（12 分）

**【题目描述】**

小赵是个程序员，正在开发一款日历 App。他要先写一个核心功能：输入月份，返回这个月有多少天。

日历上每个月有多少天是固定的。**今年（2026 年）不是闰年，所以 2 月有 28 天**：1 月 31 天、2 月 28 天、3 月 31 天、4 月 30 天、5 月 31 天、6 月 30 天、7 月 31 天、8 月 31 天、9 月 30 天、10 月 31 天、11 月 30 天、12 月 31 天。

请你写程序：输入一个月份 m，告诉小赵这个月有多少天。

请你写程序：输入一个月份 m，输出这个月有多少天。

**【输入格式】**

一行，一个整数 m，表示月份（1 到 12）。

**【输出格式】**

一行，一个整数，表示这个月的天数。

**【样例输入 1】**

```
2
```

**【样例输出 1】**

```
28
```

**【样例输入 2】**

```
7
```

**【样例输出 2】**

```
31
```

**【样例输入 3】**

```
4
```

**【样例输出 3】**

```
30
```

**【样例说明】**

今年（2026 年）不是闰年，所以 2 月是 28 天；7 月是大月，31 天；4 月是小月，30 天。小明做年历时可以这样算：2 月 28 天、4/6/9/11 月各 30 天，其余月份各 31 天。可以用 switch 语句，也可以把每个月当成分支依次判断。

**【数据范围】**

1 ≤ m ≤ 12。

### zkh63 相邻交换（12 分）

**【题目描述】**

情报员小王截获了一份加密情报：一串数字。破译专家发现，加密规则是——把**相邻两个数字交换位置**（第 1 个和第 2 个交换、第 3 个和第 4 个交换、第 5 个和第 6 个交换……）。如果数字个数是奇数，最后一位保持不变。

请你写程序：输入 n 和 n 个密文数字，输出解密后的原文。

**【输入格式】**

第一行，一个整数 n。

第二行，n 个整数，表示每个同学手里的数字。

**【输出格式】**

一行，n 个整数，表示两两交换后的数字，数字之间用空格隔开。

**【样例输入 1】**

```
4
1 2 3 4
```

**【样例输出 1】**

```
2 1 4 3
```

**【样例输入 2】**

```
5
1 2 3 4 5
```

**【样例输出 2】**

```
2 1 4 3 5
```

**【样例说明】**

样例 1：1 和 2 交换得 2 1，3 和 4 交换得 4 3，所以是 2 1 4 3。
样例 2：1 和 2 交换、3 和 4 交换，5 是最后一个（n 为奇数），不动，所以是 2 1 4 3 5。

**【数据范围】**

1 ≤ n ≤ 1000，数字 ≤ 10000。

### zkh64 上三角填数（12 分）

**【题目描述】**

科幻游戏《星际矩阵》里，有一块 n 行 n 列的能量矩阵，只有**主对角线及其右上方**的格子能充能：充能顺序从第 1 行开始、从左到右，能量值从 1 开始递增；左下方的格子没有能量，记作 0。

请你写程序：输入 n，输出这块能量矩阵的充能情况。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

n 行，每行 n 个整数，同一行的数字之间用空格分隔。

**【样例输入 1】**

```
3
```

**【样例输出 1】**

```
1 2 3
0 4 5
0 0 6
```

**【样例输入 2】**

```
4
```

**【样例输出 2】**

```
1 2 3 4
0 5 6 7
0 0 8 9
0 0 0 10
```

**【样例说明】**

第 1 排的同学全部有号码（1、2、3），第 2 排从第 2 个同学开始有号码（4、5），第 3 排只有最后 1 个同学有号码（6）。主对角线及其右上的同学有号码，左下方的同学号码是 0。

**【数据范围】**

1 ≤ n ≤ 20。
