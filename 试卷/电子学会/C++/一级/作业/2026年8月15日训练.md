### 第 1 题（变量类型）下列哪种类型能存储的最大整数范围最小？（ ）

- A. int
- B. long long
- C. short
- D. char

**答案：D**

**解析：** char 只占 1 个字节（8 位），能表示的范围是 −128~127（有符号），是所有类型里最小的。short 占 2 字节（约 ±3 万），int 占 4 字节（约 ±21 亿），long long 占 8 字节（更大）。范围从小到大：char < short < int < long long。

### 第 2 题（输入输出）执行以下代码，输入 `3 4`，输出的结果是？（ ）

```cpp
int a, b;
cin >> a >> b;
cout << a + b;
```

- A. 34
- B. 3 4
- C. 12
- D. 7

**答案：D**

**解析：** `cin >> a >> b` 连续读两个整数：a=3、b=4。`cout << a + b` 输出它们的和 3+4=7。注意 cin 用空格或换行分隔多个输入值，`3 4` 会依次赋给 a、b。

### 第 3 题（取模运算）小明要把 25 个苹果平均分给 4 个小朋友，他想知道还剩几个苹果。用哪种运算？（ ）

- A. 25 / 4
- B. 25 % 4
- C. 4 * 25
- D. 25 - 4

**答案：B**

**解析：** 求"还剩几个"就是求余数，用取模运算符 `%`：25 % 4 = 1（25 ÷ 4 = 6 余 1）。`/` 求的是商（6），`-` 和 `*` 都不对。取模运算在判断奇偶（n % 2）、判断整除（n % k == 0）里特别常用。

### 第 4 题（逻辑运算）执行以下代码，输出的结果是？（ ）

```cpp
int a = 3, b = 4, c = 5;
if (a > 2 && b < 3 || c == 5)
    cout << "yes";
else
    cout << "no";
```

- A. yes
- B. no
- C. 345
- D. 编译错误

**答案：A**

**解析：** 逻辑运算符优先级：`!` > `&&` > `||`。先算 `a > 2`（真）与 `b < 3`（假）：`真 && 假 = 假`；再算 `假 || (c == 5)`（c==5 为真）：`假 || 真 = 真`，条件成立，输出 yes。`&&` 两边都真才真，`||` 一边真就真。

### 第 5 题（switch穿透）执行以下代码，输出的结果是？（ ）

```cpp
int n = 2;
switch (n) {
    case 1: cout << "a";
    case 2: cout << "b";
    case 3: cout << "c";
}
```

- A. a
- B. b
- C. bc
- D. abc

**答案：C**

**解析：** switch 找到匹配的 case 2 后，如果没有 break，会**继续往下执行**后面的所有语句（这叫"穿透"）。所以输出 b 然后 c，结果是 "bc"。每个 case 结尾记得加 break，否则就会穿到下一个 case 去。

### 第 6 题（循环嵌套）以下嵌套循环一共会输出多少个 `*`？（ ）

```cpp
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 4; j++)
        cout << "*";
```

- A. 7
- B. 12
- C. 3
- D. 4

**答案：B**

**解析：** 外层循环 3 次，每次内层循环都完整跑 4 次，共 3 × 4 = 12 个 `*`。嵌套循环的执行次数 = 外层次数 × 内层次数。注意内层循环每轮都从 j=0 重新开始。

### 第 7 题（break/continue）执行以下代码，输出的结果是？（ ）

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    cout << i;
}
```

- A. 12345
- B. 123
- C. 1245
- D. 45

**答案：C**

**解析：** `continue` 跳过本轮循环，直接进入下一轮。i=3 时遇到 continue，跳过输出，所以 3 不打印，结果是 1245。如果换成 `break`，则会整个退出循环，输出 12（break 是终止整个循环）。

### 第 8 题（数组越界）`int a[5];` 定义后，以下哪种访问是**非法**的（越界）？（ ）

- A. a[0]
- B. a[4]
- C. a[5]
- D. a[2]

**答案：C**

**解析：** 数组 `a[5]` 有 5 个元素，合法下标是 0、1、2、3、4。a[5] 访问第 6 个元素，已经超出数组范围——这叫**越界访问**，可能读到垃圾数据或导致程序崩溃。C++ 不会自动检查越界，写代码时要小心下标范围。

### 第 9 题（二维数组列优先）执行以下代码，输出的结果是？（ ）

```cpp
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
for (int j = 0; j < 3; j++)
    cout << a[0][j];
```

- A. 123
- B. 456
- C. 14
- D. 123456

**答案：A**

**解析：** 循环只遍历第 0 行（i 固定为 0），j 从 0 到 2：a[0][0]=1、a[0][1]=2、a[0][2]=3，输出 123。这是"行固定、列变化"的遍历方式，取的是第一行的三个元素。

---

### 第 10 题（三目运算符）执行以下代码，输出的结果是？（ ）

```cpp
int a = 7, b = 10;
int m = (a > b) ? a : b;
cout << m;
```

- A. 7
- B. 10
- C. 17
- D. 0

**答案：B**

**解析：** 三目运算符 `条件 ? 值1 : 值2`：条件成立取值 1，否则取值 2。a=7 > b=10 不成立，所以取 b=10，m 是 10。这是简化版的 if-else，常用于求最大值、最小值。

---

### 第 11 题（循环变量作用域）for 循环的初始化表达式里声明的变量（如 `for (int i = 0; ...)` 中的 i），在循环结束后仍然可以在循环外使用。（ ）

**答案：F**

**解析：** `for (int i = 0; ...)` 中声明的 i，作用域**仅限于循环内部**（标准 C++），循环结束后 i 就"消失"了，在循环外使用会编译报错。想在循环外还能用 i，得把 i 声明在循环外面：`int i; for (i = 0; ...)`。

---

### 第 12 题（for循环省略）for 循环的三个表达式（初始化、条件、更新）都可以省略，但分号 `;` 必须保留。（ ）

**答案：T**

**解析：** `for (; ; )` 是死循环（条件省略默认真），三个部分都可以不写，但两个分号必须都在。比如 `for (int i = 0; i < n; )` 省略了更新部分，靠循环体里自己改 i。

---

### 第 13 题（数组下标）C++ 数组中，第一个元素的下标是 1。（ ）

**答案：F**

**解析：** C++ 数组下标从 **0** 开始，第一个元素是 a[0]（不是 a[1]）。定义 `int a[5]` 后，合法下标是 0~4。从 1 开始的是数学里的习惯，C++ 里要特别注意这个差异。

---

### 第 14 题（二维数组内存）二维数组 `int a[2][3]` 在内存中是连续存放的，a[0][2] 和 a[1][0] 在内存中相邻。（ ）

**答案：T**

**解析：** 二维数组按行优先连续存放：第一行 3 个元素存完，紧接着存第二行。所以 a[0][2]（第一行最后一个）之后紧挨着就是 a[1][0]（第二行第一个），它们在内存中相邻。

---

### 第 15 题（while条件）`while (0)` 这个循环的循环体一次也不会执行。（ ）

**答案：T**

**解析：** while 先判断条件再决定是否执行循环体。条件 0 表示假（false），第一次判断就不成立，循环体一次都不执行，直接跳过。同理 `while (1)` 是死循环（条件恒真）。

### zkh66 数字之和（12 分）

**【题目描述】**

小赵拿到一个正整数，想算一算它各个数位上的数字加起来的和是多少。比如 123 的各位数字和是 1+2+3=6，1005 的各位数字和是 1+0+0+5=6。

请你写程序：输入一个正整数 n，输出它的各位数字之和。

**【输入格式】**

一行，一个正整数 n。

**【输出格式】**

一行，一个整数，表示 n 的各位数字之和。

**【样例输入 1】**

```
123
```

**【样例输出 1】**

```
6
```

**【样例输入 2】**

```
1005
```

**【样例输出 2】**

```
6
```

**【样例说明】**

样例 1：1+2+3=6。样例 2：1+0+0+5=6（0 也要算，但加 0 不影响结果）。方法：每次取个位（n % 10）累加，再去掉个位（n / 10），循环到 n 变成 0 为止。

**【数据范围】**

1 ≤ n ≤ 1000000。

### zkh67 三角形判定（12 分）

**【题目描述】**

小赵有三根小棒，长度分别是 a、b、c。老师问他：这三根小棒能不能**首尾相接围成一个三角形**？

判断规则：任意两边之和大于第三边（即 a+b>c 且 a+c>b 且 b+c>a）才能围成三角形。

请你写程序：输入 a、b、c，判断能否围成三角形，能则输出 `Yes`，否则输出 `No`。

**【输入格式】**

一行，三个整数 a、b、c。

**【输出格式】**

一行，输出 `Yes` 或 `No`。

**【样例输入 1】**

```
3 4 5
```

**【样例输出 1】**

```
Yes
```

**【样例输入 2】**

```
1 2 3
```

**【样例输出 2】**

```
No
```

**【样例说明】**

样例 1：3+4>5、3+5>4、4+5>3 都成立，能围成三角形。样例 2：1+2=3，不大于 3（两边之和等于第三边），不能围成三角形。注意：恰好相等也不行，必须"大于"。

**【数据范围】**

1 ≤ a, b, c ≤ 1000。

### zkh68 能量水晶（12 分）

**【题目描述】**

探险家小赵在洞穴里找到了 n 颗能量水晶，每颗水晶的能量值都记了下来。传说中，**能量最高**的那颗水晶能启动上古祭坛，祭坛会把它的能量**放大 5 倍**，再**平均分成 2 份**（每份取整数部分）注入两颗魔法石。

请你写程序：输入 n 和 n 颗水晶的能量值，求出**最大能量 × 5 ÷ 2** 的结果（整数运算，先乘 5 再除以 2，取整数部分）。

**【输入格式】**

第一行，一个整数 n。

第二行，n 个整数，表示每颗水晶的能量值。

**【输出格式】**

一行，一个整数，表示最大能量 × 5 ÷ 2 的结果。

**【样例输入 1】**

```
5
3 9 2 9 1
```

**【样例输出 1】**

```
22
```

**【样例输入 2】**

```
3
7 7 7
```

**【样例输出 2】**

```
17
```

**【样例说明】**

样例 1：最大能量是 9，9 × 5 = 45，45 ÷ 2 = 22（整数部分，余数丢弃）。样例 2：最大能量是 7，7 × 5 = 35，35 ÷ 2 = 17（余数丢弃）。注意：先乘 5 再除以 2，顺序不能反；除法是整数除法，结果向下取整。

**【数据范围】**

1 ≤ n ≤ 1000，1 ≤ 能量值 ≤ 10000。

### zkh69 空心三角形（12 分）

**【题目描述】**

小明想用 `*` 号在屏幕上画一个**空心三角形**：一共 n 行，第 i 行有 i 个位置。最后一行（第 n 行）全部画 `*`；其他行只有**最左边和最右边**两个位置画 `*`，中间用空格。

请你写程序：输入 n，输出这个空心三角形。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

n 行，输出空心三角形，每行末尾不要有多余的空格。

**【样例输入 1】**

```
4
```

**【样例输出 1】**

```
*
**
* *
****
```

**【样例输入 2】**

```
6
```

**【样例输出 2】**

```
*
**
* *
*  *
*   *
******
```

**【样例说明】**

第 1 行 1 个 `*`；第 2 行两个位置都是 `*`（`**`）；第 3 行是 `* *`（两端 `*` 中间 1 空格）；……第 n 行是 n 个 `*` 全填满。判断方法：第 i 行的第 j 个位置，当 `i==n`（最后一行）或 `j==1` 或 `j==i`（两端）时画 `*`，否则画空格。

**【数据范围】**

1 ≤ n ≤ 20。

### zkh70 空心矩形（12 分）

**【题目描述】**

小明想用 `*` 号在屏幕上画一个**空心矩形**：n 行 n 列。**边框**（第 1 行、第 n 行、第 1 列、第 n 列）全部画 `*`，矩形内部的格子画空格。

请你写程序：输入 n，输出这个空心矩形。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

n 行，每行 n 个字符，输出空心矩形。

**【样例输入 1】**

```
3
```

**【样例输出 1】**

```
***
* *
***
```

**【样例输入 2】**

```
4
```

**【样例输出 2】**

```
****
*  *
*  *
****
```

**【样例说明】**

第 1 行和第 n 行全是 `*`（上边框、下边框）；中间的行是 `*` + 若干空格 + `*`（第 1 列和第 n 列是 `*`）。判断方法：`i==1 || i==n || j==1 || j==n` 时画 `*`，否则画空格。

**【数据范围】**

1 ≤ n ≤ 20。
