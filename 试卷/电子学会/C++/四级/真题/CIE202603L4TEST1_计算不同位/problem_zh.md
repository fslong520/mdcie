# 计算不同位

#### 题目描述

给你两个正整数 m、n，请问它们二进制位上有多少位是不同的。

#### 输入格式

两个正整数 n、m。

#### 输出格式

一个整数，表示答案。

#### 样例输入 #1

```
2 1
```

#### 样例输出 #1

```
2
```

#### 样例输入 #2

```
3 17
```

#### 样例输出 #2

```
2
```

#### 样例输入 #3

```
233 233
```

#### 样例输出 #3

```
0
```

#### 数据范围

1 ≤ n、m ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1200**。
