### 第 1 题（2026 电子学会4级真题·指针）已知 int x = 15; int *p = &x; ，以下说法【错误】的是？（ ）

- A. p 中存储的是变量 x 的内存地址
- B. *p 代表指针 p 指向的变量 x 的值
- C. 执行*p = 20; 后 ，x 的值会变为 20
- D. 执行 p = 20; 后 ，x 的值会变为 20

**答案：D**

**解析：** p = 20; 含义是让指针 p 指向地址编号 20，不会改变 x 的值，而且一般属于非法地址操作。

### 第 2 题（2026 电子学会4级真题·指针）执行以下代码 ，输出结果是？（ ） int arr[5] = {10, 20, 30, 40, 50}; int *p = arr; cout << *(p + 2);

- A. 10
- B. 20
- C. 30
- D. 40

**答案：C**

**解析：** 指针p指向数组首地址，则p+2指向第3个元素，取其值为：30。

### 第 3 题（2026 电子学会4级真题·类）以下关于C++类的说法 ，正确的是？（ ）

### 第 4 题（2026 电子学会4级真题·结构体）有结构体定义如下 ，以下写法正确的是？（ ） struct Book{ string name; double price; };

- A. Book .name = "C++入门";
- B. Book b; b .price = 39.9;
- C. Book b; b->name = "算法竞赛";

**答案：B**

### 第 5 题（2026 电子学会4级真题·进制转换）将十进制数 25 转换为二进制 ，结果是？（ ）

- A. 10101
- B. 11001
- C. 11100
- D. 10011

**答案：B**

**解析：** 除2求余法：
25 / 2 = 12 ... 1
12 / 2 = 6 ... 0
6 / 2 = 3 ... 0
3 / 2 = 1 ... 1
1 / 2 = 0 ... 1
余数逆序：11001。

- A. 快速排序是分治思想的典型应用
- B. 冒泡排序每一轮都会将一个最大的元素“冒泡”到末尾

- T. 正确
- F. 错误

**答案：T**

**解析：** NULL本质是宏#define NULL 0，属于整型常量；nullptr 是独立空指针常量类型。

### 第 21 题（2026 电子学会4级真题·位运算）总异或和

**OJ 链接：** <https://fslong.iok.la/problem/P9836>

总异或和
给定长度为 n 的序列 A1、A2、……、An
，我们要计算所有数对 (i, j) 对应的 Ai +Aj 的总异或和。
即把所有满足 1≤ i、j ≤n 的 Ai +Aj 依次进行异或，输出最终结果。
举例：当 n = 3 时，计算式为：
(A1+A1)⊕(A1+A2)⊕(A1+A3)⊕(A2+A1)⊕(A2+A2)⊕(A2+A3)⊕(A3+A1)⊕(A3+A2)⊕(A3+A3)
其中 ⊕ 表示按位异或运算。
输入格式
共两行，第一行，一个正整数 n；
第二行，n 个正整数，表示序列 A1、A2、……、An。
输出格式
输出一个整数，表示所有数对计算后的总异或值。
【样例输入】
3
2 12 27
【样例输出】
42
【数据范围】
1<=n<=1000000，1<=Ai<=10^9。

**【参考程序】**

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MAXN = 1e6 + 10;
int n, a[MAXN];
ll x[MAXN];
int main() {
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    ll ans = 0;
    // 枚举每一位 k
    for (int k = 0; k <= 30; k++) {
        ll bit = 1LL << k;
        ll mask = bit << 1; // 2^(k+1)
        for (int i = 0; i < n; i++) {
            x[i] = a[i] % mask;
        }
        sort(x, x + n);
        ll cnt = 0;
        ll L1 = bit, R1 = mask;
        ll L2 = 3 * bit, R2 = mask * 2;
        for (int i = 0; i < n; i++) {
            ll v = x[i];
            // [L1 - v, R1 - v)
            cnt += upper_bound(x, x + n, R1 - 1 - v) - lower_bound(x, x + n, L1 - v);
            // [L2 - v, R2 - v)
            cnt += upper_bound(x, x + n, R2 - 1 - v) - lower_bound(x, x + n, L2 - v);
        }
        if (cnt % 2 == 1) {
            ans |= bit;
        }
    }
    cout << ans << endl;
    return 0;
}
```

三数之和
给定三个非负整数 a、b、c
，请你求出三个数的和。
输入格式

输出格式

【样例输入1】
1
2
3
【样例输出1】
6
【样例输入2】
111111111111111111111111111111111111111111111111111
222222222222222222222222222222222222222222222222222
333333333333333333333333333333333333333333333333333
【样例输出2】
666666666666666666666666666666666666666666666666666
【数据范围】
0<=a、b、c<=10^1000。

**【参考程序】**

```cpp
#include <bits/stdc++.h>
using namespace std;
string addBig(string a, string b) {
    int i = a.size() - 1, j = b.size() - 1;
    int carry = 0;
    string result = "";
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        result += (sum % 10) + '0';
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    return result;
}
int main() {
    string a, b, c;
    cin >> a >> b >> c;
    string ans = addBig(addBig(a, b), c);
    cout << ans << endl;
    return 0;
}
```
