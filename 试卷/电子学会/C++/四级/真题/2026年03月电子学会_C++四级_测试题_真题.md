### 第 2 题（2026 电子学会4级真题·位运算）按位与运算常用于？ （ ）

- A. 清零特定位
- B. 判断奇偶
- C. 取某位值
- D. 以上都是

**答案：D**

**解析：** 按位与 & 的常用：
清零特定位：x & 0xF0 可清零低 4 位；
判断奇偶：x & 1 若为 1 则为奇数，否则偶数；
取某位值：(x >> k) & 1 取出第 k 位的值；
本题答案为选项D。

- B. 堆排序
- C. 归并排序
- D. 选择排序

**答案：C**

**解析：** 快速排序、堆排序、选择排序交换可能打乱相等元素的顺序，是不稳定的。

- B. O (2^n)
- C. O (n^2)

**答案：B**

题目描述
给你两个正整数 m、n

输入
两个正整数 n、m。

数据范围：1≤n、m≤10^9。
【样例输入1】
2 1

3 17

2

233 233
【样例输出3】
0

**【参考程序】**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m, ans = 0;
    unsigned int mask = 1;
    cin >> n >> m;
    for(int i=0; i<32; i++) {
        if((n & mask) != (m & mask))
            ans++;
        mask<<=1;  //左移一位
    }
    cout << ans;
    return 0;
}
```

### 第 22 题（2026 电子学会4级真题·高精度）四方定理

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L4TEST2>

四方定理
题目描述
给定一个自然数 n
，请输出 n 的所有四平方拆分方案。
输入
单个整数：表示 n。
输出
若干行：每行四个由小到大排列的自然数，表示一种拆分方案。
如果有多种方案，先输出首项较小的方案，对于首项相同的方案，先输出第二项较小的方案，其他情况以此类推。
数据范围：0≤n≤50,000。
【样例输入1】
25
【样例输出1】
0 0 0 5
0 0 3 4
1 2 2 4

**【参考程序】**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    for(int a=0; a*a<=n; a++) { //使用三重循环避免超时
        for(int b=a; a*a+b*b<=n; b++) {
            for(int c=b; a*a+b*b+c*c<=n; c++) {
                int left=n-a*a-b*b-c*c; //剩余数
                int d=sqrt(left);
                if(d*d==left && d>=c) //判断d是整数即可
                    cout << a << " " << b << " " << c << " " << d << endl;
            }
        }
    }
    return 0;
}
```
