### 第 1 题（2026 电子学会4级真题·指针）已知 int x = 10; ，要让指针 p 指向 x，以下写法正确的？（ ）

- A. int p = &x;
- B. int *p = &x;
- C. int *p = x;
- D. *p = &x;

**答案：B**

**解析：** 定义指针p指向x：int *p = &x;
&是取地址符号。

### 第 2 题（2026 电子学会4级真题·指针）执行以下代码 ，输出结果？（ ） int a = 20; int *p = &a; *p = 30; cout << a;

- A. 20
- B. 30
- C. 0
- D. 随机值

**答案：B**

**解析：** 指针 p 指向 a，修改 *p 的值，相当于修改 a 的值，最终输出30。

### 第 3 题（2026 电子学会4级真题·结构体）以下关于C++结构体的说法 ，错误的？（ ）

- A. 结构体可以包含多个不同类型的成员变量
- B. 结构体可以定义成员函数
- C. 结构体变量的成员可以通过 . 运算符访问

### 第 4 题（2026 电子学会4级真题·结构体）有结构体定义如下 ，访问结构体变量 s 的 age 成员，写法正确的？（ ） struct Student{ string name; int age; }; Student s;

### 第 8 题（2026 电子学会4级真题·排序）以下关于排序算法稳定性的说法 ，正确的？（ ）

- B. 选择排序是稳定排序
- C. 插入排序是稳定排序
- D. 快速排序是稳定排序

### 第 9 题（2026 电子学会4级真题·高精度）在用数组实现高精度加法时 ，若从数组下标 0 开始存储数字，通常选择将最低位存储在下标 0 处。这样设计的主要原因？（ ）

- A. 方便按从低位到高位的顺序处理进位
- B. 方便按从高位到低位输出
- C. 节省数组空间
- D. 避免数组越界

**答案：A**

**解析：** 加法运算是从最低位（个位）开始逐位相加，并向上一位传递进位。
将最低位存储在下标 0，可以使循环索引自然地从 0 递增，符合进位传递的方向。

- B. max(n , m) + 1
- C. n + m
- D. n + m + 1

**解析：** 较大的数有可能产生进位，因此位数最大为：max(n, m) + 1。

### 第 17 题（2026 电子学会4级真题·排序）快速排序的核心思想是分治法 。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 快速排序：
分解：选择一个基准元素（pivot），将数组划分为两个子数组，使得左边子数组的所有元素 ≤ 基准，右边子数组的所有元素 ≥ 基准。
解决：递归地对左右两个子数组进行快速排序。
正是分治法的核心思想。

### 第 22 题（2026 电子学会4级真题·高精度）双阶乘

**OJ 链接：** <https://fslong.iok.la/problem/CIE202603L4B>

双阶乘
题目描述：双阶乘（用 n!! 表示）是阶乘的一种扩展形式
，其定义为：
对于给定的非负整数 n，n!! 表示从 n 开始，依次乘以比前一项小 2 的数，直至乘积项不小于 1 为止。
具体规则：
若 n 为偶数：n!!=n×(n-2)×(n-4)×…×2；
若 n 为奇数：n!!=n×(n-2)×(n-4)×…×1；
特别地，0!!=1，1!!=1。
给定一个整数 n，请使用高精度算法计算并输出 n!! 的结果。
输入格式
单个整数表示 n。
输出格式
单个整数，表示 n!! 的计算结果。
【样例输入1】
5
【样例输出1】
15
【样例输入2】
20
【样例输出2】
3715891200
【样例输入3】
100
【样例输出3】
34243224702511976248246432895208185975118675053719198827915654463488000000000000
【数据范围】
0≤n≤2000。

**【参考程序】**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    // 特殊情况：0!! 和 1!! 都为 1
    if (n == 0 || n == 1) {
        cout << "1" << endl;
        return 0;
    }
    // 用 vector 存储高精度数，低位在前（索引0是个位）
    vector<int> res;
    res.push_back(1); // 初始值为 1
    // 确定遍历的起始值和步长
    int start = n;
    int step = -2;
    int end = (n % 2 == 0) ? 2 : 1;
    // 高精度乘法：res = res * num
    for (int num = start; num >= end; num += step) {
        int carry = 0;
        for (int i = 0; i < res.size(); ++i) {
            long long product = (long long)res[i] * num + carry;
            res[i] = product % 10;
            carry = product / 10;
        }
        // 处理剩余进位
        while (carry > 0) {
            res.push_back(carry % 10);
            carry /= 10;
        }
    }
    // 逆序输出（因为低位在前，需要从高位到低位）
    for (int i = res.size() - 1; i >= 0; --i) {
        cout << res[i];
    }
    cout << endl;
    return 0;
}
```

**解析：** 见参考程序。
