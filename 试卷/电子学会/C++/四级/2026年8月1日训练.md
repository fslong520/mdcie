### 第 1 题（指针）已知 `int x = 5; int *p = &x;`，执行 `*p = *p + 1;` 后，`x` 的值是？（ ）

- A. 5
- B. 6
- C. 地址值
- D. 随机值

**答案：B**

**解析：** `p` 指向 `x`，`*p` 即 `x` 本身。`*p = *p + 1` 等价于 `x = x + 1`，故 `x` 变为 6。

---

### 第 2 题（指针）执行以下代码，输出结果是？（ ）

```cpp
int arr[3] = {7, 8, 9};
int *p = arr;
cout << *(p + 2);
```

- A. 7
- B. 8
- C. 9
- D. 数组首地址

**答案：C**

**解析：** 指针 `p` 指向数组首元素，`p + 2` 指向第 3 个元素，解引用得 9。

### 第 3 题（进制转换）将十进制数 29 转换为二进制，结果是？（ ）

- A. 11101
- B. 11001
- C. 11100
- D. 10011

**答案：A**

**解析：** 29 = 16+8+4+1 = 2⁴+2³+2²+2⁰，对应二进制 11101；也可除 2 取余：29→14 余 1、14→7 余 0、7→3 余 1、3→1 余 1、1→0 余 1，余数倒序 11101。

### 第 4 题（结构体）有结构体定义如下，访问结构体变量 `p` 的 `y` 成员，写法正确的是？（ ）

```cpp
struct Point {
    int x, y;
};
Point p;
```

- A. `p->y`
- B. `Point.y`
- C. `p.y`
- D. `*p.y`

**答案：C**

**解析：** `p` 是结构体变量（非指针），用 `.` 访问成员；`->` 用于指针访问；`Point` 是类型名不能访问成员。

### 第 5 题（结构体）执行以下代码后，输出结果是？（ ）

```cpp
struct Student {
    string name;
    int score;
};
Student s[3] = {{"A", 80}, {"B", 90}, {"C", 70}};
cout << s[1].score;
```

- A. 80
- B. 90
- C. 70
- D. 随机值

**答案：B**

**解析：** `s[1]` 是数组第 2 个元素（下标从 0 起），其 `score` 为 90。

### 第 6 题（二维数组）执行以下代码，输出结果是？（ ）

```cpp
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
cout << a[1][2];
```

- A. 3
- B. 4
- C. 5
- D. 6

**答案：D**

**解析：** `a[1]` 是第 2 行 `{4,5,6}`，`a[1][2]` 取该行第 3 个元素，为 6。

### 第 7 题（递推）递推数列满足 f(1)=1, f(2)=1，n≥3 时 f(n)=f(n−1)+f(n−2)，则 f(7) 的值是？（ ）

- A. 8
- B. 11
- C. 13
- D. 21

**答案：C**

**解析：** 逐项推出：f(3)=2, f(4)=3, f(5)=5, f(6)=8, f(7)=13。

### 第 8 题（排序）冒泡排序对 n 个元素排序，最坏情况下比较次数约为？（ ）

- A. n
- B. n²/2
- C. n log n
- D. n/2

**答案：B**

**解析：** 冒泡排序最坏需约 n(n−1)/2 次比较，即 O(n²)，n²/2 为其主要量级。

---

### 第 9 题（排序）直接选择排序的每一轮操作是？（ ）

- A. 选出未排序序列中的最小值，与未排序序列的第一个元素交换
- B. 将当前元素与前面已排序序列逐个比较并插入
- C. 相邻两元素比较，逆序则交换
- D. 任选基准将序列分成两部分

**答案：A**

**解析：** 选择排序每轮从未排序部分挑出最小值，交换到未排序部分开头；B 是插入排序，C 是冒泡排序，D 是快速排序。

### 第 10 题（高精度）高精度加法中，某一位上两数相加再加进位得到 14，正确的处理是？（ ）

- A. 该位写 14，进位 0
- B. 该位写 4，进位 1
- C. 该位写 1，进位 4
- D. 该位写 14，进位 1

**答案：B**

**解析：** 满十进一：该位保留 14 % 10 = 4，向高一位进位 14 / 10 = 1。

### 第 12 题（指针）对空指针 `NULL` 解引用是安全操作，不会出错。（ ）

- F. 错误

### 第 15 题（二维数组）二维数组 `int a[3][4]` 可以理解为：一个长度为 3 的数组，每个元素又是一个长度为 4 的数组。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 二维数组本质是"数组的数组"，`a` 有 3 行，每行是一个含 4 个 int 的一维数组。

### 第 16 题（位运算）`&` 与 `&&` 都可用于逻辑判断，二者作用相同。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** `&` 是按位与，对每一位进行运算；`&&` 是逻辑与，只返回真(1)/假(0)。

### 第 17 题（排序）插入排序是稳定排序算法。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 插入排序遇到相等元素时插在其后，不改变相等元素的相对顺序，是稳定的。

---

### 第 18 题（排序）快速排序最坏时间复杂度为 O(n log n)。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 快排平均为 O(n log n)，但最坏（如序列已有序）退化为 O(n²)。

---

### 第 19 题（递推）递推算法是从已知条件出发，利用递推关系逐项求出后续结果。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 递推先确定初值，再按递推公式从前向后逐项计算，直至求出目标项。

### 第 20 题（高精度）高精度减法中，若被减数小于减数，应交换两数并在结果前加负号。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** a−b 当 a<b 时等于 −(b−a)，先算大减小，再补负号，避免负数借位的复杂处理。

### P9856 落单的快递★★（12 分）

**【题目描述】**

快递驿站盘点，仓库里除一个快递外，其余每个编号的快递都恰好扫码了两遍（成对出现）。由于扫描顺序打乱了，请找出那个只扫到一遍的快递编号。

**【输入格式】**

第一行，一个整数 n（奇数）。
第二行，n 个整数，表示扫码到的编号。

**【输出格式】**

一行，落单的编号。

**【样例输入】**

```
7
1 2 3 2 1 4 3
```

**【样例输出】**

```
4
```

解析：编号 1、2、3 都出现两次，互相抵消，只有 4 出现一次。

**【数据范围与提示】**

- 30% 数据：n ≤ 100，编号 ≤ 100
- 100% 数据：1 ≤ n ≤ 10⁵（n 为奇数），1 ≤ 编号 ≤ 10⁹；提示：相同的数异或为 0，把所有编号异或起来，剩下的就是落单的

### P9857 进制数字和★★（12 分）

**【题目描述】**

冯老师讲进制时留了个练习：给定 n 和进制 base，把 n 转成 base 进制，再把各位数字加起来。请你帮同学们算算。

**【输入格式】**

一行，两个整数 n 和 base。

**【输出格式】**

一行，n 的 base 进制表示中各位数字之和。

**【样例输入】**

```
255 16
```

**【样例输出】**

```
30
```

解析：255 转十六进制为 FF，F=15，各位和 15+15=30。

**【数据范围与提示】**

- 30% 数据：n ≤ 100
- 100% 数据：0 ≤ n ≤ 10⁹，2 ≤ base ≤ 16；提示：反复取余求各位数字，字母 A~F 对应 10~15
