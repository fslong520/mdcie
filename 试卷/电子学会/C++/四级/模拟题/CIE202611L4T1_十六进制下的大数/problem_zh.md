# 十六进制下的大数

#### 题目描述

输入两个正整数 a、b（十进制表示，但可能非常大），计算 a × b，并把乘积以十六进制输出（字母大写）。

#### 输入格式

一行，两个正整数 a、b，用空格隔开（1 ≤ a, b < 10¹⁰，可能超出 long long，须用高精度）。

#### 输出格式

一行，a × b 的十六进制表示，字母大写，无前导零。

#### 样例输入 #1

```
255 16
```

#### 样例输出 #1

```
FF0
```

#### 样例说明 #1

255 × 16 = 4080 = 0xFF0。

#### 样例输入 #2

```
123456789 987654321
```

#### 样例输出 #2

```
1B13114FBFF5385
```

#### 数据范围

1 ≤ a, b < 10¹⁰。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1000**。
