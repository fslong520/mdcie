# 开关灯

走廊上有 n 盏灯，编号 0 到 n-1，初始时全部关闭。进行 m 次操作，第 i 次操作给定编号 k，将编号为 k 的灯状态取反（开着变关闭，关闭变开着）。求 m 次操作后每盏灯的状态。

【输入格式】第一行两个整数 n 和 m。接下来 m 行，每行一个整数 k，表示本次取反的灯编号。
【输出格式】一行 n 个整数（0 表示关闭，1 表示打开），从灯 0 到灯 n-1，相邻数用一个空格分隔。
【样例输入 1】
```
5 3
0
2
0
```
【样例输出 1】
```
0 0 1 0 0
```
【样例说明】灯 0 被取反两次仍关闭，灯 2 取反一次打开，其余始终关闭。
【数据范围】1 ≤ n ≤ 30，1 ≤ m ≤ 10⁵，0 ≤ k < n。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1400**。
