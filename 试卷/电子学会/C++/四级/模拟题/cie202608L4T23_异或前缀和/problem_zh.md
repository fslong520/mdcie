# 异或前缀和

小码在学习按位异或运算 ⊕：两个二进制数逐位比较，相同为 0、不同为 1。现在他想快速算出一串连续整数的异或和——从 1 一直异或到 n，即 1⊕2⊕3⊕…⊕n 等于多少。n 可能很大，直接循环太慢，请你帮他找到规律算出结果。

【输入格式】一行，一个正整数 n（1 ≤ n ≤ 10⁹）。
【输出格式】一行，1⊕2⊕3⊕…⊕n 的结果。

【样例输入 1】
```
5
```
【样例输出 1】
```
1
```
【样例说明 1】1⊕2⊕3⊕4⊕5 = 1⊕2=3，3⊕3=0，0⊕4=4，4⊕5=1，结果是 1。

【样例输入 2】
```
6
```
【样例输出 2】
```
7
```
【样例说明 2】在上一步 1⊕2⊕3⊕4⊕5=1 的基础上再 ⊕6，1⊕6 = (001)₂⊕(110)₂ = (111)₂ = 7。

【数据范围】1 ≤ n ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1400**。
