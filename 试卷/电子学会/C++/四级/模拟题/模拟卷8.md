## 三、编程题（4 题 × 15 分 = 60 分）

### 第 21 题 十六进制下的大数

输入两个正整数 a、b（十进制，但可能非常大，须用高精度），计算 a × b，并以十六进制输出乘积（字母大写）。

**输入格式**

一行，两个正整数 a、b（1 ≤ a, b < 10¹⁰，均可能超出 long long，须高精度乘法）。

**输出格式**

一行，a × b 的十六进制表示，字母大写，无前导零。

**样例输入 1**

```
255 16
```

**样例输出 1**

```
FF0
```

**样例说明 1**：255×16 = 4080 = 0xFF0。

**样例输入 2**

```
123456789 987654321
```

**样例输出 2**

```
1B13114FBFF5385
```

**数据范围**

1 ≤ a, b < 10¹⁰。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202611L4T1>

### 第 22 题 进制查表机

实现一个进制转换器：输入一个整数 k（2 或 16）和一个 k 进制非负整数，把它转换成另一个进制输出。k=2 时转十六进制，k=16 时转二进制。

**输入格式**

一行，先是整数 k（2 或 16），空格后跟一个 k 进制非负整数 x（2 进制串长 ≤ 32；16 进制串长 ≤ 8）。x 无前导零（单独的 0 除外）。

**输出格式**

一行，x 在另一进制下的表示，字母大写，无前导零（结果 0 除外）。

**样例输入 1**

```
2 101010
```

**样例输出 1**

```
2A
```

**样例输入 2**

```
16 FF
```

**样例输出 2**

```
11111111
```

**数据范围**

2 进制串长 ≤ 32；16 进制串长 ≤ 8。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202611L4T2>

### 第 24 题 二进制回文数

一个正整数若其二进制表示（无前导零）正读反读完全一致，则称为"二进制回文数"。例如 9 的二进制是 1001，是回文数；6 的二进制是 110，不是。请统计区间 [1, n] 中二进制回文数的个数。

**输入格式**

一行，一个正整数 n（1 ≤ n ≤ 100000）。

**输出格式**

一行，一个整数，[1, n] 内二进制回文数的个数。

**样例输入 1**

```
10
```

**样例输出 1**

```
5
```

**样例说明 1**：1(1)、3(11)、5(101)、7(111)、9(1001) 共 5 个；10 的二进制 1010 反读为 0101，不同，不算。

**样例输入 2**

```
100
```

**样例输出 2**

```
19
```

**数据范围**

1 ≤ n ≤ 100000。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202611L4T4>
