### 第 21 题 十六进制转十四进制

#### 题目描述

给定一个十六进制非负整数（数字 0-9 与大写字母 A-F），请把它转换为十四进制数并输出。

十四进制的每一位取值为 0、1、2、…、9、A、B、C、D（其中 A 表示 10、B 表示 11、C 表示 12、D 表示 13）。

#### 输入格式

一行，一个十六进制非负整数（1 ≤ 串长 ≤ 8），无前导零；单独的 0 合法。

#### 输出格式

一行，对应的十四进制数，字母大写，无前导零（结果 0 除外）。

#### 样例输入 #1

```
1E
```

#### 样例输出 #1

```
16
```

#### 样例说明 #1

1E₁₆ = 30，30 = 2×14 + 2，即 22？——注意：30 ÷ 14 = 2 余 2，故 30 的十四进制是 22。样例输入改为验证：2×16+14 = 46，46 = 3×14 + 4 = 34₁₄。

#### 样例输入 #2

```
D
```

#### 样例输出 #2

```
D
```

#### 样例说明 #2

D₁₆ = 13，十三在十四进制中仍写作 D。

#### 数据范围

1 ≤ 串长 ≤ 8（数值 < 16⁸ ≈ 4.3×10⁹，超出 int，须用 long long 逐步转换）。

### 第 22 题 平方和拆分计数

#### 题目描述

给定自然数 n，统计有多少对非负整数 (a, b) 满足 a² + b² = n 且 a ≤ b。

#### 输入格式

一行，一个自然数 n（0 ≤ n ≤ 50000）。

#### 输出格式

一行，一个整数，满足条件的 (a, b) 对数。

#### 样例输入 #1

```
25
```

#### 样例输出 #1

```
2
```

#### 样例说明 #1

25 = 0² + 5² = 3² + 4²，共 2 对。

#### 样例输入 #2

```
0
```

#### 样例输出 #2

```
1
```

#### 样例说明 #2

0 = 0² + 0²。

#### 样例输入 #3

```
3
```

#### 样例输出 #3

```
0
```

#### 数据范围

0 ≤ n ≤ 50000。

### 第 24 题 乘积位数判定

#### 题目描述

给定两个正整数 a 和 b（都可能超过 64 位），请输出 a × b 的结果一共有多少位（十进制）。

注意：a × b 本身可能非常大（上千位），请不要真的把它乘出来——利用位值原理直接判定。

提示：若 a 有 p 位、b 有 q 位，则 a × b 的位数要么是 p + q − 1，要么是 p + q。

#### 输入格式

一行，两个正整数 a、b，用空格分隔（均不超过 500 位，无前导零）。

#### 输出格式

一行，一个整数，a × b 的位数。

#### 样例输入 #1

```
99 99
```

#### 样例输出 #1

```
4
```

#### 样例说明 #1

99 × 99 = 9801，共 4 位；位数和 2+2=4，恰好取上界。

#### 样例输入 #2

```
10 10
```

#### 样例输出 #2

```
3
```

#### 样例说明 #2

10 × 10 = 100，共 3 位；2+2=4，实际取 p+q−1=3。

#### 数据范围

a、b 均不超过 500 位。
