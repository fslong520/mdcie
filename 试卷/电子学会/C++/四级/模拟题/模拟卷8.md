## 三、编程题（4 题 × 15 分 = 60 分）

### 第 21 题 十六进制数求最大

**题目描述**

给出 n 个十六进制非负整数（数字 0-9 与大写字母 A-F），请找出其中最大的一个，并以十六进制输出。

**输入格式**

第一行一个整数 n（1 ≤ n ≤ 100）；

第二行 n 个十六进制非负整数，用空格分隔（每个串长不超过 8，无前导零，单独的 0 合法）。

**输出格式**

一行，最大的数的十六进制表示，字母大写，无前导零。

**样例输入 #1

```
3
FF A3 100
```

**样例输出 #1

```
FF
```

**样例说明** #1

FF = 255，A3 = 163，100₁₆ = 256；256 > 255，最大的数是 100₁₆。

**样例输入 #2

```
2
10 F
```

**样例输出 #2

```
F
```

**数据范围**

1 ≤ n ≤ 100，每个数串长 ≤ 8。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202611L4T1>

### 第 22 题 删0压缩

**题目描述**

给定一个正整数 n，把它写成二进制（不含前导零），删去其中所有的 0，只保留 1 并按原顺序拼接，得到一个纯 1 串；这个 1 串本身是一个二进制数，请输出它的十进制值。

例如 n = 26，二进制为 11010，删去 0 后得到 111，即十进制 7。

**输入格式**

一行，一个正整数 n。

**输出格式**

一行，一个整数，删 0 后的 1 串对应的十进制值。

**样例输入 #1

```
26
```

**样例输出 #1

```
7
```

**样例输入 #2

```
4
```

**样例输出 #2

```
1
```

**样例说明** #2

4 的二进制是 100，删 0 得 1。

**数据范围**

1 ≤ n ≤ 10⁹。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202611L4T2>

### 第 23 题 幂的十六进制

**题目描述**

给定底数 A（1 ≤ A ≤ 9）和指数 B（0 ≤ B ≤ 60），计算 Aᴮ 的精确值，并以十六进制输出（字母大写）。Aᴮ 可能远超 64 位整数范围，请使用高精度计算。

**输入格式**

一行，两个整数 A 和 B，用空格隔开（1 ≤ A ≤ 9，0 ≤ B ≤ 60）。

**输出格式**

一行，Aᴮ 的十六进制表示，字母大写，无前导零。

**样例输入 #1

```
2 8
```

**样例输出 #1

```
100
```

**样例说明** #1

2⁸ = 256 = 0x100。

**样例输入 #2

```
9 60
```

**样例输出 #2

```
C56A5F9EE2DB8B3F2D5
```

**样例输入 #3

```
5 0
```

**样例输出 #3

```
1
```

**数据范围**

1 ≤ A ≤ 9，0 ≤ B ≤ 60（9⁶⁰ 约 58 位十进制，须高精度）。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202611L4T3>
