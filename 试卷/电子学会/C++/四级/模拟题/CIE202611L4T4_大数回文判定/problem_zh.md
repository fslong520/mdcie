# 大数回文判定

#### 题目描述

给定一个大整数 A（可能超过 64 位，无前导零），判断它正读反读是否一致（即是否为回文数）。是输出 `Yes`，不是输出 `No`。

#### 输入格式

一行，一个非负大整数 A（长度 ≤ 200，无前导零；单独的 0 合法）。

#### 输出格式

一行，`Yes` 或 `No`。

#### 样例输入 #1

```
1234554321
```

#### 样例输出 #1

```
Yes
```

#### 样例输入 #2

```
123456789
```

#### 样例输出 #2

```
No
```

#### 样例输入 #3

```
0
```

#### 样例输出 #3

```
Yes
```

#### 数据范围

A 的长度 ≤ 200。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**900**。
