# 进制互转

计算机底层常在二进制与十六进制之间转换。十六进制使用数字 0~9 和大写字母 A~F（依次表示 10~15）。请写一个互转程序：若输入是二进制数，输出它的十六进制表示；若输入是十六进制数，输出它的二进制表示。

【输入格式】第一行一个字符 t（'B' 表示第二行是二进制数；'H' 表示第二行是十六进制数）。第二行一个非负整数 s，不含前导零（0 除外），二进制不超过 31 位、十六进制不超过 8 位。
【输出格式】一行，转换结果（十六进制用大写字母，均不含前导零）。
【样例输入 1】
```
B
1010101
```
【样例输出 1】
```
55
```
【样例说明】(1010101)₂ = 85 = (55)₁₆。
【样例输入 2】
```
H
FF
```
【样例输出 2】
```
11111111
```
【样例输入 3】
```
B
1111
```
【样例输出 3】
```
F
```
【数据范围】二进制数不超过 31 位，十六进制数不超过 8 位，对应十进制值 ≤ 2³¹−1。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
