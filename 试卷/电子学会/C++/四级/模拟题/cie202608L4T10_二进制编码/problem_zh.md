# 二进制编码

给定一个十进制非负整数 n，将其转换为二进制数并输出。
【输入格式】一个整数 n。
【输出格式】一个字符串，表示 n 的二进制表示。
【样例输入 1】
```
10
```
【样例输出 1】
```
1010
```
【样例输入 2】
```
0
```
【样例输出 2】
```
0
```
【数据范围】0 ≤ n ≤ 10⁹。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1400**。
