# 二进制中1的个数

给定 n 个非负整数，请输出每个数二进制表示中 1 的个数。

【输入格式】第一行一个整数 n。第二行 n 个整数。
【输出格式】n 行，每行一个整数，表示对应数二进制中 1 的个数。
【样例输入 1】
```
3
7 8 15
```
【样例输出 1】
```
3
1
4
```
【样例说明】7=111(3个1)，8=1000(1个1)，15=1111(4个1)。
【数据范围】1 ≤ n ≤ 1000，0 ≤ 每个数 ≤ 10⁹。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
