# 二进制转十六进制

#### 题目描述

给出一串由 0 和 1 组成的二进制串，请把它换算成十六进制并输出（字母用大写 A-F）。

从二进制转十六进制时，从右往左每四位分成一组，每组换成一个十六进制数码；最左边不足四位的一组按实际位数换算。

#### 输入格式

一行，一个二进制串 s（1 ≤ 串长 ≤ 32），不含前导零；若输入只有一位，则为 0。

#### 输出格式

一行，对应的十六进制数，字母大写，无前导零（结果 0 除外）。

#### 样例输入 #1

```
11011
```

#### 样例输出 #1

```
1B
```

#### 样例输入 #2

```
101010
```

#### 样例输出 #2

```
2A
```

#### 样例输入 #3

```
0
```

#### 样例输出 #3

```
0
```

#### 数据范围

1 ≤ 串长 ≤ 32。
