# 大数乘个位

#### 题目描述

给定一个大整数 A（可能超过 64 位）和一个一位数 d（0 到 9），请计算 A × d 并输出精确值。

#### 输入格式

第一行：大整数 A（字符串形式，不含前导零；单独的 0 合法，长度 ≤ 200）。

第二行：整数 d（0 ≤ d ≤ 9）。

#### 输出格式

一行，A × d 的精确值（如结果为 0，输出 0）。

#### 样例输入 #1

```
99999999999999999999
9
```

#### 样例输出 #1

```
899999999999999999991
```

#### 样例输入 #2

```
123456789
0
```

#### 样例输出 #2

```
0
```

#### 数据范围

A 的长度 ≤ 200，0 ≤ d ≤ 9。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**900**。
