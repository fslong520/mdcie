# 约瑟夫问题

n 个人围成一圈，从第 1 个人开始报数，数到 m 的人出列，下一个人从 1 开始重新报数。求最后剩下的人的编号。

【输入格式】一行两个整数 n 和 m。
【输出格式】一个整数，表示最后剩下的人的编号。
【样例输入 1】
```
5 3
```
【样例输出 1】
```
4
```
【样例输入 2】
```
7 3
```
【样例输出 2】
```
4
```
【数据范围】1 ≤ n ≤ 5000，1 ≤ m ≤ 100。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
