# 判断2的幂

#### 题目描述

给定一个正整数 x，判断 x 是否可以表示为 2 的幂，即是否存在非负整数 k 使 x = 2ᵏ。要求使用位运算判断。

#### 输入格式

第一行：整数 n（1 ≤ n ≤ 1000）
第二行：n 个正整数，用空格分隔

#### 输出格式

n 行，每行一个 `YES` 或 `NO`，表示对应整数是否为 2 的幂。

#### 样例输入 #1

```
4
1 2 3 16
```

#### 样例输出 #1

```
YES
YES
NO
YES
```

#### 样例输入 #2

```
3
5 8 100
```

#### 样例输出 #2

```
NO
YES
NO
```

#### 数据范围

1 ≤ n ≤ 1000，1 ≤ x ≤ 10⁹。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1200**。
