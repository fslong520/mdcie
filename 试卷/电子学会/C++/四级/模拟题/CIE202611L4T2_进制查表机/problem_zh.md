# 进制查表机

#### 题目描述

实现一个进制转换器：输入一个整数 k（2 或 16）和一个 k 进制非负整数 x，把 x 转换到另一种进制输出。k=2 时输出十六进制，k=16 时输出二进制。

#### 输入格式

一行，先是一个整数 k（2 或 16），空格后是一个 k 进制非负整数 x。2 进制串长 ≤ 32；16 进制串长 ≤ 8。x 无前导零（单独的 0 合法）。

#### 输出格式

一行，x 在另一种进制下的表示，字母大写，无前导零（结果 0 除外）。

#### 样例输入 #1

```
2 101010
```

#### 样例输出 #1

```
2A
```

#### 样例输入 #2

```
16 FF
```

#### 样例输出 #2

```
11111111
```

#### 样例输入 #3

```
16 0
```

#### 样例输出 #3

```
0
```

#### 数据范围

2 进制串长 ≤ 32；16 进制串长 ≤ 8。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1000**。
