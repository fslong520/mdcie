# 📘 位运算与进制转换专项模拟卷

---

# 客观题 20 道（单选 10×2 分 + 判断 10×2 分 = 40 分） + 编程题 5 道（12 分/题 = 60 分）

> 本卷里每道题都藏着一个生活小场景。请先读懂场景，再动手分析——你会发现有的是「按位拨弄灯带」，有的是「在二进制和八进制之间变来变去」，背后是同一套把数拆开又拼起的本领。

---

### 第 1 题（灯带查位）小雨的灯带（一串开/关灯，1 亮 0 灭）是 101101。他想弄清「从右数第 2 盏灯」（最右那盏算第 1 盏）是亮还是灭。这盏灯是？（）

- A. 亮
- B. 灭
- C. 最右那盏
- D. 无法判断

---

### 第 2 题（计步器末灯）一款计步器把步数记成灯带，最右边一盏亮表示「走了奇数步」。现在灯带最右一盏是亮的，说明步数是？（）

- A. 偶数
- B. 奇数
- C. 零
- D. 无法判断

---

### 第 3 题（灯带左挪）把整条灯带整体向左挪一格（右边补一盏灭灯 0），数值会怎样变化？比如灯带 101（代表 5）左挪后变成 1010（代表 10）。（）

- A. 变成一半
- B. 翻倍
- C. 不变
- D. 全清零

---

### 第 4 题（开关翻转）墙上面板，按一下某盏灯就翻转（亮变灭、灭变亮）。小博发现用「当前状态 异或 1」就能翻转：1⊕1=0、0⊕1=1。这个办法可行吗？（）

- A. 可行
- B. 不行
- C. 只对亮灯
- D. 只对灭灯

---

### 第 5 题（取一颗旋钮）调色旋钮每颗代表「连续三位灯」（也就是 0~7 八档）。要单独取出灯带最右边三位（对应一颗旋钮），可用「灯带 与 111（也就是 7）」。灯带 101101 与 000111 得到 101（即 5）。这个办法对吗？（）

- A. 对
- B. 错

---

### 第 6 题（灯带分组）一条灯带是 101110。系统从右往左每 3 盏分成一组，用「八档旋钮」（0~7）表示。两组旋钮（从高位到低位）应拨到？（）

- A. 5、6
- B. 6、5
- C. 5、5
- D. 6、6

---

### 第 7 题（旋钮展开）旋钮拨到 7、3（八进制 73），要展开成一串灯（二进制）显示。这串灯是？（）

- A. 111011
- B. 111111
- C. 110011
- D. 111001

### 第 8 题（整条转八）二进制 1000 转成八进制旋钮，应是？（）

- C. 20
- D. 100

# 编程题（每题 12 分，共 60 分）

### P9820 灯带转旋钮（二进制转八进制） ★★（12 分）

**【题目描述】**

一款灯带游戏，灯只有「亮(1)」和「灭(0)」两态。系统要把整条灯带交给老式「八档旋钮」面板显示：每 3 盏灯合成一颗旋钮（0~7）。

给你一串二进制灯带（只含 0 和 1，除单独的「0」外没有多余的前导 0），请输出对应的八进制旋钮串（同样不要多余的前导 0；输入是「0」时输出「0」）。

**【输入格式】**

一行，一个二进制字符串 s。

**【输出格式】**

一行，s 对应的八进制字符串。

**【样例输入 #1】**

```
110101
```

**【样例输出 #1】**

```
65
```

**【样例输入 #2】**

```
0
```

**【样例输出 #2】**

```
0
```

**【数据范围】**

字符串长度不超过 30。

### P9821 旋钮转灯带（八进制转二进制） ★★（12 分）

**【题目描述】**

反过来：老面板用「八档旋钮」（0~7）记数字，新屏幕要用灯带（二进制）显示。

给你一串八进制旋钮串（只含 0~7），请展开成二进制灯带（每位八进制变成 3 位二进制，整体去掉最左边多余的灭灯；输入是「0」时输出「0」）。

**【输入格式】**

一行，一个八进制字符串 s。

**【输出格式】**

一行，s 对应的二进制字符串。

**【样例输入 #1】**

```
65
```

**【样例输出 #1】**

```
110101
```

**【样例输入 #2】**

```
7
```

**【样例输出 #2】**

```
111
```

**【数据范围】**

字符串长度不超过 10。

---

### P9822 最右亮灯（取出最低位的 1） ★★（12 分）

**【题目描述】**

灯带里最右边那盏亮着的灯，代表一份特殊奖励，奖励编号就是「这盏灯所在位置的值」（从右往左第 1 盏值 1、第 2 盏值 2、第 3 盏值 4……即 2 的若干次方）。

给你一个数 n，输出最右边亮灯所代表的值（n = 0 时输出 0）。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，一个整数，表示最右边亮灯代表的值。

**【样例输入】**

```
12
```

**【样例输出】**

```
4
```

**【数据范围】**

0 ≤ n ≤ 10⁹。

---

### P9823 数亮灯（二进制中 1 的个数） ★★（12 分）

**【题目描述】**

想知道一条灯带上一共亮了几盏灯，就数一数里面有几个 1。

给你一个数 n，输出它灯带中亮灯（1）的总数（n = 0 时输出 0）。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，一个整数，表示亮灯的个数。

**【样例输入】**

```
13
```

**【样例输出】**

```
3
```

**【数据范围】**

0 ≤ n ≤ 10⁹。

---

### P9824 翻第 k 盏灯（按位取反） ★★★（12 分）

**【题目描述】**

遥控板上可以按编号翻掉某一盏灯：第 k 盏灯亮变灭、灭变亮（k 从 0 开始数，0 表示最右边那盏）。

给你 n 和 k，输出翻动之后灯带所代表的新数值。

**【输入格式】**

一行，两个整数 n 和 k，用空格隔开。

**【输出格式】**

一行，一个整数，表示翻动后的数值。

**【样例输入】**

```
10 1
```

**【样例输出】**

```
8
```

**【数据范围】**

0 ≤ n ≤ 10⁹，0 ≤ k ≤ 30。
