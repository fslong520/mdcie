# 十六进制数求最大

#### 题目描述

给出 n 个十六进制非负整数（数字 0-9 与大写字母 A-F），请找出其中最大的一个，并以十六进制输出。

#### 输入格式

第一行一个整数 n（1 ≤ n ≤ 100）；

第二行 n 个十六进制非负整数，用空格分隔（每个串长不超过 8，无前导零，单独的 0 合法）。

#### 输出格式

一行，最大的数的十六进制表示，字母大写，无前导零。

#### 样例输入 #1

```
3
FF A3 100
```

#### 样例输出 #1

```
FF
```

#### 样例说明 #1

FF = 255，A3 = 163，100₁₆ = 256；256 > 255，最大的数是 100₁₆。

#### 样例输入 #2

```
2
10 F
```

#### 样例输出 #2

```
F
```

#### 数据范围

1 ≤ n ≤ 100，每个数串长 ≤ 8。
