# 高精度减法

#### 题目描述

实现高精度减法：输入两个正整数 a、b（可能超过 64 位），输出 a - b 的结果。若 a < b，输出负数（即结果为负）。

#### 输入格式

第一行：正整数 a（字符串形式，不含前导0）
第二行：正整数 b（字符串形式，不含前导0）

#### 输出格式

一个整数，表示 a - b 的结果。若为负数，前加负号 `-`。

#### 样例输入 #1

```
1000
1
```

#### 样例输出 #1

```
999
```

#### 样例输入 #2

```
1
1000
```

#### 样例输出 #2

```
-999
```

#### 样例输入 #3

```
999999999999999999999999999999
1
```

#### 样例输出 #3

```
999999999999999999999999999998
```

#### 数据范围

a、b 长度 ≤ 500。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1600**。
