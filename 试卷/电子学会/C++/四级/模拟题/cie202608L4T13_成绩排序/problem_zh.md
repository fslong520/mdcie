# 成绩排序

有 n 个学生，每个学生有姓名和三科成绩（语文、数学、英语）。请按总分从高到低排序，总分相同则按姓名字典序升序输出。输出每位学生的姓名和总分。

【输入格式】第一行一个整数 n。接下来 n 行，每行一个字符串和三个整数，分别表示姓名、语文成绩、数学成绩、英语成绩。
【输出格式】n 行，每行一个姓名和一个整数，表示排序后的结果。
【样例输入 1】
```
3
amy 90 80 70
bob 85 90 80
cat 90 80 70
```
【样例输出 1】
```
bob 255
amy 240
cat 240
```
【样例说明】bob 总分 255 最高；amy 和 cat 同分 240，按姓名 amy < cat。
【数据范围】1 ≤ n ≤ 1000，姓名为小写字母，长度 ≤ 20，成绩 0-100。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
