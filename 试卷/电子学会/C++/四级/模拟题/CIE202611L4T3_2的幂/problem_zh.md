# 2的幂

#### 题目描述

计算 2ⁿ 的精确值，并以十六进制输出（字母大写）。提示：2 的幂在十六进制下形如 1 后面跟着若干个 0，请先用高精度逐次乘 2 求出精确值，再完成进制转换，以检验理解。

#### 输入格式

一行，一个非负整数 n。

#### 输出格式

一行，2ⁿ 的十六进制表示，字母大写，无前导零。

#### 样例输入 #1

```
8
```

#### 样例输出 #1

```
100
```

#### 样例说明 #1

2⁸ = 256 = 0x100。

#### 样例输入 #2

```
12
```

#### 样例输出 #2

```
1000
```

#### 数据范围

0 ≤ n ≤ 200（2²⁰⁰ 约 61 位，须高精度）。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**900**。
