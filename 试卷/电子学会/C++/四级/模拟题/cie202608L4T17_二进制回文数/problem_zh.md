# 二进制回文数

给定一个正整数 n，把它写成二进制表示（不含前导零），判断该二进制串是否为回文串（正读反读相同）。是输出 YES，否输出 NO。

【输入格式】一行一个正整数 n。
【输出格式】一行，YES 或 NO。
【样例输入 1】
```
5
```
【样例输出 1】
```
YES
```
【样例说明】5 的二进制为 101，是回文。
【样例输入 2】
```
6
```
【样例输出 2】
```
NO
```
【样例说明】6 的二进制为 110，不是回文。
【数据范围】1 ≤ n ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1300**。
