# 二进制反转

密码学中常用"位回文"变换打乱二进制编码：把一串二进制数字颠倒书写，就能产生一条看似无关的新编码。给定一个正整数 n，请去掉其二进制表示的前导零后把它颠倒顺序，得到一个"新二进制数"，再把它换算成十进制输出。

【输入格式】一行，一个正整数 n（1 ≤ n ≤ 10⁹）。
【输出格式】一行，n 的二进制表示颠倒顺序后所对应数字的十进制值。
【样例输入 1】
```
13
```
【样例输出 1】
```
11
```
【样例说明】13 的二进制为 1101，颠倒得 1011，十进制为 1×8 + 0×4 + 1×2 + 1×1 = 11。
【样例输入 2】
```
1
```
【样例输出 2】
```
1
```
【样例说明】1 的二进制为 1，颠倒仍为 1，输出 1。
【数据范围】1 ≤ n ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1300**。
