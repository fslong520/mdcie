# 进制转换

#### 题目描述

给定一个十进制非负整数 n，请将其转换为十六进制数并输出。十六进制数用数字 0-9 和字母 A-F 表示（A=10、B=11、C=12、D=13、E=14、F=15）。特别地，十进制 0 转换为十六进制仍为 0。

#### 输入格式

单个整数表示十进制非负整数 n。

#### 输出格式

单个字符串，表示 n 转换后的十六进制数。

#### 样例输入 #1

```
255
```

#### 样例输出 #1

```
FF
```

#### 样例输入 #2

```
4096
```

#### 样例输出 #2

```
1000
```

#### 样例输入 #3

```
0
```

#### 样例输出 #3

```
0
```

#### 数据范围

0 ≤ n ≤ 10⁹。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1200**。
