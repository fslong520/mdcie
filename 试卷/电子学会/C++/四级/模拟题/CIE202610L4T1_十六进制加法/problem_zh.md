# 十六进制加法

#### 题目描述

给定两个十六进制非负整数 A 和 B（数字 0-9 与大写字母 A-F），请计算它们的和，并以十六进制输出。

#### 输入格式

一行，两个十六进制非负整数 A、B，用空格隔开（串长均不超过 8，无前导零；单独的 0 合法）。

#### 输出格式

一行，A + B 的十六进制表示，字母大写，无前导零（结果 0 除外）。

#### 样例输入 #1

```
FF 1
```

#### 样例输出 #1

```
100
```

#### 样例输入 #2

```
2A 2A
```

#### 样例输出 #2

```
54
```

#### 样例输入 #3

```
0 0
```

#### 样例输出 #3

```
0
```

#### 数据范围

串长 ≤ 8（数值 < 16⁸ ≈ 4.3×10⁹，和可能超出 int，请注意类型）。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**900**。
