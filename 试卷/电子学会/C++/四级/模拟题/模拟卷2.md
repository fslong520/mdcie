### 第 1 题（电子学会四级模拟·指针）执行以下代码，输出结果是？（ ）

```cpp
int a[5] = {1, 2, 3, 4, 5};
int *p = a;
p++;
cout << *p;
```

- A. 1
- B. 5
- C. 3
- D. 2

**答案：D**

**解析：** `p` 初始指向数组首元素 `a[0]`（值为 1），执行 `p++` 后 `p` 指向下一个元素 `a[1]`，`*p` 取值为 2。

### 第 2 题（电子学会四级模拟·指针）执行以下代码，输出结果是？（ ）

```cpp
void f(int *p) { *p = 100; }
int x = 5;
f(&x);
cout << x;
```

- A. 5
- B. 0
- C. 随机值
- D. 100

**答案：D**

**解析：** `f(&x)` 将 `x` 的地址传给形参 `p`，`*p = 100` 通过指针把实参 `x` 的值改为 100，故输出 100。

### 第 3 题（电子学会四级模拟·结构体）有结构体定义如下，访问变量 `b` 中 `A` 类型成员 `a` 的成员 `x`，写法正确的是？（ ）

```cpp
struct A {
    int x;
};
struct B {
    A a;
    int y;
};
B b;
```

- A. `b.x`
- B. `B.a.x`
- C. `b.a.x`
- D. `a.x`

**答案：C**

**解析：** 嵌套结构体逐层访问：先通过 `b.a` 取得 `A` 类型成员，再访问其成员 `x`，写作 `b.a.x`。

### 第 4 题（电子学会四级模拟·类）以下关于 C++ 构造函数说法，正确的是？（ ）

- A. 构造函数与类同名，可以有返回值
- B. 构造函数在对象创建时自动调用
- C. 一个类只能定义一个构造函数
- D. 构造函数必须由程序员显式调用

**答案：B**

**解析：** 构造函数与类同名且无返回值（A 错）；可重载定义多个（C 错）；创建对象时自动调用、无需显式调用（D 错）。

### 第 5 题（电子学会四级模拟·进制转换）将二进制数 `10111101` 转换为十六进制数，结果是？（ ）

- A. 9D
- B. BD
- C. B3
- D. 8F

**答案：B**

**解析：** 从右向左每 4 位一组：`1011 1101`，对应十六进制 `B` 与 `D`，故为 `BD`₁₆。

### 第 6 题（电子学会四级模拟·位运算）32 位系统中，执行以下代码，输出结果是？（ ）

```cpp
int x = 0;
cout << (~x);
```

- A. 0
- B. 1
- C. 2147483647
- D. -1

**答案：D**

**解析：** 按位取反 `~0` 将每一位 0 变 1，32 位全 1 按补码解释为 -1。

### 第 7 题（电子学会四级模拟·排序）有 1000 个整数，取值范围为 0 到 100，要将其排序，下列哪种方法通常效率最高？（ ）

- A. 冒泡排序
- B. 归并排序
- C. 桶排序
- D. 插入排序

**答案：C**

**解析：** 数据取值范围很小时，桶排序（计数思想）只需遍历计数再输出，时间复杂度约 O(n+k)，远快于 O(n log n) 或 O(n²) 算法。

### 第 8 题（电子学会四级模拟·排序）对 n 个元素的数组进行冒泡排序，最多需要进行多少趟？（ ）

- A. n-1
- B. n
- C. 2
- D. n+1

**答案：A**

**解析：** 每趟至少让一个元素到位，n 个元素只需 n-1 趟即可保证全部有序。

### 第 9 题（电子学会四级模拟·高精度）高精度算法比较两个大整数 a 和 b 的大小时，首先应比较？（ ）

- A. 各位数字之和
- B. 位数
- C. 最高位数字
- D. 个位数字

**答案：B**

**解析：** 位数不同的两数，位数多者一定更大；位数相同时才逐位比较。故先比较位数。

### 第 10 题（电子学会四级模拟·高精度）十进制高精度减法中，若当前位不够减需向高位借 1，则借来的 1 相当于本位的多少？（ ）

- A. 9
- B. 1
- C. 10
- D. 0

**答案：C**

**解析：** 十进制中，高位 1 借到低位相当于 10，故当前位加 10 后再减。

### 第 11 题（电子学会四级模拟·指针）指向不同类型变量的指针可以直接用 `==` 判断是否指向同一地址。（ ）

- T. 正确
- F. 错误

### 第 12 题（电子学会四级模拟·指针）指针变量可以用 `if (p)` 判断是否为空指针（空指针为假）。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 空指针（nullptr/NULL）在布尔语境下为假，非空指针为真，故 `if (p)` 可判空。

### 第 13 题（电子学会四级模拟·结构体）结构体变量作函数参数时按值传递，函数内部修改成员不影响原变量。（ ）

- T. 正确
- F. 错误

**答案：T**

- T. 正确
- F. 错误

### 第 15 题（电子学会四级模拟·进制转换）二进制数 `110010` 转换为十进制数是 50。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `110010`₂ = 32 + 16 + 2 = 50。

### 第 16 题（电子学会四级模拟·位运算）`x & 0xFF` 可以提取整数 x 的高 8 位。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** `0xFF` 低 8 位全 1，`x & 0xFF` 保留的是 x 的低 8 位；提取高 8 位应写作 `(x >> 8) & 0xFF`。

### 第 18 题（电子学会四级模拟·排序）选择排序每一趟都会从剩余未排序元素中选出最小值，放到已排序序列的末尾。（ ）

- T. 正确
- F. 错误

### 第 20 题（电子学会四级模拟·高精度）高精度加法中，两数位数不同时，从个位对齐，位数较短者的高位按 0 处理。（ ）
