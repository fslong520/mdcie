### 第 23 题 数字信号 ★★（30 分）

**【题目描述】**

一串数字信号用二进制表示，给定 n 个非负整数，请判断每个数的二进制表示中第 k 位（从右往左，最低位为第 0 位）是否为 1。
【输入格式】第一行两个整数 n、k；第二行 n 个整数。
【输出格式】n 行，每行 YES 或 NO。
【样例输入 1】
```
3 2
5 7 8
```
【样例输出 1】
```
YES
YES
NO
```
【样例输入 2】
```
2 0
1 2
```
【样例输出 2】
```
YES
NO
```
【数据范围】1 ≤ n ≤ 100000，0 ≤ 整数 ≤ 10⁹，0 ≤ k ≤ 30。

**【参考程序】**

```cpp
#include <iostream>
using namespace std;

int main()
{
    int n, k, x;
    cin >> n >> k;
    while (n--)
    {
        cin >> x;
        cout << ((x >> k) & 1 ? "YES" : "NO") << endl;
    }
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 用位运算 x>>k & 1 判断第 k 位是否为 1。

### 第 24 题 二进制编码 ★★（30 分）

**【题目描述】**

给定一个十进制非负整数 n，将其转换为二进制数并输出。
【输入格式】一个整数 n。
【输出格式】一个字符串，表示 n 的二进制表示。
【样例输入 1】
```
10
```
【样例输出 1】
```
1010
```
【样例输入 2】
```
0
```
【样例输出 2】
```
0
```
【数据范围】0 ≤ n ≤ 10⁹。

**【参考程序】**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    int n;
    cin >> n;
    if (n == 0) { cout << 0 << endl; return 0; }
    vector<int> a;
    while (n > 0) { a.push_back(n % 2); n /= 2; }
    for (int i = a.size() - 1; i >= 0; i--) cout << a[i];
    cout << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 除 2 取余倒序：n 不断除以 2，余数依次存入数组，最后倒序输出。n=0 时直接输出 0。
