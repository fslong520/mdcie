# 细胞分裂

一种细胞每轮分裂一次（1 个变 2 个），初始有 1 个。求 n 轮后有多少个细胞，结果可能很大，请用高精度输出。
【输入格式】一个整数 n。
【输出格式】一个整数，表示 2ⁿ 的结果。
【样例输入 1】
```
10
```
【样例输出 1】
```
1024
```
【样例输入 2】
```
100
```
【样例输出 2】
```
1267650600228229401496703205376
```
【数据范围】0 ≤ n ≤ 1000。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1600**。
