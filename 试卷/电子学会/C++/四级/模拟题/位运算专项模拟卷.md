### P9830 两种灯带混色（异或运算） ★（8 分）

**【题目描述】**

两路控制信号分别控制两条灯带，同时作用时效果是「异或」：一盏灯在两路中相同则灭、不同则亮。

给你两个数 n 和 m，输出它们异或的结果。

**【输入格式】**

一行，两个整数 n 和 m，用空格隔开。

**【输出格式】**

一行，一个整数，表示 n ⊕ m 的值。

**【样例输入 #1】**

```
12 10
```

**【样例输出 #1】**

```
6
```

**【样例输入 #2】**

```
5 3
```

**【样例输出 #2】**

```
6
```

**【数据范围】**

0 ≤ n, m ≤ 10⁹。

### P9835 灯牌解码（异或找落单） ★★★（10 分）

**【题目描述】**

晚会布置了 N 个灯牌，每个灯牌上刻有一个编号。正常情况下每个编号应该有两个灯牌（一左一右对称挂），现在有一个编号只出现了一次——它落单了。

利用异或的性质（a^a=0、a^0=a，且交换律成立），把所有编号逐个异或起来，成对的会互相抵消，剩下的就是落单的编号。

给定 N（N 为奇数）和 N 个非负整数，输出只出现一次的那个数。

**【输入格式】**

第一行，一个整数 N。
第二行，N 个非负整数，表示每个灯牌的编号。

**【输出格式】**

一行，一个整数，表示落单的那个编号。

**【样例输入 #1】**

```
7
1 2 3 2 3 1 5
```

**【样例输出 #1】**

```
5
```

**【样例输入 #2】**

```
3
10 20 10
```

**【样例输出 #2】**

```
20
```

**【数据范围】**

1 ≤ N ≤ 10⁵，0 ≤ 每个编号 ≤ 10⁹。

### P9836 数对异或和（总异或和） ★★★（10 分）

**【题目描述】**

给定长度为 n 的序列 A₁、A₂、……、Aₙ。计算所有数对 (i, j) 的 Aᵢ + Aⱼ 的总异或和。即把所有满足 1 ≤ i、j ≤ n 的 Aᵢ + Aⱼ 依次进行异或，输出最终结果。

举例：当 n = 3、序列为 (2, 12, 27) 时，计算式为：
(2+2) ⊕ (2+12) ⊕ (2+27) ⊕ (12+2) ⊕ (12+12) ⊕ (12+27) ⊕ (27+2) ⊕ (27+12) ⊕ (27+27)

请你输出这个总异或和。

**【输入格式】**

第一行，一个整数 n。
第二行，n 个非负整数，表示序列 A。

**【输出格式】**

一行，一个整数，表示所有数对 (i,j) 的 Aᵢ + Aⱼ 的总异或和。

**【样例输入 #1】**

```
3
2 12 27
```

**【样例输出 #1】**

```
42
```

**【数据范围】**

1 ≤ n ≤ 10⁶，0 ≤ Aᵢ ≤ 10⁹。
