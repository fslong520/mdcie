# k进制回文

#### 题目描述

给定进制 k（2 ≤ k ≤ 16）和一个十进制非负整数 n，请判断 n 在 k 进制表示下（无前导零）是否为回文数。回文指正读反读完全一致。是输出 `Yes`，不是输出 `No`。

k 进制数码：0-9 表示 0~9，10~15 依次用大写字母 A-F 表示。

#### 输入格式

一行，两个整数 k 和 n（2 ≤ k ≤ 16，0 ≤ n ≤ 10⁹），用空格分隔。

#### 输出格式

一行，`Yes` 或 `No`。

#### 样例输入 #1

```
2 9
```

#### 样例输出 #1

```
Yes
```

#### 样例说明 #1

9 的二进制是 1001，正读反读一致。

#### 样例输入 #2

```
10 19
```

#### 样例输出 #2

```
No
```

#### 样例输入 #3

```
16 255
```

#### 样例输出 #3

```
Yes
```

#### 样例说明 #3

255 的十六进制是 FF。

#### 数据范围

2 ≤ k ≤ 16，0 ≤ n ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**900**。
