# 奇偶位交换

计算机存储数字时用的是二进制。现在我们要玩一个二进制小魔术：给定一个正整数 n，把它二进制表示中的每一位按"相邻两位交换"处理——第 0 位（最低位）与第 1 位交换，第 2 位与第 3 位交换，第 4 位与第 5 位交换……以此类推。交换完成后得到一个新的二进制数，请输出这个新数对应的十进制值。

【输入格式】一行，一个正整数 n（1 ≤ n ≤ 10⁹）。
【输出格式】一行，奇偶位交换后得到的十进制数。

【样例输入 1】
```
10
```
【样例输出 1】
```
5
```
【样例说明 1】10 的二进制是 1010，第 0/1 位交换得 01，第 2/3 位交换得 10，拼起来是 0101，即十进制 5。

【样例输入 2】
```
15
```
【样例输出 2】
```
15
```
【样例说明 2】15 的二进制是 1111，每对相邻位交换后仍是 1111，所以还是 15。

【数据范围】1 ≤ n ≤ 10⁹。
