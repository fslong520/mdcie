# 大数比大小

#### 题目描述

给定两个非负大整数 A 和 B（可能超过 64 位），请比较它们的大小并输出结果：若 A > B 输出 `>`，若 A < B 输出 `<`，若相等输出 `=`。

#### 输入格式

一行，两个非负大整数 A、B，用空格隔开（长度均 ≤ 200，无前导零；单独的 0 合法）。

#### 输出格式

一行，一个字符：`>`、`<` 或 `=`。

#### 样例输入 #1

```
123456789123456789123456789 99999999999999999999999999
```

#### 样例输出 #1

```
>
```

#### 样例输入 #2

```
100 99
```

#### 样例输出 #2

```
>
```

#### 样例输入 #3

```
1000 1000
```

#### 样例输出 #3

```
=
```

#### 数据范围

A、B 长度 ≤ 200。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**800**。
