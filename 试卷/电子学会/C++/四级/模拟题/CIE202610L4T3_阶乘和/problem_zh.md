# 阶乘和

#### 题目描述

求 S = 1! + 2! + 3! + … + n! 的精确值。其中 n! = 1 × 2 × … × n，规定 1! = 1。

#### 输入格式

一行，一个正整数 n。

#### 输出格式

一行，S 的精确值。

#### 样例输入 #1

```
4
```

#### 样例输出 #1

```
33
```

#### 样例说明 #1

1! + 2! + 3! + 4! = 1 + 2 + 6 + 24 = 33。

#### 样例输入 #2

```
10
```

#### 样例输出 #2

```
4037913
```

#### 数据范围

1 ≤ n ≤ 50（50! 约 65 位，须用高精度）。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1100**。
