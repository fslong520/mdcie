# 高精度阶乘

小星正在筹备一场班级联欢会，他需要把座位按 1 号到 n 号依次编号并统计所有可能的排列方式，答案的数值非常大，普通整数根本装不下。请你帮小星计算出 n 的阶乘 n! 的精确值（即 1×2×3×…×n）。

给定一个正整数 n（1≤n≤500），输出 n! 的精确值。结果可能多达上千位，你无法用 64 位整数直接存储，必须使用高精度乘法：把大数存放在 int 数组中（低位在前，即 a[0] 为个位），让大数逐位乘上一个整数因子，再统一处理进位。

【输入格式】
一行一个正整数 n。

【输出格式】
一行，n! 的精确十进制值。

【样例输入 1】
```
5
```

【样例输出 1】
```
120
```

【样例说明 1】
5! = 1×2×3×4×5 = 120。

【样例输入 2】
```
10
```

【样例输出 2】
```
3628800
```

【样例说明 2】
10! = 1×2×3×…×10 = 3628800。

【数据范围】
对于全部数据，1 ≤ n ≤ 500。
- 结果最大时为 500!，约有 1135 位，int 数组只需开 2000 位即可安全存下。
