# 指针数组反转

给定 n 个整数存放到数组中，请使用**指针**（首尾两个指针，分别指向数组第一个和最后一个元素，交换所指元素后相向移动，直到相遇）将数组原地反转，然后输出。

【输入格式】第一行一个整数 n。第二行 n 个整数。
【输出格式】一行 n 个整数，表示反转后的数组，相邻元素用一个空格分隔。
【样例输入 1】
```
5
1 2 3 4 5
```
【样例输出 1】
```
5 4 3 2 1
```
【样例输入 2】
```
2
3 9
```
【样例输出 2】
```
9 3
```
【数据范围】1 ≤ n ≤ 100000，每个数 ≤ 10⁹。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
