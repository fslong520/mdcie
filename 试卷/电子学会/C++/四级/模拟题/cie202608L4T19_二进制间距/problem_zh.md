# 二进制间距

给定一个正整数 n，把它写成二进制（不含前导零）。两个相邻的 1 之间可能夹着一段连续的 0。请求出被两个 1 夹住的最长连续 0 段的长度；如果二进制中 1 的个数不足两个，输出 0。

【输入格式】一行一个正整数 n。
【输出格式】一行一个整数，表示最长间距；1 的个数不足两个时输出 0。
【样例输入 1】
```
22
```
【样例输出 1】
```
1
```
【样例说明】22 = (10110)₂，位 3 的 1 与位 1 的 1 之间夹着 1 个 0，最长间距为 1。
【样例输入 2】
```
9
```
【样例输出 2】
```
2
```
【样例说明】9 = (1001)₂，两个 1 之间夹着 2 个 0。
【样例输入 3】
```
8
```
【样例输出 3】
```
0
```
【样例说明】8 = (1000)₂，只有一个 1，输出 0。
【数据范围】1 ≤ n ≤ 10⁹。
