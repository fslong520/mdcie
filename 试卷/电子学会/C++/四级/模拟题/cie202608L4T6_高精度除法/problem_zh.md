# 高精度除法

#### 题目描述

给定一个大整数 a（可能超过 64 位）和一个正整数 b，求 a ÷ b 的商和余数。

#### 输入格式

第一行：大整数 a（字符串形式，不含前导0）
第二行：整数 b（1 ≤ b ≤ 10⁹）

#### 输出格式

两行，第一行为商，第二行为余数。

#### 样例输入 #1

```
1000
3
```

#### 样例输出 #1

```
333
1
```

#### 样例输入 #2

```
123456789012345678901234567890
2
```

#### 样例输出 #2

```
61728394506172839450617283945
0
```

#### 数据范围

a 长度 ≤ 1000，1 ≤ b ≤ 10⁹。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1600**。
