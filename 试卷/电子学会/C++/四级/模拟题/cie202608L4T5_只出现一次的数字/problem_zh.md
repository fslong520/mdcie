# 只出现一次的数字

#### 题目描述

给定 n 个整数，其中只有一个整数出现奇数次，其余整数都成对出现（出现偶数次）。请找出这个出现奇数次的整数。要求使用位运算（异或）实现。

#### 输入格式

第一行：整数 n（n 为奇数，1 ≤ n ≤ 100000）
第二行：n 个整数，用空格分隔

#### 输出格式

一个整数，表示出现奇数次的数。

#### 样例输入 #1

```
5
1 2 1 3 2
```

#### 样例输出 #1

```
3
```

#### 样例输入 #2

```
3
7 7 9
```

#### 样例输出 #2

```
9
```

#### 数据范围

1 ≤ n ≤ 100000（奇数），整数绝对值 ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1200**。
