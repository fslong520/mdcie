# 十六进制转二进制

#### 题目描述

给一个十六进制非负整数（数字 0-9 与大写字母 A-F），请把它换算成二进制串输出。

每一位十六进制数码恰好对应 4 位二进制；拼接后去掉整体的前导零。

#### 输入格式

一行，一个十六进制非负整数（1 ≤ 串长 ≤ 8），无前导空格；单独的 0 合法。

#### 输出格式

一行，对应的二进制串，不含前导零（结果 0 除外）。

#### 样例输入 #1

```
2A
```

#### 样例输出 #1

```
101010
```

#### 样例输入 #2

```
1B
```

#### 样例输出 #2

```
11011
```

#### 样例输入 #3

```
0
```

#### 样例输出 #3

```
0
```

#### 数据范围

1 ≤ 串长 ≤ 8（数值 < 16⁸，超出 int 范围，须逐位转换拼接，不能先转十进制再存 int）。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**900**。
