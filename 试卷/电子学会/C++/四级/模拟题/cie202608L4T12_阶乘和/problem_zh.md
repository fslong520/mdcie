# 阶乘和

求 1! + 2! + 3! + … + n! 的值，结果可能很大，请用高精度计算。
【输入格式】一个整数 n。
【输出格式】一个整数，表示阶乘之和。
【样例输入 1】
```
5
```
【样例输出 1】
```
153
```
【样例输入 2】
```
10
```
【样例输出 2】
```
4037913
```
【数据范围】1 ≤ n ≤ 200。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1700**。
