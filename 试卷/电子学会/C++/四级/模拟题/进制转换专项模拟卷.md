# 📘 进制转换专项模拟卷

# 客观题 20 道（单选 10×2 分 + 判断 10×2 分 = 40 分） + 编程题 5 道（12 分/题 = 60 分）

> 本卷里每道题都藏着一个生活小场景。请先读懂场景，再动手分析——你会发现，它们背后用的其实是同一套「数数」的本领。

### 第 1 题（快递柜指示灯）小区门口的快递柜，每个格子有一排指示灯，灯只有「亮(1)」和「灭(0)」两态，从左往右表示数字的高位到低位。小雨的快递在编号为 23 的格子。表示 23 时，这排灯从左往右的 1/0 序列是？（）

- A. 10111
- B. 11011
- C. 11101
- D. 100111

---

### 第 2 题（四关闯关积分）一款闯关游戏，每关只有「通关(1)」和「未通关(0)」两种记录。小博的四关记录是「通、不通、通、通」，也就是 1101。系统结算时：第 1 关值 8 分、第 2 关值 4 分、第 3 关值 2 分、第 4 关值 1 分，通关才加分。小博最后得几分？（）

- A. 11
- B. 13
- C. 12
- D. 14

---

### 第 3 题（八音盒旋钮）八音盒用三个旋钮记录一段旋律编号，每个旋钮有 8 档（0~7）。要把第 64 号旋律存进去，三个旋钮（从高位到低位）应当拨到？（）

- A. 1、0、0
- B. 1、0、1
- C. 0、8、0
- D. 1、4、4

### 第 4 题（颜色浓度缩写）调色时颜色浓度用一个 0~255 的数表示，但程序里习惯用「两位十六进制」缩写（每位 0~15，用 0-9 和 A-F）。浓度 255 写成哪两个缩写字符？（）

# 编程题（每题 12 分，共 60 分）

### P9811 闯关灯带（十进制转二进制） ★（12 分）

**【题目描述】**

一款闯关游戏，每关只有「通过(1)」和「未通过(0)」两种状态。系统把玩家的总进度用一个「开/关灯带」显示：从最高位到最低位依次亮或灭，拼成一串。

给你一个十进制的总进度数 n，请输出这串灯带（用 1 和 0 表示，不要多余的前导 0；n = 0 时输出 `0`）。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，n 的灯带字符串。

**【样例输入】**

```
13
```

**【样例输出】**

```
1101
```

**【数据范围】**

0 ≤ n ≤ 10⁹。

---

### P9812 通用缩写（十进制转任意进制） ★★（12 分）

**【题目描述】**

调色盘里颜色常用「两位十六进制」表示，但有些老系统用八进制，有些用二进制。

写一个程序：输入一个总数 n 和目标进制 base（2 ≤ base ≤ 16），把它写成 base 进制（用 0~9 与 A~F 表示，不要前导 0，n = 0 时输出 `0`）。

**【输入格式】**

一行，两个整数 n 和 base，用空格隔开。

**【输出格式】**

一行，n 的 base 进制字符串。

**【样例输入】**

```
255 16
```

**【样例输出】**

```
FF
```

**【数据范围】**

0 ≤ n ≤ 10⁹，2 ≤ base ≤ 16。

---

### P9813 存档还原（任意进制转十进制） ★★（12 分）

**【题目描述】**

游戏存档里，时间用一个 base 进制的字符串保存（base 已知，2 ≤ base ≤ 16）。比如存档写的是「FF」、base = 16，就要还原成秒数 255。

给你 base 和一个 base 进制下的数字串（只含 `0~9` 与大写 `A~F`），输出它代表的十进制数。

**【输入格式】**

第一行，一个整数 base。
第二行，一个字符串 s，表示 base 进制下的数字。

**【输出格式】**

一行，转换后的十进制整数。

**【样例输入】**

```
16
FF
```

**【样例输出】**

```
255
```

**【数据范围】**

2 ≤ base ≤ 16，字符串长度不超过 10。

---

### P9814 连续灭灯（二进制末尾 0 的个数） ★★（12 分）

**【题目描述】**

二进制灯带里，从最右边（最低位）往左数，连续灭(0)的灯有几盏，就发几颗糖奖励。

给你一个数 n，输出它灯带末尾连续灭灯的数量（n = 0 时输出 0）。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，一个整数，表示 n 的灯带末尾连续 0 的个数。

**【样例输入】**

```
12
```

**【样例输出】**

```
2
```

**【样例输入 2】**

```
10
```

**【样例输出 2】**

```
1
```

**【数据范围】**

0 ≤ n ≤ 10⁹。

---

### P9815 对称号码（进制回文数） ★★★（12 分）

**【题目描述】**

游戏里，若把一个总数转成 base 进制后，正读反读一样（回文），就是「对称号码」，有特殊奖励。

给你 n 和 base（2 ≤ base ≤ 16），判断其 base 进制是否回文，是输出 `Yes`，否则输出 `No`（n = 0 时视作回文）。

**【输入格式】**

一行，两个整数 n 和 base，用空格隔开。

**【输出格式】**

一行，`Yes` 或 `No`。

**【样例输入 1】**

```
5 2
```

**【样例输出 1】**

```
Yes
```

**【样例输入 2】**

```
10 2
```

**【样例输出 2】**

```
No
```

**【数据范围】**

0 ≤ n ≤ 10⁹，2 ≤ base ≤ 16。
