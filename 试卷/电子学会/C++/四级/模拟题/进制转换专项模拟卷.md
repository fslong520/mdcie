# 客观题 20 道（单选 10×2 分 + 判断 10×2 分 = 40 分） + 编程题 5 道（12 分/题 = 60 分）

> 本卷里每道题都藏着一个生活小场景。请先读懂场景，再动手分析——你会发现，它们背后用的其实是同一套「数数」的本领。

### 第 1 题（快递柜指示灯）小区门口的快递柜，每个格子有一排指示灯，灯只有「亮(1)」和「灭(0)」两态，从左往右表示数字的高位到低位。小雨的快递在编号为 23 的格子。表示 23 时，这排灯从左往右的 1/0 序列是？（）

- A. 10111
- B. 11011
- C. 11101
- D. 100111

**答案：A**

**解析：** 灯只有两态，本质是用「只有 0 和 1 两种数字」的方式记录一个数。把 23 拆成 2 的幂：23 = 16+4+2+1 = 2⁴+2²+2¹+2⁰，对应位 1 0 1 1 1，即 10111。也可反复除以 2 取余数：23→11余1、11→5余1、5→2余1、2→1余0、1→0余1，把余数倒着读得 10111。

---

### 第 2 题（四关闯关积分）一款闯关游戏，每关只有「通关(1)」和「未通关(0)」两种记录。小博的四关记录是「通、不通、通、通」，也就是 1101。系统结算时：第 1 关值 8 分、第 2 关值 4 分、第 3 关值 2 分、第 4 关值 1 分，通关才加分。小博最后得几分？（）

- A. 11
- B. 13
- C. 12
- D. 14

**答案：B**

**解析：** 记录 1101 中第 1、2、4 关通关：8 + 4 + 1 = 13。这其实是用「每一位乘上对应的 2 的幂再相加」把一串 0/1 还原成了普通数字：1101 = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 13。

---

### 第 3 题（八音盒旋钮）八音盒用三个旋钮记录一段旋律编号，每个旋钮有 8 档（0~7）。要把第 64 号旋律存进去，三个旋钮（从高位到低位）应当拨到？（）

- A. 1、0、0
- B. 1、0、1
- C. 0、8、0
- D. 1、4、4

**答案：A**

**解析：** 每旋钮 8 档，三个旋钮合起来就是一种「每位只能是 0~7」的记法。64 = 1×8² + 0×8¹ + 0×8⁰，所以旋钮是 1、0、0，即「八进制」的 100。

---

### 第 4 题（颜色浓度缩写）调色时颜色浓度用一个 0~255 的数表示，但程序里习惯用「两位十六进制」缩写（每位 0~15，用 0-9 和 A-F）。浓度 255 写成哪两个缩写字符？（）

- A. FF
- B. FE
- C. EF
- D. 1FF

**答案：A**

**解析：** 255 = 15×16 + 15，而十六进制里 15 记作 F，所以写成 FF。这正是把一串十进制数改写成「每位 0~15」的记法。

---

### 第 5 题（游戏装备攻击力）一款游戏里，装备攻击力在代码里写成 `0x1A`。程序规定 `0x` 开头表示「十六进制写法」，字母 A 代表 10。这件装备实际攻击力是多少？（）

- A. 26
- B. 16
- C. 1A
- D. 21

**答案：A**

**解析：** `0x1A` 是十六进制，1A = 1×16 + 10 = 26，所以攻击力其实是 26。

---

### 第 6 题（调色代码展开）调色代码写成两位十六进制 `2F`（每位 0~15，用 0-9 和 A-F）。系统把它展开成一串开/关灯（二进制）：每位十六进制变成 4 盏灯，再去掉最左边多余的灭灯。这串灯是？（）

- A. 101111
- B. 101110
- C. 100111
- D. 111011

**答案：A**

**解析：** 2 在二进制是 0010，F（即 15）是 1111，拼起来是 00101111，去掉最左边多余的灭灯(0)就是 101111。这就是把十六进制一步步展开成 0/1 记录的办法。

---

### 第 7 题（灯带分组）一条 6 盏灯的灯带状态是 110101。系统从右往左每 3 盏分成一组，用「八档旋钮」（0~7）表示，两组旋钮（从高位到低位）应当拨到？（）

- A. 6、5
- B. 5、6
- C. 6、6
- D. 4、5

**答案：A**

**解析：** 从右往左每 3 位分组：110 | 101。左边 110 = 6，右边 101 = 5，所以是 6、5（也就是八进制的 65）。这正是在二进制和八进制之间转换的常用分组法。

---

### 第 8 题（游戏装备攻击力）一款游戏里，装备攻击力在代码里写成 `0xB3`。程序规定 `0x` 开头表示十六进制，字母 B 代表 11。这件装备实际攻击力是多少？（）

- A. 179
- B. 173
- C. 11
- D. 183

**答案：A**

**解析：** `0xB3` 是十六进制，B3 = 11×16 + 3 = 176 + 3 = 179，所以攻击力是 179。

---

### 第 9 题（门禁卡密码）小区门禁卡密码是「两位十六进制」（每位 0~F，范围 00 到 FF）。这能设出多少把不同的密码？（）

- A. 16
- B. 32
- C. 256
- D. 128

**答案：C**

**解析：** 每位十六进制有 16 种取值，两位合起来是 16×16 = 256 种（从 00 到 FF，对应 0~255）。

---

### 第 10 题（八颗灯全亮）一条 8 颗灯的灯带，全部点亮时状态是 11111111（亮亮亮亮亮亮亮亮）。用「两位十六进制」简写，它是？（）

- A. FF
- B. FE
- C. 11
- D. 88

**答案：A**

**解析：** 每 4 位「只有 0 和 1」的灯对应 1 位十六进制，1111 = F，所以 1111 1111 = FF（也就是十进制的 255）。

---

### 第 11 题（开/关记录还原）小雨说：「一串开/关记录，把每一位亮灯代表 2 的若干次方，把所有亮灯对应的数加起来，就得到它代表的总数。」这种说法正确吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 这正是把一串 0/1 还原成普通数字的办法——把每一位的「值」乘上对应的 2 的幂再全部相加。

---

### 第 12 题（倒着读余数）冯阿姨教大家：「把总数不断除以 2，每次记下余数，最后把余数倒着读出来，就得到开/关记录。」这种说法正确吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 这正是「反复除以 2 取余数，再把余数倒着排」得到那串 0/1 记录的标准方法。

---

### 第 13 题（浓度缩写对照）调色浓度写成 `FF`，有人说「这就是 255」。对吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** `FF` 是十六进制，FF = 15×16 + 15 = 255。

---

### 第 14 题（八档旋钮）用「八档旋钮」记录数字时，每个旋钮只能拨到 0~7，拨到 8 或 9 就错了。对吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 八档即每一位只有 8 种选择，合法数字只有 0、1、2、3、4、5、6、7，不能出现 8 和 9。

---

### 第 15 题（灯带变旋钮）把一串开/关灯（二进制）转成八档旋钮（八进制），办法是「从右往左每 3 盏分成一组，每组变成一位八进制数字」。这种说法对吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 因为 2³ = 8，所以每 3 位二进制恰好对应 1 位八进制，从右往左三位一组转换即可。

---

### 第 16 题（小数能存准吗）小雨说：「电脑用开/关记录小数，任意一个十进制小数都能被精确存下，比如 0.1 分毫不差。」对吗？（）

- T. 正确
- F. 错误

**答案：F**

**解析：** 并非所有十进制小数都能精确表示。例如 0.1 在「只有 0 和 1」的记法下是无限循环的，只能近似存储，会有微小误差。

---

### 第 17 题（旋钮的档数）十六进制每一位可以是 0 到 15 之间的数（用 0~9 和 A~F 表示）。对吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 十六进制每位有 16 种取值，即 0~15，其中 10~15 用字母 A~F 表示。

---

### 第 18 题（旋钮与灯带）一位「十六档旋钮」（0~F）的信息量，正好等于四位「开/关灯」（因为 16 = 2⁴）。比如旋钮拨到 F，就是四盏灯全亮(1111)。对吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 2⁴ = 16，所以每 1 位十六进制恰可用 4 位「只有 0 和 1」的灯完整表示。

---

### 第 19 题（前缀的含义）在 C++ 里，写 `012` 表示八进制，写 `0x12` 也表示八进制。对吗？（）

- T. 正确
- F. 错误

**答案：F**

**解析：** `0x` 开头表示的是「每位 0~15」的记法（如 `0xFF`）；只有前导 `0`（数字零，如 `012`）才表示八进制。

---

### 第 20 题（总数 10 的记录）总数 10，用开/关灯记录，是 1010（亮灭亮灭）。对吗？（）

- T. 正确
- F. 错误

**答案：T**

**解析：** 1010 = 8 + 2 = 10，所以十进制 10 用那串 0/1 记下来就是 1010。

### P9811 闯关灯带（十进制转二进制） ★（12 分）

**【题目描述】**

一款闯关游戏，每关只有「通过(1)」和「未通过(0)」两种状态。系统把玩家的总进度用一个「开/关灯带」显示：从最高位到最低位依次亮或灭，拼成一串。

给你一个十进制的总进度数 n，请输出这串灯带（用 1 和 0 表示，不要多余的前导 0；n = 0 时输出 `0`）。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，n 的灯带字符串。

**【样例输入】**

```
13
```

**【样例输出】**

```
1101
```

**【数据范围】**

0 ≤ n ≤ 10⁹。

### P9812 通用缩写（十进制转任意进制） ★★（12 分）

**【题目描述】**

调色盘里颜色常用「两位十六进制」表示，但有些老系统用八进制，有些用二进制。

写一个程序：输入一个总数 n 和目标进制 base（2 ≤ base ≤ 16），把它写成 base 进制（用 0~9 与 A~F 表示，不要前导 0，n = 0 时输出 `0`）。

**【输入格式】**

一行，两个整数 n 和 base，用空格隔开。

**【输出格式】**

一行，n 的 base 进制字符串。

**【样例输入】**

```
255 16
```

**【样例输出】**

```
FF
```

**【数据范围】**

0 ≤ n ≤ 10⁹，2 ≤ base ≤ 16。

### P9813 存档还原（任意进制转十进制） ★★（12 分）

**【题目描述】**

游戏存档里，时间用一个 base 进制的字符串保存（base 已知，2 ≤ base ≤ 16）。比如存档写的是「FF」、base = 16，就要还原成秒数 255。

给你 base 和一个 base 进制下的数字串（只含 `0~9` 与大写 `A~F`），输出它代表的十进制数。

**【输入格式】**

第一行，一个整数 base。
第二行，一个字符串 s，表示 base 进制下的数字。

**【输出格式】**

一行，转换后的十进制整数。

**【样例输入】**

```
16
FF
```

**【样例输出】**

```
255
```

**【数据范围】**

2 ≤ base ≤ 16，字符串长度不超过 10。

### P9814 连续灭灯（二进制末尾 0 的个数） ★★（12 分）

**【题目描述】**

二进制灯带里，从最右边（最低位）往左数，连续灭(0)的灯有几盏，就发几颗糖奖励。

给你一个数 n，输出它灯带末尾连续灭灯的数量（n = 0 时输出 0）。

**【输入格式】**

一行，一个整数 n。

**【输出格式】**

一行，一个整数，表示 n 的灯带末尾连续 0 的个数。

**【样例输入】**

```
12
```

**【样例输出】**

```
2
```

**【样例输入 2】**

```
10
```

**【样例输出 2】**

```
1
```

**【数据范围】**

0 ≤ n ≤ 10⁹。

### P9815 对称号码（进制回文数） ★★★（12 分）

**【题目描述】**

游戏里，若把一个总数转成 base 进制后，正读反读一样（回文），就是「对称号码」，有特殊奖励。

给你 n 和 base（2 ≤ base ≤ 16），判断其 base 进制是否回文，是输出 `Yes`，否则输出 `No`（n = 0 时视作回文）。

一行，`Yes` 或 `No`。

```
5 2
```

**【样例输出 1】**

```
Yes
```

**【样例输入 2】**

```
10 2
```

**【样例输出 2】**

```
No
```

**【数据范围】**

0 ≤ n ≤ 10⁹，2 ≤ base ≤ 16。
