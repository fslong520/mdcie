### 第 1 题（电子学会四级模拟·指针）以下关于 C++ 指针的说法，正确的是？（ ）

- A. 指针变量存储的是变量的值
- B. 指针变量存储的是变量的地址
- C. 指针变量只能指向同类型变量
- D. 指针变量可以不初始化直接使用

**答案：B**

**解析：** 指针变量存储的是其他变量的内存地址；指针可以指向不同类型的变量（需强制转换）；未初始化的指针是野指针，不可直接使用。

### 第 2 题（电子学会四级模拟·指针）执行以下代码，输出结果是？（ ）

```cpp
int x = 10, y = 20;
int *p = &x;
int *q = &y;
p = q;
*p = 30;
cout << x << " " << y;
```

- A. 10 20
- B. 10 30
- C. 30 20
- D. 30 30

**答案：B**

**解析：** `p` 原指向 `x`，执行 `p = q` 后 `p` 改指向 `y`，`*p = 30` 通过指针将 `y` 改为 30；`x` 未被修改，仍为 10。故输出 `10 30`。

### 第 3 题（电子学会四级模拟·结构体）执行以下代码，输出结果是？（ ）

```cpp
struct Node {
    int v;
};
Node a[3] = {{1}, {2}, {3}};
Node *p = &a[1];
cout << p->v;
```

- A. 1
- B. 2
- C. 3
- D. 随机值

**答案：B**

**解析：** `p` 指向结构体数组 `a` 的第 2 个元素 `a[1]`，`p->v` 等价于 `(*p).v`，值为 2。

### 第 4 题（电子学会四级模拟·类）有类定义如下，创建对象并调用成员函数的写法正确的是？（ ）

```cpp
class Dog {
public:
    void bark() { cout << "Woof"; }
};
```

- A. `Dog d; d.bark();`
- B. `Dog d; Dog.bark();`
- C. `new Dog bark();`
- D. `bark Dog d;`

**答案：A**

**解析：** 先创建对象 `Dog d;`，再用 `.` 调用成员函数 `d.bark()`；`Dog` 是类型名不能直接调用，`new` 返回指针应用 `->` 调用。

### 第 5 题（电子学会四级模拟·进制转换）将十进制数 63 转换为十六进制数，结果是？（ ）

- A. 3F
- B. 4F
- C. 2F
- D. 5F

**答案：A**

**解析：** 63 = 3×16 + 15，商 3 余 15（即 F），故为 `3F`₁₆。

### 第 6 题（电子学会四级模拟·位运算）C++ 表达式 `18 >> 2` 的计算结果是？（ ）

- A. 2
- B. 4
- C. 9
- D. 18

**答案：B**

**解析：** 18 的二进制为 10010，右移 2 位得 100，即十进制 4。

### 第 7 题（电子学会四级模拟·排序）以下排序算法中，空间复杂度为 O(1) 的是？（ ）

- A. 快速排序
- B. 归并排序
- C. 冒泡排序
- D. 桶排序

**答案：C**

**解析：** 冒泡排序是原地排序，空间复杂度 O(1)；快速排序递归栈 O(log n)；归并排序需辅助数组 O(n)；桶排序需额外桶空间。

### 第 8 题（电子学会四级模拟·排序）对数组执行升序冒泡排序，完成第一趟后，以下说法正确的是？（ ）

- A. 最大值一定到达数组末尾
- B. 最小值一定到达数组首位
- C. 所有元素都已就位
- D. 数组一定完全有序

**答案：A**

**解析：** 升序冒泡排序每趟将当前未排序部分的最大值"冒泡"到末尾，故第一趟结束后最大值一定到位；其余元素不一定就位。

### 第 9 题（电子学会四级模拟·高精度）在高精度减法运算中，若被减数小于减数，通常需要？（ ）

- A. 直接输出负号
- B. 交换两数相减后输出负号
- C. 使用高精度加法
- D. 报错退出

**答案：B**

**解析：** 高精度减法通常先比较大小，若被减数小于减数，则交换两数相减，最后输出负号。

### 第 10 题（电子学会四级模拟·高精度）高精度加法中，若当前位两个数字分别为 7 和 8，且进位为 1，则本位的值和新的进位分别是？（ ）

- A. 本位 6，进位 1
- B. 本位 5，进位 2
- C. 本位 6，进位 2
- D. 本位 7，进位 1

**答案：A**

**解析：** 7 + 8 + 1 = 16，本位取 16 % 10 = 6，进位取 16 / 10 = 1。

### 第 16 题（电子学会四级模拟·位运算）C++ 中，左移运算符 `<<` 将数左移一位，等价于将原数乘以 2（在不溢出的前提下）。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 左移一位相当于各二进制位整体向高位移动一位，数值变为原来的 2 倍（无溢出时）。

### 第 17 题（电子学会四级模拟·排序）归并排序在合并两个有序序列时，需要额外的数组空间。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 归并排序合并过程需要与待排区间等长的辅助数组暂存数据，故空间复杂度为 O(n)。

- T. 正确
- F. 错误

- T. 正确
- F. 错误

### 第 20 题（电子学会四级模拟·高精度）高精度加法中，两个 n 位大整数相加，结果一定有 n+1 位。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 只有进位时才增加位数，如 500 + 500 = 1000（3位+3位=4位），但 123 + 456 = 579（3位+3位=3位）。
