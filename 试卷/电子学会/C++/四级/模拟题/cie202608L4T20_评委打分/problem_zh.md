# 评委打分

歌唱比赛中有 n 位评委给选手打分（均为 0 到 100 的整数）。计分规则：去掉一个最高分和一个最低分后，取剩余分数的平均值（保留 2 位小数）。请计算该选手的最终得分。

【输入格式】第一行一个整数 n（n ≥ 3）。第二行 n 个整数，表示各评委的打分。
【输出格式】一行，一个保留 2 位小数的小数，表示最终得分。
【样例输入 1】
```
5
90 80 85 70 95
```
【样例输出 1】
```
85.00
```
【样例说明】去掉最高分 95 和最低分 70，剩余 90、80、85，平均分 85.00。
【样例输入 2】
```
3
100 100 100
```
【样例输出 2】
```
100.00
```
【数据范围】3 ≤ n ≤ 1000，0 ≤ 每个分数 ≤ 100。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1400**。
