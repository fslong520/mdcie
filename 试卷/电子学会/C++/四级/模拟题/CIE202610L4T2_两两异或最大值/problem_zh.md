# 两两异或最大值

#### 题目描述

给出 n 个非负整数，从中任选两个不同的数 a、b（下标不同即可，数值可以相同），计算 a ⊕ b（按位异或）。请输出所有选择中异或值的最大值。

异或 ⊕ 的规则：两个二进制位相同得 0，不同得 1。例如 5 ⊕ 3 = 101₂ ⊕ 011₂ = 110₂ = 6。

#### 输入格式

第一行一个整数 n（2 ≤ n ≤ 1000）；

第二行 n 个非负整数 aᵢ（0 ≤ aᵢ ≤ 10⁹），用空格分隔。

#### 输出格式

一行，一个整数，最大的异或值。

#### 样例输入 #1

```
3
5 3 6
```

#### 样例输出 #1

```
6
```

#### 样例说明 #1

5⊕3=6，5⊕6=3，3⊕6=5，最大为 6。

#### 样例输入 #2

```
4
7 7 7 7
```

#### 样例输出 #2

```
0
```

#### 数据范围

2 ≤ n ≤ 1000，0 ≤ aᵢ ≤ 10⁹。
