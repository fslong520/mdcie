### 第 1 题（电子学会四级模拟·指针）

设有整数数组 a[5]，它的初值依次为 10、20、30、40、50。指针 p 指向下标为 1 的数组元素，指针 q 指向下标为 4 的数组元素。在同数组范围里，指针做差可得到它们之间的元素个数；此外再取出 a 下标为 2 的元素。两段信息合起来，输出内容是？（ ）

```cpp
int a[5] = {10, 20, 30, 40, 50};
int *p = a + 1, *q = a + 4;
cout << (q - p) << " " << *(a + 2);
```

- A. 3 30
- B. 4 30
- C. 3 50
- D. 5 40

### 第 2 题（电子学会四级模拟·指针）

用一个指针作为游标，从数组首元素开始不断自加，依次读取每个元素并累加求和。给定的整数序列为 1 到 5，求最后得到的累加和为？（ ）

```cpp
int a[] = {1, 2, 3, 4, 5};
int s = 0;
for (int *p = a; p < a + 5; p++) s += *p;
cout << s;
```

- A. 10
- B. 15
- C. 20
- D. 14

### 第 3 题（电子学会四级模拟·结构体）

结构体允许层层嵌套，内层结构体 A 含整数成员 x、y，外层结构体 B 把结构体 A 的变量作为成员 a，另外还有整数成员 z。取 B 类型变量 b 的地址赋给指针 p 之后，通过指针读取 a 的 y 成员与 z 成员并求和，结果是？（ ）

```cpp
struct A { int x; int y; };
struct B { A a; int z; };
B b = {{1, 2}, 3};
B *p = &b;
cout << p->a.y + p->z;
```

- A. 3
- B. 4
- C. 5
- D. 6

### 第 4 题（电子学会四级模拟·类）

类的静态成员归整个类所有，用某个计数器观察对象被构造的次数颇具趣味。类 C 内置两个构造函数，每一种函数体都会把静态计数器加一。先后构造两个普通对象再加上一个长度为 2 的对象数组，计数器最终显示的数值是？（ ）

```cpp
class C {
public:
    static int cnt;
    C() { cnt++; }
    C(int) { cnt++; }
};
int C::cnt = 0;
int main() {
    C a; C b(1); C c[2];
    cout << C::cnt;
}
```

- A. 4
- B. 3
- C. 5
- D. 2
