# 解码

情报员收到一条用 k 进制数字表示的密文（用数字 0-9 和字母 A-F 表示），请将其转换为十进制数。
【输入格式】第一行一个整数 k（2≤k≤16）；第二行一个字符串 s，表示 k 进制数。
【输出格式】一个整数，表示十进制结果。
【样例输入 1】
```
16
FF
```
【样例输出 1】
```
255
```
【样例输入 2】
```
2
1010
```
【样例输出 2】
```
10
```
【数据范围】2≤k≤16，s 长度 ≤ 30，结果 ≤ 10¹⁸。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
