# 任意进制转换

考古队在古墓中发现了一块石板，上面刻着两个数字——一个十进制计数与一个底数标记。要破译石板记录的真实数值，只需把十进制整数按指定进制重新书写。给定十进制非负整数 n 和进制 k，请输出 n 在 k 进制下的表示。

【输入格式】一行，两个整数 n、k。n 为十进制非负整数，k 为进制（2 ≤ k ≤ 16）。
【输出格式】一行，n 的 k 进制表示。10、11、…、15 分别用大写字母 A、B、…、F 表示。当 n = 0 时输出 0。
【样例输入 1】
```
2009 16
```
【样例输出 1】
```
7D9
```
【样例说明】2009 ÷ 16 = 125 余 9，125 ÷ 16 = 7 余 13(→D)，7 ÷ 16 = 0 余 7，自下而上拼接得 7D9。
【样例输入 2】
```
0 5
```
【样例输出 2】
```
0
```
【样例说明】n = 0 时无论进制为几，表示都是 0，直接输出 0。
【数据范围】0 ≤ n ≤ 10⁹，2 ≤ k ≤ 16。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1200**。
