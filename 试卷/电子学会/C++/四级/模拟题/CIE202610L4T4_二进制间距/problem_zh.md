# 二进制间距

#### 题目描述

一个正整数的二进制表示中，相邻两个 1 之间夹着的连续 0 的个数称为一个"间距"。例如 22 的二进制是 10110，中间两个 1 之间夹着 1 个 0，间距为 1；541 的二进制是 1000011101，最长的连续 0 段（夹在两个 1 之间）为 4，最大间距为 4。若二进制中 1 的个数不足 2 个（如 8 的二进制 1000），最大间距为 0。给定正整数 n，求其二进制的最大间距。

#### 输入格式

一行，一个正整数 n。

#### 输出格式

一行，一个整数，最大间距。

#### 样例输入 #1

```
22
```

#### 样例输出 #1

```
1
```

#### 样例输入 #2

```
541
```

#### 样例输出 #2

```
4
```

#### 样例输入 #3

```
8
```

#### 样例输出 #3

```
0
```

#### 数据范围

1 ≤ n ≤ 10⁹。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1000**。
