# 二进制回文数

#### 题目描述

一个正整数若其二进制表示（无前导零）正读反读完全一致，则称为"二进制回文数"。例如 9 的二进制是 1001，是回文数；6 的二进制是 110，不是。请统计区间 [1, n] 中二进制回文数的个数。

#### 输入格式

一行，一个正整数 n。

#### 输出格式

一行，一个整数，[1, n] 内二进制回文数的个数。

#### 样例输入 #1

```
10
```

#### 样例输出 #1

```
5
```

#### 样例说明 #1

1(1)、3(11)、5(101)、7(111)、9(1001) 共 5 个；10 的二进制 1010 反读为 0101，不同，不算。

#### 样例输入 #2

```
100
```

#### 样例输出 #2

```
19
```

#### 数据范围

1 ≤ n ≤ 100000。
