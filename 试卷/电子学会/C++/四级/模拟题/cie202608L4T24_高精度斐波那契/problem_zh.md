# 高精度斐波那契

小安的储物柜里有一串按规律生长的魔法藤蔓，每一段的长度都等于前两段长度之和，第 1 段长 1，第 2 段长 1。藤蔓长得越来越快，到第 1000 段时已经有两百多位长，普通整数装不下。请你帮小安计算第 n 段的长度。

斐波那契数列定义为 F(1)=1，F(2)=1，F(n)=F(n-1)+F(n-2)（n≥3）。给定正整数 n（1≤n≤1000），输出 F(n) 的精确值。F(1000) 约 209 位，需要使用高精度加法：把大数存放在 int 数组中（低位在前，即 a[0] 为个位），逐位相加并处理进位，再按递推关系逐步累加。

【输入格式】
一行一个正整数 n。

【输出格式】
一行，F(n) 的精确十进制值。

【样例输入 1】
```
6
```

【样例输出 1】
```
8
```

【样例说明 1】
F(1)=1, F(2)=1, F(3)=2, F(4)=3, F(5)=5, F(6)=8。

【样例输入 2】
```
10
```

【样例输出 2】
```
55
```

【样例说明 2】
第 10 项 F(10)=55。

【数据范围】
对于全部数据，1 ≤ n ≤ 1000。
- F(1000) 约有 209 位，高精度数组只需开 250 位即可安全存下。
