# 📘 高精度加减乘专项训练

> C++ 内置整数类型（int / long long）有范围限制——约 21 亿 / 9e18。但天文数字、超大账单、微观粒子计数……这些数远超内置类型上限。于是有了"高精度算法"：用数组存每一位，模拟竖式逐位运算。
>
> 本卷前三编程题聚焦三大基本操作（高精加、高精减、高精乘），后两题展示"低精度输入→高精度输出"的典型场景——用循环重复运算，让小数字长成大数字，正是高精度算法的用武之地。

**知识点覆盖：**
| 编号 | 考点 | 说明 |
|:----:|------|------|
| ① | 逆序存储原理 | 为何数组倒着放？对齐进位/借位的便利 |
| ② | 字符串→数组 | 字符转数字、正序逆序映射 |
| ③ | 加法进位链 | 逐位相加、模10存位、除10进位、连续进位 |
| ④ | 减法借位链 | 逐位相减、借位标记、连续借位、去前导零 |
| ⑤ | 大小比较 | 先比位数、再比高位——减法前置判断 |
| ⑥ | 乘法双重循环 | a[i]×b[j]→c[i+j] 的位偏移、进位统一处理 |
| ⑦ | 前导零处理 | 去头零、保至少一位（结果为0时输出"0"） |
| ⑧ | 结果位数估计 | 加/减/乘的结果位数范围 |
| ⑨ | 递推高精加 | 斐波那契和——n 小结果大，加法累加出大数 |
| ⑩ | 嵌套高精乘 | (N!)!——外阶乘的乘数本身也是大数，两次累乘 |

### 第 8 题（账单对账·去前导零）算完加法后，结果数组存着 `[3,2,1,0,0]`（个位→高位），但实际数字是 123。去除多余前导零的正确代码是（已知 len 为当前位数-1，下标从 0 开始）？（ ）

### P9854 斐波那契和（高精加）★

**【题目描述】**

斐波那契数列：F(1)=1, F(2)=1，n≥3 时 F(n)=F(n−1)+F(n−2)。

给定 N（普通整数），计算前 N 项之和：S = F(1)+F(2)+⋯+F(N)。

N 虽小，斐波那契数增长极快——F(5000) 已有 1045 位。每个 F(i) 及累积和都远超内置类型，每一步加法都须高精度实现。

**【输入格式】**

一行，一个整数 N（1 ≤ N ≤ 5000）。

**【输出格式】**

一行，前 N 项斐波那契数之和 S。

**【样例输入】**

```
10
```

**【样例输出】**

```
143
```

**【数据范围】**

1 ≤ N ≤ 5000。

### P9855 阶乘的阶乘（高精乘）★★

**【题目描述】**

给定 N，计算 (N!)!——先算 N 的阶乘，再对结果取阶乘。

N 是普通整数（≤ 6），但数值暴涨极快：
| N | N! | (N!)!（位数） |
|---|----|--------------|
| 3 | 6  | 720（3 位） |
| 4 | 24 | 24!（24 位） |
| 5 | 120 | 120!（199 位） |
| 6 | 720 | 720!（**1747 位**） |

两步皆须高精度乘小整数实现。

**【输入格式】**

一行，一个整数 N（1 ≤ N ≤ 6）。

**【输出格式】**

一行，(N!)!。

**【样例输入】**

```
3
```

**【样例输出】**

```
720
```

**【数据范围】**

1 ≤ N ≤ 6。
