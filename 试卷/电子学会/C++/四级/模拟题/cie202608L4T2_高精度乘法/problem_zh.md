# 高精度乘法

#### 题目描述

实现高精度乘法：输入两个正整数（可能超过 64 位），输出它们的乘积。

#### 输入格式

第一行：第一个正整数（字符串形式，不含前导0）
第二行：第二个正整数（字符串形式，不含前导0）

#### 输出格式

一个整数，表示两数之积。

#### 样例输入 #1

```
12
12
```

#### 样例输出 #1

```
144
```

#### 样例输入 #2

```
999999999999999999999999999999
2
```

#### 样例输出 #2

```
1999999999999999999999999999998
```

#### 数据范围

两个正整数长度 ≤ 500。

#### 知识点与难度

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1600**。
