# 十六进制转十进制

给定一个十六进制字符串（由数字 0-9 和大写字母 A-F 组成，A=10、B=11、…、F=15），请将其转换为十进制数并输出。

【输入格式】一个十六进制字符串。
【输出格式】一个十进制整数。
【样例输入 1】
```
A
```
【样例输出 1】
```
10
```
【样例输入 2】
```
FF
```
【样例输出 2】
```
255
```
【数据范围】字符串长度 1-8，结果不超过 2³²-1。

本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
