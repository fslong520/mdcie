# 平方和拆分计数

#### 题目描述

给定自然数 n，统计有多少对非负整数 (a, b) 满足 a² + b² = n 且 a ≤ b。

#### 输入格式

一行，一个自然数 n（0 ≤ n ≤ 50000）。

#### 输出格式

一行，一个整数，满足条件的 (a, b) 对数。

#### 样例输入 #1

```
25
```

#### 样例输出 #1

```
2
```

#### 样例说明 #1

25 = 0² + 5² = 3² + 4²，共 2 对。

#### 样例输入 #2

```
0
```

#### 样例输出 #2

```
1
```

#### 样例说明 #2

0 = 0² + 0²。

#### 样例输入 #3

```
3
```

#### 样例输出 #3

```
0
```

#### 数据范围

0 ≤ n ≤ 50000。
