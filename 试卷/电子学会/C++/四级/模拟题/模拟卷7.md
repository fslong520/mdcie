### 第 21 题 十六进制加法

**题目描述**

给定两个十六进制非负整数 A 和 B（数字 0-9 与大写字母 A-F），请计算它们的和，并以十六进制输出。

**输入格式**

一行，两个十六进制非负整数 A、B，用空格隔开（串长均不超过 8，无前导零；单独的 0 合法）。

**输出格式**

一行，A + B 的十六进制表示，字母大写，无前导零（结果 0 除外）。

**样例输入 #1

```
FF 1
```

**样例输出 #1

```
100
```

**样例输入 #2

```
2A 2A
```

**样例输出 #2

```
54
```

**样例输入 #3

```
0 0
```

**样例输出 #3

```
0
```

**数据范围**

串长 ≤ 8（数值 < 16⁸ ≈ 4.3×10⁹，和可能超出 int，请注意类型）。

### 第 22 题 两两异或最大值

**题目描述**

给出 n 个非负整数，从中任选两个不同的数 a、b（下标不同即可，数值可以相同），计算 a ⊕ b（按位异或）。请输出所有选择中异或值的最大值。

异或 ⊕ 的规则：两个二进制位相同得 0，不同得 1。例如 5 ⊕ 3 = 101₂ ⊕ 011₂ = 110₂ = 6。

**输入格式**

第一行一个整数 n（2 ≤ n ≤ 1000）；

第二行 n 个非负整数 aᵢ（0 ≤ aᵢ ≤ 10⁹），用空格分隔。

**输出格式**

一行，一个整数，最大的异或值。

**样例输入 #1

```
3
5 3 6
```

**样例输出 #1

```
6
```

**样例说明** #1

5⊕3=6，5⊕6=3，3⊕6=5，最大为 6。

**样例输入 #2

```
4
7 7 7 7
```

**样例输出 #2

```
0
```

**数据范围**

2 ≤ n ≤ 1000，0 ≤ aᵢ ≤ 10⁹。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T2>
