## 三、编程题（4 题 × 15 分 = 60 分）

### 第 21 题 k进制回文

#### 题目描述

给定进制 k（2 ≤ k ≤ 16）和一个十进制非负整数 n，请判断 n 在 k 进制表示下（无前导零）是否为回文数。回文指正读反读完全一致。是输出 `Yes`，不是输出 `No`。

k 进制数码：0-9 表示 0~9，10~15 依次用大写字母 A-F 表示。

#### 输入格式

一行，两个整数 k 和 n（2 ≤ k ≤ 16，0 ≤ n ≤ 10⁹），用空格分隔。

#### 输出格式

一行，`Yes` 或 `No`。

#### 样例输入 #1

```
2 9
```

#### 样例输出 #1

```
Yes
```

#### 样例说明 #1

9 的二进制是 1001，正读反读一致。

#### 样例输入 #2

```
10 19
```

#### 样例输出 #2

```
No
```

#### 样例输入 #3

```
16 255
```

#### 样例输出 #3

```
Yes
```

#### 样例说明 #3

255 的十六进制是 FF。

#### 数据范围

2 ≤ k ≤ 16，0 ≤ n ≤ 10⁹。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T1>

### 第 22 题 立方和

#### 题目描述

求 1³ + 2³ + 3³ + … + n³ 的精确值。

提示：立方和公式为 1³ + 2³ + … + n³ = (1 + 2 + … + n)²。即先求前 n 个正整数的和 S，答案就是 S × S。n 较大时 S 的平方会超过 64 位整数范围，请使用高精度计算。

#### 输入格式

一行，一个正整数 n（1 ≤ n ≤ 30000）。

#### 输出格式

一行，1³ + 2³ + … + n³ 的精确值。

#### 样例输入 #1

```
3
```

#### 样例输出 #1

```
36
```

#### 样例说明 #1

1 + 8 + 27 = 36；验证公式：(1+2+3)² = 6² = 36。

#### 样例输入 #2

```
100
```

#### 样例输出 #2

```
25502500
```

#### 样例说明 #2

(1+2+…+100)² = 5050² = 25502500。

#### 数据范围

1 ≤ n ≤ 30000（n = 30000 时答案约 18 位，超过 64 位整数，须高精度）。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T2>

### 第 23 题 两数相同位

#### 题目描述

给定两个正整数 m 和 n，把两个数都写成二进制（无前导零）。将较短的数在高位补 0，使两串等长。请统计对应位上数字相同的位数有多少。

例如 m = 5（101），n = 3（011），补齐后比较：1=0 不同、0=1 不同、1=1 相同，答案为 1。

#### 输入格式

一行，两个正整数 m 和 n（1 ≤ m, n ≤ 10⁹），用空格分隔。

#### 输出格式

一行，一个整数，相同位的个数。

#### 样例输入 #1

```
5 3
```

#### 样例输出 #1

```
1
```

#### 样例输入 #2

```
233 233
```

#### 样例输出 #2

```
8
```

#### 样例说明 #2

233 的二进制是 11101001，共 8 位，全部相同。

#### 数据范围

1 ≤ m, n ≤ 10⁹。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T3>

### 第 24 题 十六进制转二进制

#### 题目描述

给一个十六进制非负整数（数字 0-9 与大写字母 A-F），请把它换算成二进制串输出。

每一位十六进制数码恰好对应 4 位二进制；拼接后去掉整体的前导零。

#### 输入格式

一行，一个十六进制非负整数（1 ≤ 串长 ≤ 8），无前导空格；单独的 0 合法。

#### 输出格式

一行，对应的二进制串，不含前导零（结果 0 除外）。

#### 样例输入 #1

```
2A
```

#### 样例输出 #1

```
101010
```

#### 样例输入 #2

```
1B
```

#### 样例输出 #2

```
11011
```

#### 样例输入 #3

```
0
```

#### 样例输出 #3

```
0
```

#### 数据范围

1 ≤ 串长 ≤ 8（数值 < 16⁸，超出 int 范围，须逐位转换拼接，不能先转十进制再存 int）。
