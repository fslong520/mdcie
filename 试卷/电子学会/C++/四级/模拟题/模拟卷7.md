## 三、编程题（4 题 × 15 分 = 60 分）

### 第 21 题 二进制转十六进制

给出一串 0/1 数字组成的二进制串，请把它换算成十六进制并输出（字母用大写 A-F）。从二进制转十六进制时，从右往左每四位分成一组，每组换成一个十六进制数码；最左边不足四位的一组按实际位数换算。

**输入格式**

一行，一个二进制串 s（1 ≤ 串长 ≤ 32），不含前导零（串 0 除外，若输入只有一位则为 0）。

**输出格式**

一行，对应的十六进制数，字母大写，无前导零（结果 0 除外）。

**样例输入 1**

```
11011
```

**样例输出 1**

```
1B
```

**样例输入 2**

```
101010
```

**样例输出 2**

```
2A
```

**数据范围**

1 ≤ 串长 ≤ 32。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T1>

### 第 23 题 阶乘和

求 S = 1! + 2! + 3! + … + n! 的精确值。n! 表示阶乘，即 1×2×…×n，并规定 1! = 1。

**输入格式**

一行，一个正整数 n（1 ≤ n ≤ 50）。

**输出格式**

一行，S 的精确值。

**样例输入 1**

```
4
```

**样例输出 1**

```
33
```

**样例说明 1**：1! + 2! + 3! + 4! = 1 + 2 + 6 + 24 = 33。

**样例输入 2**

```
10
```

**样例输出 2**

```
4037913
```

**数据范围**

1 ≤ n ≤ 50（50! 约 65 位，须用高精度）。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T3>

### 第 24 题 二进制间距

一个正整数的二进制表示中，两个相邻的 1 之间的 0 的连续段长度称为一个"间距"。例如 22 的二进制是 10110，1 与 1 之间的间距有 1（两个 1 之间隔一个 0）。定义"最大间距"为所有间距中的最大值：22 的最大间距是 1；而 541 的二进制是 1000011101，最长连续 0 段为 4，最大间距为 4。若二进制中 1 的个数不足 2 个（如 8 的二进制 1000），最大间距为 0。给定正整数 n，求其二进制的最大间距。

**输入格式**

一行，一个正整数 n（1 ≤ n ≤ 10⁹）。

**输出格式**

一行，一个整数，最大间距。

**样例输入 1**

```
22
```

**样例输出 1**

```
1
```

**样例输入 2**

```
541
```

**样例输出 2**

```
4
```

**数据范围**

1 ≤ n ≤ 10⁹。

**OJ 链接：** <https://fslong.iok.la/problem/CIE202610L4T4>
