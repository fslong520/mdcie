# 高精度加法

天文望远镜记录了两个超大整数的观测编号，它们都可能长达 500 位。请计算这两个非负整数的和。

【输入格式】共两行，每行一个非负整数（不含前导零，可以为 0）。
【输出格式】一行，表示两数之和。
【样例输入 1】
```
12345678901234567890
98765432109876543210
```
【样例输出 1】
```
111111111011111111100
```
【样例输入 2】
```
0
0
```
【样例输出 2】
```
0
```
【数据范围】两个整数均不超过 500 位。
#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1400**。
