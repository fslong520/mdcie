# 高精度平方和

天文学中常用"能量平方和"衡量两颗星体的活跃度：把两串超长读数各自平方后相加。读数可能长达 100 位，请计算 a² + b² 的精确值。

【输入格式】共两行，每行一个非负整数 a、b（不含前导零，可以为 0）。
【输出格式】一行，表示 a² + b²。
【样例输入 1】
```
12
34
```
【样例输出 1】
```
1300
```
【样例说明】12² + 34² = 144 + 1156 = 1300。
【样例输入 2】
```
0
0
```
【样例输出 2】
```
0
```
【数据范围】a、b 均不超过 100 位。

#### 知识点与难度
本题涉及的知识点从属于 **电子学会（CIE）4级**，难度（CF Rating）：**1500**。
