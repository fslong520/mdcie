### 第 23 题 单价计算 ★★（30 分）

**【题目描述】**

购买若干件商品，单价为 p（可能很大），数量为 k（1-9 的一位整数），请用高精度计算总价。
【输入格式】第一行一个字符串 p（表示单价，不含前导 0）；第二行一位整数 k。
【输出格式】一个整数，表示总价。
【样例输入 1】
```
123
4
```
【样例输出 1】
```
492
```
【样例输入 2】
```
999999999999999999999999
9
```
【样例输出 2】
```
8999999999999999999999991
```
【数据范围】p 长度 ≤ 1000，1 ≤ k ≤ 9。

**【参考程序】**

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

string mul(string a, int k)
{
    string r = "";
    int carry = 0;
    for (int i = a.size() - 1; i >= 0; i--)
    {
        int s = (a[i] - '0') * k + carry;
        r += char(s % 10 + '0');
        carry = s / 10;
    }
    while (carry) { r += char(carry % 10 + '0'); carry /= 10; }
    reverse(r.begin(), r.end());
    return r;
}

int main()
{
    string p;
    int k;
    cin >> p >> k;
    cout << mul(p, k) << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 高精度乘法：从最低位开始逐位乘 k，当前位 = (原位×k+进位) % 10，进位 = (原位×k+进位)/10，最后处理进位。

### 第 24 题 阶乘和 ★★★（30 分）

**【题目描述】**

求 1! + 2! + 3! + … + n! 的值，结果可能很大，请用高精度计算。
【输入格式】一个整数 n。
【输出格式】一个整数，表示阶乘之和。
【样例输入 1】
```
5
```
【样例输出 1】
```
153
```
【样例输入 2】
```
10
```
【样例输出 2】
```
4037913
```
【数据范围】1 ≤ n ≤ 200。

**【参考程序】**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

vector<int> add(vector<int> a, vector<int> b)
{
    vector<int> r;
    int carry = 0, i = 0;
    while (i < a.size() || i < b.size() || carry)
    {
        int s = carry;
        if (i < a.size()) s += a[i];
        if (i < b.size()) s += b[i];
        r.push_back(s % 10);
        carry = s / 10;
        i++;
    }
    return r;
}

vector<int> mul(vector<int> a, int k)
{
    vector<int> r;
    int carry = 0;
    for (int i = 0; i < a.size(); i++)
    {
        int s = a[i] * k + carry;
        r.push_back(s % 10);
        carry = s / 10;
    }
    while (carry) { r.push_back(carry % 10); carry /= 10; }
    return r;
}

int main()
{
    int n;
    cin >> n;
    vector<int> sum(1, 0), term(1, 1);
    for (int i = 1; i <= n; i++)
    {
        term = mul(term, i);
        sum = add(sum, term);
    }
    for (int i = sum.size() - 1; i >= 0; i--) cout << sum[i];
    cout << endl;
    return 0;
}
```

**答案：（见参考程序）**

**解析：** 高精度乘加：每次计算当前阶乘 term = term × i（高精度乘一位），再累加到 sum（高精度加），循环 i=1..n。
