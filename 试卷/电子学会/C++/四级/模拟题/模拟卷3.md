### 第 1 题（电子学会四级模拟·指针）执行以下代码，输出结果是？（ ）

```cpp
int a[5] = {1, 2, 3, 4, 5};
int *p = &a[3];
cout << *(p - 2);
```

- A. 1
- B. 3
- C. 4
- D. 2

**答案：D**

**解析：** `p` 指向 `a[3]`（值为 4），`p - 2` 指向它前面第 2 个元素 `a[1]`，`*(p - 2)` 取值为 2。

### 第 2 题（电子学会四级模拟·指针）执行以下代码，以下表达式结果为真的是？（ ）

```cpp
int a = 5, b = 5;
int *p = &a, *q = &b;
```

- A. `p == q`
- B. `*p == *q`
- C. `p == 5`
- D. `&p == &q`

**答案：B**

**解析：** `p`、`q` 分别指向变量 `a`、`b`，地址不同故 `p == q` 为假；`*p` 与 `*q` 都是 5，`*p == *q` 为真。

### 第 3 题（电子学会四级模拟·结构体）执行以下代码，输出结果是？（ ）

```cpp
struct Point { int x, y; };
void f(Point *p) { p->x = 10; }
Point p = {1, 2};
f(&p);
cout << p.x;
```

- A. 1
- B. 2
- C. 10
- D. 随机值

**答案：C**

**解析：** `f(&p)` 将结构体地址传给形参，`p->x = 10` 通过指针修改原结构体的成员 `x`，故输出 10。

### 第 4 题（电子学会四级模拟·类）以下关于类与对象的说法，正确的是？（ ）

- A. 类是对象的实例
- B. 对象是类的实例
- C. 一个对象可以同时属于多个类
- D. 定义类之后必须创建对象，成员函数才能被定义

**答案：B**

**解析：** 类是对一类事物的抽象模板，对象是按类创建的实例；对象只属于其创建所用的类。

### 第 5 题（电子学会四级模拟·进制转换）将二进制数 `101101` 转换为十进制数，结果是？（ ）

- A. 43
- B. 45
- C. 47
- D. 41

**答案：B**

### 第 6 题（电子学会四级模拟·位运算）C++ 表达式 `10 & 6` 的计算结果是？（ ）

- A. 10
- B. 6
- C. 14
- D. 2

**答案：D**

**解析：** 10 的二进制为 1010，6 的二进制为 0110，按位与 1010 & 0110 = 0010 = 2。

### 第 7 题（电子学会四级模拟·排序）桶排序在数据分布较均匀时，平均时间复杂度接近？（ ）

- A. O(n)
- B. O(n²)
- C. O(n log n)
- D. O(1)

**答案：A**

**解析：** 桶排序将数据分入若干桶后分别排序，数据均匀时每桶元素很少，总复杂度接近 O(n)。

### 第 8 题（电子学会四级模拟·排序）对数组 `[5, 3, 8, 1]` 执行升序选择排序，第一趟结束后数组为？（ ）

- A. `[1, 3, 8, 5]`
- B. `[1, 5, 8, 3]`
- C. `[5, 3, 8, 1]`
- D. `[3, 5, 8, 1]`

**答案：A**

**解析：** 选择排序第一趟选出未排序部分的最小值 1，与第一个元素 5 交换，得 `[1, 3, 8, 5]`。

### 第 9 题（电子学会四级模拟·高精度）高精度减法中，若被减数与减数位数相同，比较大小应如何做？（ ）

- A. 从个位开始逐位比较
- B. 比较各位数字之和
- C. 从最高位开始逐位比较
- D. 直接相减看符号

**答案：C**

**解析：** 位数相同时，从最高位（首位）开始逐位比较数字大小，即可判断两数大小。

### 第 10 题（电子学会四级模拟·高精度）十进制高精度减法中，当前位数字为 3，需要减去 8，向高位借 1 后本位的计算结果是？（ ）

- A. 5
- B. 11
- C. 3
- D. 13

**答案：A**

**解析：** 借 1 后当前位变 3 + 10 = 13，13 - 8 = 5。

### 第 11 题（电子学会四级模拟·指针）使用未初始化的指针是安全的，可以直接访问内存。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 未初始化的指针是野指针，指向未知地址，解引用会导致程序崩溃或未定义行为。

### 第 12 题（电子学会四级模拟·指针）`int` 类型指针加 1，会指向下一个 `int` 元素（地址增加 `sizeof(int)` 字节）。（ ）

- T. 正确
- F. 错误

### 第 16 题（电子学会四级模拟·位运算）异或运算满足交换律和结合律。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 按位异或逐位独立进行，满足交换律（a⊕b = b⊕a）与结合律（(a⊕b)⊕c = a⊕(b⊕c)）。

### 第 17 题（电子学会四级模拟·排序）对已经基本有序的数组，插入排序的效率通常高于快速排序。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 插入排序对基本有序数组接近 O(n)；快速排序若基准选取不当（如取首元素且数组有序）会退化为 O(n²)。

### 第 18 题（电子学会四级模拟·排序）两个排序算法的稳定性相同，则它们的时间复杂度一定相同。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 稳定性描述相等元素的相对顺序是否保持不变，与时间复杂度没有直接关系。

### 第 19 题（电子学会四级模拟·高精度）高精度加法中，如果最高位产生进位，结果的位数比最长的加数多 1。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 加法从低位逐位进位，若最高位也产生进位，结果位数比最长加数多 1。

### 第 20 题（电子学会四级模拟·高精度）高精度乘法的时间复杂度为 O(n + m)，其中 n、m 为两数的位数。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 高精度乘法需两层循环逐位相乘，时间复杂度为 O(n × m)，并非 O(n + m)。
