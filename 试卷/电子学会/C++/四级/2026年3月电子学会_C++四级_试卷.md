### 第 1 题（2026 电子学会四级真题·指针）已知 `int x = 10;`，要让指针 `p` 指向 `x`，以下写法正确的是？（ ）

- A. `int p = &x;`
- B. `int *p = &x;`
- C. `int *p = x;`
- D. `*p = &x;`

**答案：B**

**解析：** `int *p = &x;` 中 `p` 是指向 int 的指针，`&x` 是变量 `x` 的地址，类型匹配，正确；A 把地址赋给普通 int 变量类型不匹配；C 把 int 值赋给指针需强制转换；D 解引用未初始化的指针并赋地址，错误。

### 第 2 题（2026 电子学会四级真题·指针）执行以下代码，输出结果是？（ ）

```cpp
int a = 20;
int *p = &a;
*p = 30;
cout << a;
```

- A. 20
- B. 30
- C. 0
- D. 随机值

**答案：B**

**解析：** `p` 指向 `a`，`*p = 30` 通过指针把 `a` 的值改为 30，故输出 30。

### 第 3 题（2026 电子学会四级真题·结构体）以下关于 C++ 结构体的说法，错误的是？（ ）

- A. 结构体可以包含多个不同类型的成员变量
- B. 结构体可以定义成员函数
- C. 结构体变量的成员可以通过 `.` 运算符访问
- D. 结构体的大小等于所有成员变量大小的总和，无任何内存对齐

**答案：D**

**解析：** C++ 结构体存在内存对齐（padding），其大小通常是各成员大小之和再按对齐规则向上取整，并非简单相加；A、B、C 均正确。

### 第 4 题（2026 电子学会四级真题·结构体）有结构体定义如下，访问结构体变量 `s` 的 `age` 成员，写法正确的是？（ ）

```cpp
struct Student {
    string name;
    int age;
};
Student s;
```

- A. `s->age`
- B. `Student.age`
- C. `s.age`
- D. `*s.age`

**答案：C**

**解析：** `s` 是结构体变量（非指针），用 `.` 访问成员；`->` 用于指针访问；`Student` 是类型名，不能直接访问成员。

### 第 5 题（2026 电子学会四级真题·进制转换）将二进制数 `1010` 转换为十进制数，结果是？（ ）

- A. 8
- B. 10
- C. 12
- D. 14

**答案：B**

**解析：** `1010`₂ = 1×8 + 0×4 + 1×2 + 0×1 = 10。

### 第 6 题（2026 电子学会四级真题·位运算）C++ 表达式 `5 & 3` 的计算结果是？（ ）

- A. 1
- B. 7
- C. 8
- D. 15

**答案：A**

**解析：** 5 的二进制为 101，3 的二进制为 011，按位与 101 & 011 = 001 = 1。

### 第 7 题（2026 电子学会四级真题·排序）以下排序算法中，平均时间复杂度为 O(n log n) 的是？（ ）

- A. 冒泡排序
- B. 插入排序
- C. 选择排序
- D. 快速排序

**答案：D**

**解析：** 冒泡、插入、选择排序平均时间复杂度均为 O(n²)；快速排序平均时间复杂度为 O(n log n)。

### 第 8 题（2026 电子学会四级真题·排序）以下关于排序算法稳定性的说法，正确的是？（ ）

- A. 冒泡排序是不稳定排序
- B. 选择排序是稳定排序
- C. 插入排序是稳定排序
- D. 快速排序是稳定排序

**答案：C**

**解析：** 插入排序是稳定排序；冒泡排序稳定、选择排序不稳定、快速排序不稳定。

### 第 9 题（2026 电子学会四级真题·高精度）在用数组实现高精度加法时，若从数组下标 0 开始存储数字，通常选择将最低位存储在下标 0 处。这样设计的主要原因是？（ ）

- A. 方便按从低位到高位的顺序处理进位
- B. 方便按从高位到低位输出
- C. 节省数组空间
- D. 避免数组越界

**答案：A**

**解析：** 加法从最低位算起，进位向高位传播；将最低位放在下标 0，可顺序遍历数组处理每一位及进位，逻辑自然。

### 第 10 题（2026 电子学会四级真题·高精度）两个长度分别为 n 和 m 的大整数相加，结果的最大长度是？（ ）

- A. max(n, m)
- B. max(n, m) + 1
- C. n + m
- D. n + m + 1

**答案：B**

**解析：** 两个大整数相加，进位最多使位数增加 1，故最大长度为 max(n, m) + 1。

- T. 正确
- F. 错误

**答案：T**

### 第 12 题（2026 电子学会四级真题·指针）空指针 `NULL` 可以被解引用，不会出现运行错误。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 解引用 `NULL`（地址 0）会访问非法内存，通常导致程序崩溃（段错误）。

### 第 13 题（2026 电子学会四级真题·结构体）C++ 中，结构体的成员变量必须全部是 `public` 的，不能设置为 `private` 或 `protected`。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** C++ 结构体默认成员为 `public`，但可显式使用 `private` / `protected` 改变访问权限。

### 第 14 题（2026 电子学会四级真题·结构体）相同类型的结构体变量之间可以直接用 `=` 进行赋值。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 若结构体可平凡复制（trivially copyable），C++ 允许同类型结构体变量整体赋值（逐成员拷贝）。

- T. 正确

十一进制是一种以 11 为基数的计数体系，其数字由 0-9 的常规数字和代表数值 10 的符号（大写字母 A）组成。给定一个十进制非负整数 n，请将其转换为十一进制数并输出。

单个整数表示十进制非负整数 n。

11

10

### 第 2 题 双阶乘 ★★★（30 分）

**【题目描述】**

双阶乘（用 n!! 表示）是阶乘的一种扩展形式，其定义为：

对于给定的非负整数 n，n!! 表示从 n 开始，依次乘以比前一项小 2 的数，直至乘积项不小于 1 为止。

具体规则：

若 n 为偶数：n!! = n × (n-2) × (n-4) × … × 2；

若 n 为奇数：n!! = n × (n-2) × (n-4) × … × 1；

特别地，0!! = 1，1!! = 1。

给定一个整数 n，请使用高精度算法计算并输出 n!! 的结果。

**【输入格式】**

单个整数表示 n。

**【输出格式】**

单个整数，表示 n!! 的计算结果。

**【样例输入 1】**

```
5
```

**【样例输出 1】**

```
15
```

**【样例输入 2】**

```
20
```

**【样例输出 2】**

```
3715891200
```

**【样例输入 3】**

```
100
```

**【样例输出 3】**

```
34243224702511976248246432895208185975118675053719198827915654463488000000000000
```

**【数据范围】**

0 ≤ n ≤ 2000。
