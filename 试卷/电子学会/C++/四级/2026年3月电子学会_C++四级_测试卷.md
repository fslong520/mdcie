### 第 1 题（2026 电子学会四级测试卷·位运算）`5 & 3` 的结果是？（ ）

- A. 1
- B. 7
- C. 6
- D. 0

**答案：A**

**解析：** 5 的二进制为 101，3 的二进制为 011，按位与 101 & 011 = 001 = 1。

### 第 2 题（2026 电子学会四级测试卷·位运算）按位与运算常用于？（ ）

- A. 清零特定位
- B. 判断奇偶
- C. 取某位值
- D. 以上都是

**答案：D**

**解析：** 按位与 `&` 可清零特定位（与 0 相与）、判断奇偶（与 1 相与取末位）、取某位值（与掩码相与），以上均为常见用法。

### 第 3 题（2026 电子学会四级测试卷·位运算）将某位设置为 1 的操作是？（ ）

- A. `x & mask`
- B. `x | mask`
- C. `x ^ mask`
- D. `x >> mask`

**答案：B**

**解析：** 按位或 `|` 可将对应位强制置 1（与 1 相或），故用 `x | mask` 设位；`&` 用于清位，`^` 用于取反，`>>` 是移位。

---

### 第 4 题（2026 电子学会四级测试卷·位运算）`0x0F | 0xF0` 的结果是？（ ）

- A. 0xFF
- B. 0x00
- C. 0x0F
- D. 0xF0

**答案：A**

**解析：** 0x0F = 0000 1111，0xF0 = 1111 0000，按位或得 1111 1111 = 0xFF。

### 第 5 题（2026 电子学会四级测试卷·位运算）以下代码的输出是？（ ）

```cpp
int a = 12;
int b = 10;
cout << (a ^ b);
```

- A. 6
- B. 12
- C. 10
- D. 14

**答案：A**

**解析：** 12 = 1100₂，10 = 1010₂，异或 1100 ^ 1010 = 0110₂ = 6。

### 第 6 题（2026 电子学会四级测试卷·位运算）交换 `a` 和 `b` 的值，可用异或实现，以下语句的正确顺序是？（ ）

（1）`a ^= b;`

（2）`b ^= a;`

- A. 1 2 1
- B. 1 2 2
- C. 2 2 1
- D. 2 2 1

**答案：A**

**解析：** 异或交换三步：`a ^= b; b ^= a; a ^= b;`（即 1 2 1）。第一步令 a = a^b；第二步 b = b^(a^b) = 原 a；第三步 a = (a^b)^原 a = 原 b。

### 第 7 题（2026 电子学会四级测试卷·排序）以下哪种排序算法是稳定的？（ ）

- A. 快速排序
- B. 堆排序
- C. 归并排序
- D. 选择排序

**答案：C**

**解析：** 归并排序是稳定排序；快速排序、堆排序、选择排序均为不稳定排序。

### 第 8 题（2026 电子学会四级测试卷·进制转换）十六进制 `0xFF` 转换为十进制是？（ ）

- A. 255
- B. 256
- C. 15
- D. 240

**答案：A**

**解析：** 0xFF = 15×16¹ + 15×16⁰ = 240 + 15 = 255。

### 第 9 题（2026 电子学会四级测试卷·复杂度）分析以下程序片段的时间复杂度是？（ ）

```cpp
int cal(int n) {
    if (n <= 0) return 1;
    return cal(n - 1) + cal(n - 1);
}
```

- A. O(n)
- B. O(2^n)
- C. O(n²)
- D. O(n log n)

**答案：B**

**解析：** `cal(n)` 每次递归产生 2 个 `cal(n-1)` 调用，递归深度为 n，总调用次数约 2ⁿ，时间复杂度 O(2ⁿ)。

### 第 10 题（2026 电子学会四级测试卷·进制转换）二进制 `1011` 转换为十进制是？（ ）

- A. 11
- B. 13
- C. 9
- D. 12

**答案：A**

**解析：** 1011₂ = 1×8 + 0×4 + 1×2 + 1×1 = 11。

### 第 11 题（2026 电子学会四级测试卷·位运算）`x & (x-1)` 可以将 `x` 的最低位的 1 置为 0。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `x & (x-1)` 是经典位运算技巧，可将 `x` 二进制表示中最低的那个 1 变为 0，其余位不变。

### 第 12 题（2026 电子学会四级测试卷·位运算）按位或运算满足交换律和结合律。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 按位或逐位独立进行，满足交换律（a|b = b|a）与结合律（(a|b)|c = a|(b|c)）。

### 第 13 题（2026 电子学会四级测试卷·位运算）`x | 0` 的结果是 0。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 任何数与 0 按位或结果仍是原数本身，即 `x | 0 = x`，并非恒为 0（仅当 x = 0 时为 0）。

### 第 15 题（2026 电子学会四级测试卷·位运算）任何数与自身异或结果为 0。（ ）

### 第 16 题（2026 电子学会四级测试卷·排序）快速排序在最坏情况下的时间复杂度是 O(n²)。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 当基准选取出极端（如序列已有序且每次取最小/最大元素作基准），快速排序退化为 O(n²)。

### 第 17 题（2026 电子学会四级测试卷·排序）冒泡排序是一种稳定的排序算法。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 冒泡排序仅当相邻元素严格大于才交换，相等元素不交换，相对顺序不变，是稳定排序。

- F. 错误

### 第 19 题（2026 电子学会四级测试卷·数据类型）负数的二进制表示通常使用补码。（ ）

- T. 正确
- F. 错误

**答案：T**

### 第 20 题（2026 电子学会四级测试卷·算法）枚举法一定不是最好的解法。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 枚举（暴力）并非“一定不是最好解法”——当数据规模较小或无更优算法时，枚举往往最直接、可靠甚至最优；“一定”过于绝对。

### 第 2 题 四方定理 ★★★（30 分）

**【题目描述】**

给定一个自然数 n，请输出 n 的所有四平方拆分方案。

**【输入格式】**

单个整数：表示 n。

**【输出格式】**

若干行：每行四个由小到大排列的自然数，表示一种拆分方案。

如果有多种方案，先输出首项较小的方案，对于首项相同的方案，先输出第二项较小的方案，其他情况以此类推。

**【样例输入 1】**

```
25
```

**【样例输出 1】**

```
0 0 0 5
0 0 3 4
1 2 2 4
```

**【数据范围】**

0 ≤ n ≤ 50,000。
