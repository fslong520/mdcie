# 编程题（每题 30 分，共 60 分）

### 第 1 题 计算不同位 ★★（30 分）

**【题目描述】**

给你两个正整数 m、n，请问它们二进制位上有多少位是不同的。

**【输入格式】**

两个正整数 n、m。

**【输出格式】**

一个整数，表示答案。

**【样例输入 1】**

```
2 1
```

**【样例输出 1】**

```
2
```

**【样例输入 2】**

```
3 17
```

**【样例输出 2】**

```
2
```

**【样例输入 3】**

```
233 233
```

**【样例输出 3】**

```
0
```

**【数据范围】**

1 ≤ n、m ≤ 10⁹。

---

### 第 2 题 四方定理 ★★★（30 分）

**【题目描述】**

给定一个自然数 n，请输出 n 的所有四平方拆分方案。

**【输入格式】**

单个整数：表示 n。

**【输出格式】**

若干行：每行四个由小到大排列的自然数，表示一种拆分方案。

如果有多种方案，先输出首项较小的方案，对于首项相同的方案，先输出第二项较小的方案，其他情况以此类推。

**【样例输入 1】**

```
25
```

**【样例输出 1】**

```
0 0 0 5
0 0 3 4
1 2 2 4
```

**【数据范围】**

0 ≤ n ≤ 50,000。
