### 第 1 题（2026 电子学会四级真题·指针）已知 `int x = 15; int *p = &x;`，以下说法【错误】的是？（ ）

- A. `p` 中存储的是变量 `x` 的内存地址
- B. `*p` 代表指针 `p` 指向的变量 `x` 的值
- C. 执行 `*p = 20;` 后，`x` 的值会变为 20
- D. 执行 `p = 20;` 后，`x` 的值会变为 20

**答案：D**

**解析：** `p = 20;` 的含义是让指针 `p` 指向地址编号 20，不会改变 `x` 的值，而且一般属于非法地址操作。

### 第 2 题（2026 电子学会四级真题·指针）执行以下代码，输出结果是？（ ）

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;
cout << *(p + 2);
```

- A. 10
- B. 20
- C. 30
- D. 40

**答案：C**

**解析：** 指针 `p` 指向数组首地址，则 `p + 2` 指向第 3 个元素，取其值为 30。

### 第 3 题（2026 电子学会四级真题·类）以下关于 C++ 类的说法，正确的是？（ ）

- A. 类的成员默认访问权限是 `public`
- B. 类中只能定义成员变量，不能定义成员函数
- C. 面向对象是一种封装数据与行为的编程方法
- D. 一个类只能创建一个对象

**答案：C**

**解析：** 类的成员默认访问权限是 `private`；类中可以定义成员变量和成员函数；类的对象个数无限制。

### 第 4 题（2026 电子学会四级真题·结构体）有结构体定义如下，以下写法正确的是？（ ）

```cpp
struct Book {
    string name;
    double price;
};
```

- A. `Book.name = "C++入门";`
- B. `Book b; b.price = 39.9;`
- C. `Book b; b->name = "算法竞赛";`
- D. `struct b; b.name = "数据结构";`

**答案：B**

**解析：** 只能对类的对象进行成员赋值，A 错误；`->` 是对指针访问成员的方式，C 错误；应为 `struct Book b;`，D 错误。

### 第 5 题（2026 电子学会四级真题·进制转换）将十进制数 25 转换为二进制，结果是？（ ）

- A. 10101
- B. 11001
- C. 11100
- D. 10011

**答案：B**

**解析：** 除 2 求余法：25/2=12…1，12/2=6…0，6/2=3…0，3/2=1…1，1/2=0…1，余数逆序为 11001。

### 第 6 题（2026 电子学会四级真题·位运算）C++ 表达式 `7 | 3` 的计算结果是？（ ）

- A. 3
- B. 7
- C. 10
- D. 21

**答案：B**

**解析：** 7 的二进制为 111，3 的二进制为 011，二者按位或运算结果仍是 111，即 7。

### 第 7 题（2026 电子学会四级真题·排序）以下排序算法中，最坏时间复杂度为 O(n log n) 的是？（ ）

- A. 冒泡排序
- B. 插入排序
- C. 归并排序
- D. 选择排序

**答案：C**

**解析：** 冒泡、插入、选择排序时间复杂度为 O(n²)，归并排序时间复杂度为 O(n log n)。

### 第 8 题（2026 电子学会四级真题·排序）以下关于排序算法的说法，【错误】的是？（ ）

- A. 快速排序是分治思想的典型应用
- B. 冒泡排序每一轮都会将一个最大的元素“冒泡”到末尾
- C. 插入排序适合处理已经基本有序的数组
- D. 选择排序是稳定排序算法

**答案：D**

**解析：** 选择排序每次选择最小值与未排序序列第一个交换，可能会改变相同值元素的相对位置，是不稳定的。

### 第 9 题（2026 电子学会四级真题·高精度）两个长度分别为 1000 位和 800 位的大整数相乘，结果的最大长度是？（ ）

- A. 1000
- B. 1800
- C. 1801
- D. 800000

**答案：B**

**解析：** m 位十进制整数 × n 位十进制整数，乘积最多 m + n 位。

### 第 11 题（2026 电子学会四级真题·指针）空指针 `nullptr` 是 C++11 引入的，专门用于表示空指针，比 `NULL` 更安全。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** `NULL` 本质是宏 `#define NULL 0`，属于整型常量；`nullptr` 是独立空指针常量类型。当函数重载区分 `int` 和指针参数时，`NULL` 会产生歧义，`nullptr` 不会，安全性更高。

### 第 16 题（2026 电子学会四级真题·位运算）C++ 中，右移运算符 `>>` 对于有符号数，会在低位补符号位。（ ）

- T. 正确
- F. 错误

**答案：F**

**解析：** 右移丢掉低位，空缺出现在左边高位；对有符号数按算术移位在高位补符号位（非负补 0，负数补 1），而非在低位补符号位。

### 第 17 题（2026 电子学会四级真题·排序）归并排序是稳定排序算法。（ ）

- T. 正确
- F. 错误

**答案：T**

**解析：** 归并排序合并时，遇到相等元素优先取左区间元素，维持原有先后顺序，属于稳定排序。

### 第 1 题 总异或和 ★★★（30 分）

**【题目描述】**

给定长度为 n 的序列 A₁、A₂、……、Aₙ，我们要计算所有数对 (i, j) 对应的 Aᵢ + Aⱼ 的总异或和。即把所有满足 1 ≤ i、j ≤ n 的 Aᵢ + Aⱼ 依次进行异或，输出最终结果。

举例：当 n = 3 时，计算式为：

(A₁+A₁) ⊕ (A₁+A₂) ⊕ (A₁+A₃) ⊕ (A₂+A₁) ⊕ (A₂+A₂) ⊕ (A₂+A₃) ⊕ (A₃+A₁) ⊕ (A₃+A₂) ⊕ (A₃+A₃)

其中 ⊕ 表示按位异或运算。

**【输入格式】**

共两行，第一行一个正整数 n；第二行 n 个正整数，表示序列 A₁、A₂、……、Aₙ。

**【输出格式】**

输出一个整数，表示所有数对计算后的总异或值。

**【样例输入】**

```
3
2 12 27
```

**【样例输出】**

```
42
```

**【数据范围】**

1 ≤ n ≤ 1000000，1 ≤ Aᵢ ≤ 10⁹。
